## 1. 表 4-3 之后的过渡与更新覆盖

前述候选筛选在 306,801 个 rollout 场景中得到 30,159 个至少含一条最终 RL 回归目标的场景组，共计 167,730 条候选轨迹目标。这里的 30,159 是**场景组数**，167,730 是**候选轨迹数**；其余 rollout 场景仍保存在 Replay 中，但不能称为产生了 RL 回归目标。

**表 4-4　全量安全约束后训练的目标覆盖与参数更新配置**

| 训练项 | 正式设置／观测结果 |
|---|---:|
| 含最终 RL 目标的场景组 | 30,159 |
| 最终 RL 回归目标候选轨迹 | 167,730 |
| Batch size（单进程实际值） | 2 个场景组 |
| 每批目标组槽位 | 1 个，无放回；另 1 个槽位取非目标组 |
| 目标组唯一访问数 | 30,159 |

| 实际 optimizer step | 30,159 |

| 配置初始学习率 | $4\times10^{-7}$（AdamW） |
| 参数更新范围 | 场景 Encoder 冻结；仅可训练的扩散模型部分进入 optimizer |

| 专家轨迹锚定系数 | 0.1 |
| 冻结 B10 参考策略锚定系数 | 0.1 |

在完成训练目标审计后，本文采用覆盖式更新方式优化上述 30,159 个目标场景组。目标组索引经随机化后无放回遍历，每批固定安排一个目标组和一个非目标组；由于每批只有一个目标槽位，完整覆盖所需的步数为 $\lceil 30159/1\rceil=30159$。正式训练执行了 30,159 次 optimizer step、未跳过更新，并记录 30,159 个唯一目标组被访问，验证目标组覆盖率为 100%。该设计避免随机有放回抽样漏掉稀缺的有效目标组，使安全筛选与任务保持约束得到的训练目标实际参与策略更新。

这里的“100% 覆盖”**仅指 30,159 个有目标的组**，不表示 306,801 个 rollout 场景全部产生 RL 梯度；完整 306,801 场景覆盖对应的是候选生成与磁盘 Replay。非目标组作为 batch 的第二个槽位参与条件输入与锚定更新，但不应被计入正优势 RL 目标。`rl_max_update_steps_per_epoch=0` 表示不另设固定步数上限，实际步数按目标组数量自动确定，而非执行零步。

## 2. 实际优化目标与损失构成

每个被保留的正优势候选作为扩散模型的回归目标。更新同时保留专家轨迹监督，并以冻结 B10 的预测为参考锚定。实际总目标为

$$
L_{\mathrm{total}}
=1.0L_{\mathrm{RL}}+0.1L_{\mathrm{expert}}+0.1L_{\mathrm{ref}},
\qquad
L_{\mathrm{RL}}=L_{\mathrm{diff,target}}+0.01L_{\mathrm{waypoint,target}}.
$$

其中，$L_{\mathrm{expert}}$ 沿用监督扩散损失实现，包含该实现配置的 hybrid waypoint 项；$L_{\mathrm{ref}}$ 是训练模型相对冻结 B10 的**预测空间均方误差锚定**，不是严格的策略 KL 或安全约束保证。

**表 4-5　30,159 个 optimizer step 的平均损失：原始值与进入总目标的贡献**

| 损失项 | 日志原始均值 | 进入总目标的系数 | 加权贡献均值 |
|---|---:|---:|---:|
| Reward-weighted diffusion loss | 0.000091671 | 1.00 | 0.000091671 |
| Reward-weighted waypoint loss | 0.004683046 | 0.01 | 0.000046830 |
| $L_{\mathrm{RL}}$（上两项小计） | 0.000138501 | 1.00 | 0.000138501 |
| Expert anchor | 0.003173458 | 0.10 | 0.000317346 |
| Reference anchor | 0.000035252 | 0.10 | 0.000003525 |
| **$L_{\mathrm{total}}$** | — | — | **0.000459372** |

表中的 RL 小计不是在前两行之外另加一次的独立损失；总损失只由 RL 小计、加权专家锚定和加权参考锚定三项相加。由于各项均为逐 step 均值且显示值经过四舍五入，按表内六位小数重算时可能有末位差异。尤其不能把 waypoint 原始均值 `0.004683046` 直接加到总损失：它先乘 `planning_hybrid_loss=0.01`，对总损失的平均贡献为约 `0.000046830`。同理，专家锚定的原始均值虽高于 RL 小计，但进入总损失前乘了 0.1。

上述统计证明这次训练确实完成了目标访问、参数更新与三项损失的联合优化；**仅凭训练损失大小不能证明闭环安全或总分改善**。策略有效性仍应引用独立 validation 和完整 Test14 对照，并报告已发现的责任碰撞／限速退化，不应把目标组全覆盖写成安全验收通过。
