# 第四章：候选生成修复的后训练严格单因素对照结果

> 结果固化时间：10月04日11时05分  
> 实验时间：10月04日09时58分—10时47分  
> 状态：完成  
> 结论级别：短程机制与方向证据，不是最终闭环性能证据

## 1. 本实验回答了什么

本实验只改变候选生成方式，其余起点checkpoint、数据、seed、group size、reward、安全过滤、anchor、学习率和更新步数均一致：

- Control：原始`noise=0.1×32`；
- Repair：`200条多尺度搜索池 → 安全多样性筛选 → 32条`；
- 共同起点：B10 Epoch10 EMA，SHA-256 `22ec0cf6be7cc89a3cf8414cddd0c7446ce2737ddc4e44b23e50dbeeeb0b29ce`；
- 每组执行20次optimizer update；
- 训练后相对B10执行`validation-1000×3`公共随机数配对评价，共3000对轨迹。

核心问题是：修复后的候选生成能否把“更大的候选差异”真正转化为更充分、方向更正确的后训练信号。

## 2. 训练信号：候选修复已经解决主要瓶颈

| 指标 | Control | Repair | 变化 |
|---|---:|---:|---:|
| `reward_std_mean` | 0.002393 | 0.046273 | **19.33×** |
| `reward_std_p50` | 0.002393 | 0.046273 | **19.33×** |
| `active_group_fraction` | 5.0% | 42.5% | **8.5×** |
| `has_regression_targets` | 10.0% | 75.0% | **7.5×** |
| `eligible_candidate_fraction` | 57.42% | 57.81% | +0.39pp |
| `no_eligible_group_fraction` | 42.5% | 35.0% | -7.5pp |
| 实际optimizer steps | 20 | 20 | 一致 |

这一结果的重要性在于：

1. 原始候选中只有5%的group达到`min_reward_std=0.01`，大部分group无法提供有效的组内优势信号；
2. Repair将有效group提高到42.5%，且有回归目标的batch由10%提高到75%；
3. 候选的总安全资格率几乎未变（57.42%→57.81%），说明改善主要来自候选差异和筛选结构，而不是放宽安全门槛；
4. Repair的更大train loss不代表模型更差，它反映的是更多group进入了有效的reward-weighted update。

因此，“同场景多候选过于相似，导致优势信号稀缺”这一训练侧问题已被明显缓解。

## 3. validation-1000×3：策略变化方向初步正确，但幅度很小

下表均为“后训练checkpoint - B10”的配对均值。对cost、ADE、FDE而言，负值表示改善。

| 指标 | Control - B10 | Repair - B10 | 方向审计 |
|---|---:|---:|---|
| reward | +0.008589 | +0.001682 | 两者均上升；Control均值受极端尾部影响大 |
| progress | -0.000198 | **+0.001050** | **Repair更好** |
| progress提高比例 | 62.4% | **94.9%** | **Repair方向更一致** |
| collision cost | -0.000014 | **-0.000192** | **Repair更好** |
| no-collision | +0.000333 | +0.000333 | 相同，各少一个碰撞样本 |
| comfort cost | -0.000010 | **-0.000110** | **Repair更好** |
| route cost | **-0.000039** | +0.000011 | Repair存在极小路线cost退化 |
| ADE (m) | -0.000197 | +0.000017 | 均可视为基本不变 |
| FDE (m) | +0.000503 | +0.001107 | 均为极小退化 |
| heading error (rad) | -0.0000039 | -0.0000065 | 两者均基本不变 |

Repair的progress差值在P10/P50/P90上均为正：`+0.000323 / +0.000964 / +0.002159`，这比只看均值更能说明方向一致。Control的progress均值反而为负。

Control的reward均值虽然更高，但其配对差值标准差为`0.232862`，而中位数仅`+0.000052`，说明均值被少量极端差值拉高。Repair的reward差值标准差仅`0.006475`，中位数为`+0.000078`，且reward提高比例为64.57%，高于Control的61.87%。因此，不应用Control的reward均值判定其优于Repair。

## 4. 验收结论

### 4.1 已经通过的部分

- **训练信号验收通过**：Repair显著提高reward组内方差、active group和有回归目标批次比例；
- **短程变化方向初步通过**：相对Control，Repair表现为progress上升、collision cost下降、comfort cost下降，且ADE基本不变；
- **基础模仿能力未见明显破坏**：ADE/FDE/航向误差变化都远小于指标本身尺度。

### 4.2 尚未通过的部分

- **尚不能声称闭环提升**：本轮只是近似离线reward和开环轨迹评价，未运行safety40或official closed-loop；
- **策略变化量仍然很小**：20次更新适合审计机制和方向，不足以证明最终收敛效果；
- **路线指标未严格全优**：Repair的route cost增加`0.000011`，幅度极小，但按预注册的严格安全/路线门禁，不应忽略；
- **计算代价增加**：Control训练约7分钟，Repair约40分钟，原因是每场景需要先生成200条搜索候选。

## 5. 当前最准确的科学结论

> 原始`noise=0.1×32`的后训练存在明显的候选同质化和有效优势信号稀缺问题。多尺度搜索与安全多样性筛选能在不放宽安全资格的前提下，大幅提高可用优势信号。在20次受控更新中，该信号已表现出更一致的进度改善以及碰撞和舒适性代价降低方向；但策略变化幅度尚小，且路线代价存在极小退化，因此当前证据只支持“候选生成机制修复有效”，不支持“后训练已实现稳定闭环提升”。

## 6. 下一步判断

不建议立即把这个20步checkpoint投入safety40并将其当作最终模型，因为当前差异小到很容易被40场闭环方差淹没。更合理的下一步是：

1. 只沿用已通过机制验收的Repair候选生成；
2. 在同一seed和同一训练数据上增加受控更新预算，保留中间checkpoint；
3. 每个中间checkpoint先通过`validation-1000×3`的progress/collision/route/comfort/ADE门禁；
4. 只将差异幅度足够且安全方向不退化的checkpoint进入固定`safety40`闭环配对评测。

这样可以把“候选生成修复”与“安全约束后训练是否真正改善策略”分成两个可独立验证、不夸大的科学结论。
