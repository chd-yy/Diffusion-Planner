# EXP001｜安全约束后训练的历史证据与最小研究问题

整理时间：09月17日 01:23（北京时间）。状态：completed，历史数据二次分析；新增训练0次、仿真0次。

## 1. 问题与方法

问题：现有旧RL/修复版相对B10的微小score差，是否足以支持稳定收益？修复是否主要体现为普遍进度损失？

采用全部272 hard、261 random原始逐场景指标，不筛选有利案例。按(log_name, scenario)配对；分别包含160和148个日志。以日志为重采样单元、有放回抽取相同日志数，保留每个日志中的所有场景配对。每次计算场景加权均值差，重复10000次，seed3407，取2.5%/97.5%分位。

区间是观测日志的探索性聚类重采样结果：假设log之间可作为近似独立重采样单位，不能消除跨log关联、场景选择偏差、测试调参偏差；不含训练或推理seed变异；无多重比较校正。它不是文献HCPI的OPE/重要性采样BCa保证，也不授权策略升级。

### 2.1 旧RL的尾部风险

hard上旧RL score胜116场、负48场；最差4场占全部下降量97.1694%。random对应比例94.0787%。因此“多数场景小幅提升”与“少数严重失败抵消收益”同时存在。这里是下降量的集中度，不是失败概率或CVaR估计。

### 2.2 修复后的广泛进度下降

修复版相对B10，hard progress增加5场、减少191场、持平76场；random增加1场、减少140场、持平120场，阈值1e-6。平均进度下降不是仅由一两个离群场景解释。

修复版hard仍有2场无责任碰撞指标新增退化；random有3场该指标改善、无新增该项退化。必须分集合展示，不能把random表现概括成“修复版全面更安全”。

## 3. 可以写入中期报告的认识

1. 在当前固定模型和评测实现下，奖励后训练改变了通行行为，但没有形成清晰的跨集合综合得分正收益证据。
2. 安全纠错/过滤后的进度损失具有较广场景覆盖，值得研究安全与进度的约束关系，而不是继续单纯增大安全reward。
3. 总分、均值碰撞率和逐场新增严重失败必须联合报告。只看score或只看reward均值会遗漏重要变化。
4. 现有对照同时改变了权重形式、过滤和几何，无法确定每个因素的因果贡献，必须新增同B10起点的受控消融。

## 4. 不能写的结论

- “已经证明安全过滤导致减速”：尚缺expert-only和单因素对照，进度减少也不能自动等同速度降低。
- “reward越高闭环越差”：此处没有对每个新策略重新采样并比较同分布reward的证据。
- “显著更安全”“高置信不退化”“保证无新增碰撞”：当前数据和分析不支持。
- “533个独立场景”：hard/random重叠11个token，且同log相关。
