# validation-1000当前多扩散候选采样对照实验

> 完成时间：10月07日22时  
> 实验性质：冻结B10的只读候选推理实验；不更新模型参数  
> 对照目标：复现“原始`0.1×32`与Repair比较”的实验结构，将Repair替换为当前Guided Safe-Set `88→32`多扩散候选采样方法  
> 正式结果：`tmp/chapter4_guided_safe_set_validation1000/validation1000_guided_safe_set88_to32_seed3407_formal.json`

## 1. 实验目的

本实验回答：

> 在相同B10、相同validation-1000场景、相同推理seed和相同DPM步数下，当前四分支`88→32`多扩散候选采样方法，相较原始`noise=0.1`重复采样32条，是否真正扩大了候选支持范围，并且是否保持了轨迹质量与安全代理？

这不是后训练实验，也不评价训练后模型。两组均使用冻结的B10，仅比较候选生成与压缩机制。

## 5. 按历史Repair门槛重新判定

若完全沿用历史Repair验收门槛，当前方法在截图所列8项中通过3项、未通过5项：

| 门槛 | 当前结果 | 判定 |
|---|---:|---|
| 终点P50≥0.25 m | 0.146333 m | 未通过 |
| 整轨迹P50≥0.10 m | 0.056044 m | 未通过 |
| `reward std≥0.01`场景≥40% | 10.6% | 未通过 |
| 至少2条安全候选增益≥5 pp | +2.10 pp | 未通过 |
| 运动场景安全覆盖增益≥5 pp | +2.72 pp | 未通过 |
| 候选平均ADE恶化≤1% | 改善0.161% | 通过 |
| Oracle ADE至少改善0.10 m | 改善0.101478 m | 通过 |
| 安全reward最佳ADE不差于基线单候选 | 2.188716 m＜2.207712 m | 通过 |

因此，不能把旧文档中的“厘米级候选坍缩已经按9倍幅度完成修复”原封不动转移到当前方法。当前方法的正确结论是：

> **它在不牺牲平均ADE、无碰撞比例和DA合规率的情况下，将终点及整轨迹候选差异分别扩大到原始方案的2.64倍和2.22倍，并带来可测的Oracle收益；但若沿用旧Repair的强多样性验收线，其候选支持范围和组内reward区分度仍未达标。**

## 6. 如何理解这个结果

### 6.1 正面结果

1. 当前方法不是“候选完全没有变化”：两个几何多样性指标均提高到两倍以上。
2. 多样性增加没有以平均轨迹质量下降为代价，平均ADE反而小幅改善`0.161%`。
3. Oracle ADE改善`0.101478 m`，说明32条最终候选中确实出现了原始低噪声组未覆盖的更优轨迹。
4. 无碰撞比例和DA合规率均未下降，证明hard-safe优先压缩发挥了作用。

### 6.2 负面结果

1. 当前方法只保留`noise=0.5`的有限探索，未使用Repair中的1.0–2.0高噪声分支，因此几何覆盖远低于Repair。
2. 73%左右场景关闭Guidance，这些场景的32条guided proposal只是额外低噪声自然样本，不能显著扩大行为支持。
3. 最终32条压缩优先保证hard-safe和平均质量，因此会主动牺牲一部分极端多样性。
4. `safe reward std≥0.01`只有10.6%，说明大量场景中即使轨迹几何不同，当前reward对这些差异仍不够敏感。

## 7. 对第四章结论的影响

本实验使第四章的结论需要分成两层：

1. **工程和训练可用性层面**：当前方法在306,801场景全量rollout中形成了30,159个正式target-bearing groups，已经足以完成全量后训练；这一点有正式训练日志支持。
2. **强候选多样性层面**：当前方法没有通过旧Repair预注册的强多样性门槛，不能宣称其在候选几何覆盖上优于Repair。

因此当前方案的优势不是“以更大的几何跨度取代Repair”，而是：

> 用更低的候选池成本和更保守的探索范围，在保持候选质量与安全代理的同时，提供足以启动全量后训练的有效目标；代价是候选支持与reward区分度仍然有限。
