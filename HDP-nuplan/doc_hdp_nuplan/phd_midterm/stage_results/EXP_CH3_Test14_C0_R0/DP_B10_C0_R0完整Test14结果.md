## 3. 跨集合结论

### 3.1 能够由当前证据支持的结论

1. **HDP系列在当前完整评测中均优于本地重训DP基线。** B10、C0和R0在hard/random上的Score均高于DP，方向在两个集合上一致；“均优于”仅指当前单训练seed、单推理seed的观测均值，不代表已证明统计显著性。
2. **R0稳定提高了路线推进性。** 相对C0，Route progress在hard和random分别提高`+0.029072`和`+0.022872`，Making progress也分别提高`+0.014706`和`+0.022989`。
3. **R0未稳定保持安全性与可行性。** DA在两个集合上均下降，TTC、限速合规性和舒适性也均未超过C0。NC在hard下降而在random上升，不具备跨集合一致性。
4. **R0的综合得分收益不稳定。** hard上相对C0下降`-0.016020`，random上提高`+0.008250`。因此，现有证据不支持“Abs表示在系统级闭环中整体优于Delta表示”。
5. **基础模型之间存在安全、推进性和驾驶质量的权衡，后训练继续以B10为起点。** C0相对R0在DA、TTC、限速合规性和舒适性上的均值更高；B10则在hard上NC及两个集合的舒适性上优于C0。因此，不能从综合分数排序推断C0是唯一更合适的后训练起点。既有后训练已固定B10作为初始化模型和冻结参考策略，C0/R0继续作为第三章的对照。

## 4. 不能由当前实验直接得出的结论

1. 不能将R0与C0的所有差异简化为“绝对轨迹与增量轨迹表示”的唯一因果效应，结论强度仍受训练随机性和单次训练的限制。
2. 不能根据单一seed声称R0或C0具有统计显著的全局优势。
3. C0与历史B10不是严格单因素训练实验，因此不能将二者差异全部归因于Hybrid Loss。

## 5. 对第三章的实质意义

完整Test14表明，轨迹表示方案不只影响开环轨迹误差，还会改变闭环中“推进性—安全性—可行性”的权衡。R0更强的路线推进性没有稳定转化为更高的综合闭环性能；C0相对R0呈现更均衡的系统级表现；B10则保留了方向合规、限速合规和舒适性等优势。后续安全约束后训练继续沿用已经固定的B10作为初始化与参考策略，不根据本轮测试集排序更换基础模型。这自然引出后续科学问题：如何在固定参考策略的基础上，利用奖励信号改善路线推进和任务性能，同时保持安全、舒适性以及基础闭环能力。
