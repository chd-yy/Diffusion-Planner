## 1. 实验目的

在既有本地重训Diffusion Planner和历史B10完整Test14结果的基础上补齐C0和R0，形成四模型系统级闭环比较：

| 对比 | 回答的问题 |
|---|---|
| DP vs B10 | 完整HDP系统相对原始DP的总体变化 |
| C0 vs B10 | 无Hybrid与历史Hybrid配方的系统级差异 |
| C0 vs R0 | Delta与Abs轨迹表示的闭环推进性、安全性和可行性权衡 |
| validation-1000 vs Test14 | 开环误差及运动学代理是否转化为闭环性能 |

## 4. 闭环协议

- simulation：`closed_loop_nonreactive_agents`；
- 推理seed：0；
- 单simulation worker，避免NuPlan MetricsEngine并发污染；
- 每40场景一个分片；
- 每片完成后校验runner和aggregator场景集合并归档；
- 关闭`simulation_log_callback`，避免保存大体积仿真历史；
- 支持按已归档分片断点续跑；
- DP和B10既有结果必须先通过相同manifest的完整集合门禁。

## 5. 结果角色

Test14作为第三章主要系统级闭环定量证据；已有safety40不删除，继续作为车辆交互碰撞案例和开发阶段安全诊断证据。Test14不能消除单训练seed、单推理seed、非反应式交通参与者等边界。

1. DP、B10、C0统一比较score、route progress、NC、DA、TTC和comfort；
2. C0/B10属于历史准消融，不能把全部差异严格归因于Hybrid Loss；
3. DP/B10仍是系统级比较，不能归因于单个模块；
4. 10月06日时的R0不完整结果不参与任何正式比较，也不用于支持或否定轨迹表示的闭环结论。
5. 10月07日完成的R0 hard 272/272和random 261/261可用于完整C0/R0配对比较，但应标记为后续补充分析，且不将单训练seed、单推理seed的均值差异扩大为统计显著性结论。
