## 4. 自动评价协议

训练完成后，后台任务将自动完成：

1. 查找唯一Epoch10 checkpoint、`args.json`和初始化报告；
2. 再次执行C0/C2完整初始化SHA门禁；
3. 在validation-1000上评价C0、历史B10、C2；
4. 每个模型3次、公共随机数、seed=3407、10步扩散、noise scale=0.1；
5. 输出1/3/5/8秒ADE/FDE、heading与运动学描述量；
6. 使用C2 checkpoint重新执行256场景梯度审计，确认训练后实际梯度比例。

固定safety40暂不自动启动。只有开环结果确认C2至少具有信息增益后，再进入闭环安全门禁，避免无依据扩展仿真预算。

## 7. 判定规则

- 若C2改善5～8秒ADE/FDE，且1秒误差没有明显恶化，则进入safety40；
- 若C2只改善训练loss而不改善独立开环，Hybrid继续降级为工程辅助项；
- 若C2开环改善但safety40出现新增碰撞、DA/TTC退化，则不晋升为基础模型；
- 无论结果正负，均保留梯度审计与严格初始化对照作为第三章阶段性成果。
