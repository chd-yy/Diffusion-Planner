# 第四章：F25任务保持资格单因素实验协议

> 协议固化时间：10月05日11时18分  
> 状态：10月05日15时07分validation-1000完成；route通过但有效组降至18.5%，方案拒绝  
> 性质：只读资格门实验，不更新模型参数

## 1. 科学问题

F25已使`D_s>=0.01`有效组达到41.3%，平均候选ADE仅相对B增加0.323%，且DA、collision、risk、TTC、progress和comfort均通过门禁；唯一失败项是Top-1 route cost相对B增加`1.76e-4`，超过`1e-4`容差。该结果表明，当前剩余问题不是候选数量或reward尺度，而是标量对齐reward仍允许路线质量被其他分量小幅补偿。

本实验检验：将route和progress从标量软目标提升为相对当前策略的不可补偿任务保持资格后，能否修复route退化，同时保留不少于40%的有效优势组。

## 2. 严格单因素设计

G组固定F25的以下全部条件：B10、validation-1000、seed 3407、200条池、`10/14/3/3/2`配额、质量空间压缩、NuPlan对齐reward、DA/risk/TTC/collision安全资格和全不安全组B式回退。唯一新增条件为逐锚点任务保持资格。

设B的32条组中最高对齐reward的安全候选为`tau_B*`，候选`tau_i`只有同时满足下式才可进入G的优势集合：

\[
C_{route}(\tau_i)\le C_{route}(\tau_B^*)+10^{-4},
\]

\[
R_{progress}(\tau_i)\ge R_{progress}(\tau_B^*)-0.005.
\]

该门只限制候选资格，不修改reward权重。若一个锚点没有任何满足任务保持资格的候选，则该组不产生回归目标，并复用B索引填充张量形状。

## 3. 预注册验收

G只有同时满足以下条件，才允许进入100步后训练：

1. 至少1条任务合格候选覆盖相对B下降不超过2个百分点；
2. 至少2条任务合格候选覆盖相对F25下降不超过3个百分点；
3. `D_s>=0.01`有效组不少于40%；
4. Top-1 route cost相对B增加不超过`1e-4`；
5. Top-1 progress guard相对B下降不超过0.005；
6. Top-1 DA和no-collision不下降；
7. risk不下降，TTC下降不超过0.01秒，comfort cost增加不超过`1e-4`；
8. 平均候选ADE相对B增加不超过1%。

所有门槛在完整运行前固定，不允许因route差值接近边界而事后放宽。
