# 第四章：任务保持优势权重屏蔽审计协议

> 协议固化时间：10月05日15时10分  
> 状态：10月05日15时19分validation-1000完成；组保留率通过、正优势质量保留失败  
> 性质：只读优势权重审计，不更新模型参数

## 1. 动机

F25已获得41.3%的质量空间有效组；将route/progress加入候选资格的G方案虽然修复route，却使有效组降至18.5%。这说明任务保持约束的内容正确，但作用位置过早。

本实验检验：保留F25完整DA安全集合计算组统计与优势，只在优势形成之后，将违反route/progress保持边界的正优势候选权重置零，能否既阻止错误方向更新，又保留大部分可学习组和优势质量。

## 2. H方案

对F25每个锚点：

1. 使用完整DA/risk/TTC/collision安全集合计算五维质量离散度`D_s`；
2. 仅当`D_s>=0.01`且至少2条安全候选时激活该组；
3. 在完整安全集合内计算对齐reward的组内标准化优势；
4. 仅保留正优势；
5. 对不满足下列任务保持条件的正优势权重置零：

\[
C_{route}(\tau_i)\le C_{route}(\tau_B^*)+10^{-4},
\]

\[
R_{progress}(\tau_i)\ge R_{progress}(\tau_B^*)-0.005.
\]

与G不同，违规候选仍参与安全组均值、方差和`D_s`计算，只是不产生正向回归梯度。

## 3. 预注册验收

H必须同时满足：

1. F25的413个有效组中，至少90%仍有不少于1条任务合规正优势候选；
2. 屏蔽后保留的正优势质量总和不少于屏蔽前的50%；
3. 所有最终非零更新权重100%满足route/progress保持条件；
4. F25原安全候选集合和`D_s`计算不变。

若通过，下一步才将独立`update_mask`接入Replay Buffer和`positive_advantage`损失，并执行单元测试与20步训练烟雾实验；若失败，则需要重构reward/约束，而不是继续训练。
