## 1. 当前最应该做的事

第三章最低实验闭环已经形成：基础模型身份、训练数据、开环误差和固定场景闭环结果均可复查。当前仍缺的不是更多“模型分数”，而是**能够把性能变化严格归因到具体设计的公平消融**。

现有完整 Test14 已经证明：在各自归档训练轨迹下，HDP B Epoch10 的系统级闭环结果优于本地重训的原始 Diffusion Planner。但是两者同时改变了 Decoder、token/输出组织、ego-only 与 joint prediction、状态归一化、初始化和实际学习率历程。因此，这组结果只能支撑“两个完整系统的观察性比较”，不能支撑“hybrid loss、增量表示或某一种扩散监督空间导致了提升”。

所以第三章应按以下顺序推进：

1. 冻结第三章的证据边界和可写结论；
2. 把现有系统级结果写入正文，但明确混杂因素；
3. 设计并最终完成一个**同架构、同数据、同初始化、同学习率，仅改变 loss 的最小公平消融**；
4. 在消融完成前，不把第三章包装成独立原创算法章，而将其定位为后续安全约束后训练的统一基础模型与实验载体。

其中第3项在中期前已完成历史B10准消融，但由于B10初始化与完整随机训练轨迹不可追溯，尚未达到严格单变量因果实验。中期检查应展示真实的准消融结果；最终论文若把hybrid监督列为独立方法贡献，仍需重新训练严格匹配的C1。

## 2. 第三章的科学定位

第三章回答的不是“扩散模型是否比所有规划器更好”，而是：

> 在统一的 nuPlan 场景编码和扩散规划架构下，轨迹表示、扩散监督与轨迹重建监督如何共同影响基础规划器的生成质量，并为后续奖励驱动和安全约束后训练提供稳定起点？

本章在整篇论文中的作用是建立固定参考策略 \(\pi_{\mathrm{B10}}\)。第四章研究如何利用轨迹级奖励改变该策略，第五章研究如何限制这种改变带来的安全风险与基础能力损失。因此，第三章是否“基础扎实、模型身份明确、训练过程可复查”，比强行声明新的扩散理论更重要。

### 2.1 当前可以提出但尚未完全验证的假设

- **H3-1：** 在同一 HDP 架构、数据和优化协议下，增量空间主监督与位置重建辅助监督的组合，能够改善长时域位置重建或闭环规划表现。
- **H3-2：** Encoder 解冻后的学习率会显著影响基础规划器的训练稳定性与闭环表现，训练 loss 不能代替闭环模型选择。
- **H3-3：** `x_start`、noise 和 diffusion-v 等参数化已经具备代码支持，但当前本地证据不足以判定哪一种普遍最优。

H3-1 是当前最值得补齐的受控实验；H3-2 已有初步小样本闭环证据；H3-3 不应在中期前扩展成昂贵的全交叉矩阵。

### 3.5 C0与历史B10配对开环结果

C0于09月18日06:46完成10轮训练。Epoch10 checkpoint包含完整model与EMA权重，校验状态为passed。C0记录的训练loss为0.003117，但由于C0总目标不包含位置辅助项，不能与历史B10的0.009062直接比较。

在1000个开发场景、3次扩散采样重复和公共随机数条件下，历史B10的1s ADE/FDE分别为0.102182/0.226291 m，低于C0的0.112250/0.249811 m；但C0的5s ADE/FDE为1.044908/2.408967 m，低于B10的1.073409/2.576265 m。8s全程ADE和终点FDE方面，C0分别为2.075229和5.364922 m，B10为2.194442和5.739802 m，即C0低5.75%和6.99%。C0总体heading MAE也低11.91%。

值得注意的是，B10在全程ADE和FDE上仍分别有51.40%和51.37%的配对观测低于C0，但其均值更差。这种“胜率略高、均值更差”的组合说明差异受到长时尾部样本影响，不能只报告平均值或单一改善比例。本结果不支持“位置重建辅助监督必然改善长时域平均误差”的原始假设；更准确的认识是，历史B10呈现短时误差优势，而C0呈现5～8秒平均误差和航向误差优势。

上述结果仍是历史对照准消融，无法排除B10的初始化、分叉和恢复训练影响，也不能由开环误差直接推导闭环性能。下一步应在固定40场景上配对比较C0与B10的综合score、路线进度、NC、DA、TTC和comfort。

分组score差值为：路口`+0.002898`、车辆交互`-0.055332`、行人及规则`+0.006314`、动态与环境`+0.000548`、基础能力`0`。车辆交互组下降主要由上述单一碰撞构成。鉴于样本量和单seed限制，不能推断某模型在一般车辆交互中稳定占优；但对安全约束研究而言，也不能用其余场景的平均小幅改善抵消一次严重安全回归。

开环与闭环组合后得到本章最关键的负结果：C0在5～8秒ADE/FDE均值和heading MAE上优于历史B10，却没有转化为更高闭环综合分，并产生一个新的责任碰撞。这支持“监督生成质量与闭环安全目标存在错位”，而不支持“更低开环误差自然带来更安全规划”。该证据自然引出后续安全候选门控、可行集合内优势估计和参考策略保持机制。

## 5. 最小公平消融设计

### 5.1 必做对照

| ID | 架构与表示 | diffusion参数化 | hybrid weight | detach | 唯一研究因素 |
|---|---|---|---:|---:|---|
| C0 | HDP；`[Δx,Δy,cosθ,sinθ]` | `x_start→x_start` | 0 | 0 | 无位置重建辅助项 |
| C1 | 历史B10；同一HDP架构与表示，但训练经历中断恢复 | `x_start→x_start` | 0.01 | 0 | 已有历史模型；训练前完整初始化hash不可追溯 |

严格因果实验原本要求两组统一：

- 同一训练/验证 manifest 和数据顺序；
- 同一 Encoder warm-start 权重；
- 同一随机初始化状态，或从完全相同、尚未接受 hybrid 训练的 checkpoint 出发；
- 同一 Encoder 冻结/解冻时点；
- 同一实际学习率序列、optimizer、scheduler、batch size、训练 epoch 和 EMA；
- 同一数据增强和推理配置；
- 逐 epoch 记录真实 optimizer LR，不能只记录命令行基础值。

当前决定采用历史B10后，初始化身份和完整随机训练轨迹无法统一，因此结果只作为准消融。它比“不同架构DP与B10系统比较”更接近目标因素，但证据强度低于重新训练的新C1；结果分析必须同时列出历史B10的Epoch4分叉、Epoch10恢复和缺少初始化hash等限制。

### 5.2 评价指标

实验结果应按三层报告：

1. **训练层：** 主扩散 loss、位置重建项、总 loss、学习率和梯度/非有限值统计；不同定义的 total loss 不直接横向解释。
2. **开环层：** ADE、FDE、1/3/5/8秒分时域位置误差、heading误差；补充位移、加速度、jerk、曲率等描述量，但不把描述量称作硬动力学保证。
3. **闭环层：** score、route progress、NC、DA、TTC、comfort和逐场差值。后续恢复测评时先使用已锁定的40场景开发集进行同场景配对；既有完整 Test14 继续作为历史系统证据，不因新消融反复调参。

### 5.3 成功与失败均可形成的结论

- 若历史B10在长时域误差和闭环进度上优于C0，只能写为“观察结果支持位置重建辅助监督可能缓解累积误差”，不能写成单因素因果证明。
- 若只降低训练 loss 而闭环无改善，应写成监督目标与闭环质量仍存在偏差，这将进一步支撑第四章的研究动机。
- 若 C1 改善开环但损害闭环安全或舒适性，应分析 loss 尺度和轨迹平滑/激进程度，而不是只报告平均总分。
- 若 C0/C1 无明显差异，应把 hybrid 降级为工程实现选择，不把它列为博士论文创新；第三章仍可作为完整研究平台和统一基础模型章节。

## 7. 可直接进入正文的结果分析草稿

在完整 Test14 nonreactive 闭环评测中，HDP B Epoch10 在 hard 与 random 集合上分别取得0.705304和0.824270的综合得分，高于本地重训 Diffusion Planner 的0.602691和0.689908。B10在路线进度、无责任碰撞、可行驶区域、TTC和舒适性指标上均呈现更高的集合均值，说明该模型能够作为后续后训练研究的有效基础策略。

需要强调的是，上述比较反映的是两个归档系统在各自实际训练轨迹下的总体差异，而不是单一方法因素的因果效应。审计发现，两者的实际学习率序列未完全对齐，同时还存在解码结构、预测对象、归一化和初始化等差异。因此，本章不将综合得分差异直接归因于增量表示或hybrid loss。为验证位置重建辅助监督的独立作用，后续采用统一HDP架构、数据、初始化和优化协议，仅比较hybrid权重为0与0.01的受控实验，并同时报告分时域开环误差和配对闭环指标。

学习率分叉实验进一步表明，监督训练过程中的优化设置会影响闭环模型质量。从同一Epoch4 checkpoint出发，恒定`5e-5`分支在固定20场景上的综合得分比`5e-4`分支高0.055198，差异主要来自路线进度。但该实验规模较小，现阶段只支持“优化协议是不可忽略的混杂因素”，不支持`5e-5`在一般条件下必然最优。该结果也说明，训练loss、开环误差与闭环驾驶质量需要分别评估，不能相互替代。

进一步的C0/历史B10准消融把这一认识扩展到了开环—闭环目标错位。C0在validation-1000的5～8秒ADE/FDE均值上更低，但在safety40上因一个新增责任碰撞使综合score从B10的0.896331降至0.884712。与此同时，C0的route progress、TTC和comfort均值略有提高。该组合说明，连续平均指标的改善无法排除低频但高代价的离散安全失败；安全项也不应只作为可与进度线性抵消的普通标量奖励。这一负结果构成后续安全约束后训练章节的直接实验动机。
