这个项目是 ICLR 2025 的自动驾驶规划模型 **Diffusion Planner** 官方实现，围绕 nuPlan 数据集和 nuPlan devkit 构建。整体可以按“数据处理 -> 模型训练 -> 闭环仿真”三条线理解。

**项目结构**

`README.md`  
项目说明、环境安装、训练和仿真命令入口。建议先读这里。

`data_process.py`  
离线数据预处理入口。它用 nuPlan scenario builder 读取场景，然后调用 `DataProcessor` 把 ego、周车、静态物体、地图 lane、route lane、未来轨迹整理成 `.npz` 训练样本。

`diffusion_planner/data_process/`  
数据处理核心：
- `data_processor.py`：训练预处理和仿真时 observation adapter 的主流程
- `agent_process.py`：周车历史和未来处理
- `ego_process.py`：自车历史、未来、当前状态处理
- `map_process.py`：矢量地图/lane/route 特征处理
- `roadblock_utils.py`：route roadblock 修正

`train_predictor.py`  
训练入口。负责解析参数、加载数据集、构建 `Diffusion_Planner`、DDP、EMA、optimizer、scheduler，然后循环调用训练 epoch。

`diffusion_planner/utils/`  
训练工具和数据加载：
- `dataset.py`：读取预处理后的 `.npz`
- `normalizer.py`：输入和轨迹归一化
- `data_augmentation.py`：训练时状态扰动
- `ddp.py`：分布式训练辅助
- `train_utils.py`：保存/恢复模型等

`diffusion_planner/model/`  
模型主体：
- `diffusion_planner.py`：顶层模型，组合 encoder 和 decoder
- `module/encoder.py`：编码 agent、static object、lane，再做融合 attention
- `module/decoder.py`：扩散解码器，训练时预测 score/x_start，推理时采样未来轨迹
- `module/dit.py`：DiT block 结构
- `diffusion_utils/`：SDE、DPM-Solver 采样逻辑
- `guidance/`：classifier guidance 相关逻辑

`diffusion_planner/loss.py`  
扩散训练 loss。把 ego 和 neighbor future 拼成轨迹，加噪后让模型恢复 `x_start` 或预测 score。

`diffusion_planner/train_epoch.py`  
单 epoch 训练逻辑：组 batch、数据增强、归一化、调用 diffusion loss、反传、EMA 更新。

`diffusion_planner/planner/planner.py`  
nuPlan 闭环仿真入口。它实现 `AbstractPlanner`，把 nuPlan 的 `PlannerInput` 转成模型输入，再把模型输出的轨迹转成 `InterpolatedTrajectory`。

`diffusion_planner/config/`  
Hydra 配置，主要用于 nuPlan simulation：
- `planner/diffusion_planner.yaml`
- `planner/diffusion_planner_guidance.yaml`
- `scenario_filter/*.yaml`

根目录脚本：
- `data_process.sh`：跑预处理
- `torch_run.sh`：跑训练
- `sim_diffusion_planner_runner.sh`：跑闭环仿真
- `sim_guidance_demo.sh`：跑 guidance demo

1. 先读 [README.md](E:/yanjun/Diffusion-Planner/README.md)  
   了解这个项目解决什么问题、依赖 nuPlan 的哪些流程、训练和评估怎么跑。

2. 再读 [data_process.py](E:/yanjun/Diffusion-Planner/data_process.py)，然后看 [data_processor.py](E:/yanjun/Diffusion-Planner/diffusion_planner/data_process/data_processor.py)  
   这是理解输入数据格式的关键。先搞清楚模型吃什么：ego 当前状态、周车历史、静态物体、lanes、route lanes，以及 ego/neighbor future ground truth。

3. 接着读 [dataset.py](E:/yanjun/Diffusion-Planner/diffusion_planner/utils/dataset.py) 和 [train_epoch.py](E:/yanjun/Diffusion-Planner/diffusion_planner/train_epoch.py)  
   这一步能把“预处理后的 npz”如何进入训练 batch 串起来。

4. 然后读 [loss.py](E:/yanjun/Diffusion-Planner/diffusion_planner/loss.py)  
   这里是扩散训练目标的核心：当前状态 + 未来轨迹归一化，加噪，通过模型恢复未来轨迹。

5. 再读模型主干：  
   [diffusion_planner.py](E:/yanjun/Diffusion-Planner/diffusion_planner/model/diffusion_planner.py) -> [encoder.py](E:/yanjun/Diffusion-Planner/diffusion_planner/model/module/encoder.py) -> [decoder.py](E:/yanjun/Diffusion-Planner/diffusion_planner/model/module/decoder.py) -> `dit.py`。

6. 最后读 [planner.py](E:/yanjun/Diffusion-Planner/diffusion_planner/planner/planner.py)  
   这部分解释训练好的模型如何接入 nuPlan 闭环仿真，并把预测轨迹转换成 nuPlan 可执行的 trajectory。

一句话主线：  
`nuPlan scenario -> DataProcessor -> .npz -> Dataset/DataLoader -> Diffusion_Planner encoder/decoder -> diffusion loss -> checkpoint -> DiffusionPlanner(AbstractPlanner) -> nuPlan closed-loop simulation`

如果你只是想快速上手代码，建议从 `train_predictor.py` 和 `diffusion_planner/model/module/decoder.py` 开始；如果你想改数据或接自己的数据集，优先看 `data_process/data_processor.py`。
