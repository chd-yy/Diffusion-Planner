# `MixerBlock` 代码原理：面向初学者的完整讲解

## 0. 这段代码要解决什么问题？

这段代码实现了一个 **MLP-Mixer 风格的基础模块**：`MixerBlock`。

它接收一个三维张量：

$$
x\in\mathbb{R}^{B\times T\times C}
$$

其中：

| 符号 | 含义 | 示例 |
|---|---|---|
| $B$ | batch size，一次送入网络的样本数量 | 一次处理 $32$ 张图片 |
| $T$ | token 数量 | 一张图片被切成 $196$ 个小块 |
| $C$ | 每个 token 的特征维度，也叫通道数 | 每个小块用 $768$ 个数字表示 |

模块会依次完成两件事：

1. **Token Mixing**：让不同 token 之间交换信息；
2. **Channel Mixing**：让同一个 token 内部的不同通道交换信息。

整个过程不会改变张量形状。输入和输出均为：

$$
[B,T,C]
$$

---

## 1. 完整代码

```python
import torch.nn as nn
from timm.models.layers import Mlp

class MixerBlock(nn.Module):
    def __init__(self, tokens_mlp_dim, channels_mlp_dim, drop_path_rate):
        super().__init__()

        self.norm1 = nn.LayerNorm(channels_mlp_dim)
        self.channels_mlp = Mlp(in_features=channels_mlp_dim, hidden_features=channels_mlp_dim, act_layer=nn.GELU, drop=drop_path_rate)
        self.norm2 = nn.LayerNorm(channels_mlp_dim)
        self.tokens_mlp = Mlp(in_features=tokens_mlp_dim, hidden_features=tokens_mlp_dim, act_layer=nn.GELU, drop=drop_path_rate)
        
    def forward(self, x):
        y = self.norm1(x)
        y = y.permute(0, 2, 1)
        y = self.tokens_mlp(y)
        y = y.permute(0, 2, 1)
        x = x + y
        y = self.norm2(x)
        return x + self.channels_mlp(y)
```

# 2. 先理解三个核心概念

## 2.1 什么是 token？

`token` 可以理解为一个基本信息单元。

在图像任务中，一张图片通常会被切成多个小块。每个小块可以视为一个 token。

例如，一张 $224\times224$ 的图片被切成 $16\times16$ 的小块，则每行和每列均有：

$$
\frac{224}{16}=14
$$

因此，一张图片一共有：

$$
T=14\times14=196
$$

个 token。

在轨迹规划任务中，token 也可能表示：

- 某个时间步；
- 某辆车；
- 某个道路节点；
- 某个时空单元格；
- 某段历史轨迹。

具体含义由上游网络如何组织输入决定。

---

## 2.2 什么是 channel？

每个 token 通常不是一个单独的数字，而是一个特征向量。

例如，一个 token 可以表示为：

$$
\boldsymbol{x}_i=
\begin{bmatrix}
x_{i,1}\\
x_{i,2}\\
\vdots\\
x_{i,C}
\end{bmatrix}
$$

这里，$C$ 就是通道数或特征维度。

如果：

$$
C=768
$$

说明每个 token 使用 $768$ 个数字描述。

---

## 2.3 什么是 MLP？

MLP 是 **Multi-Layer Perceptron** 的缩写，中文通常叫多层感知机。

一个常见的两层 MLP 可以写成：

$$
\operatorname{MLP}(z)=W_2\,\phi(W_1z+b_1)+b_2
$$

其中：

- $W_1$ 和 $W_2$ 是需要训练的权重矩阵；
- $b_1$ 和 $b_2$ 是需要训练的偏置；
- $\phi(\cdot)$ 是非线性激活函数；
- 当前代码使用 GELU 作为激活函数。

在这段代码中，MLP 的输入维度与输出维度保持一致，因此不会改变张量形状。

---

# 3. 为什么要分别做 Token Mixing 和 Channel Mixing？

考虑一个形状为：

$$
[B,T,C]
$$

的输入张量。

对于单个样本，可以将它想象成一个矩阵：

$$
X=
\begin{bmatrix}
\text{token}_1\\
\text{token}_2\\
\vdots\\
\text{token}_T
\end{bmatrix}
\in\mathbb{R}^{T\times C}
$$

其中：

- 每一行对应一个 token；
- 每一列对应一个通道。

仅仅对每一行独立处理，无法让不同 token 交换信息。

仅仅对每一列独立处理，也无法充分组合单个 token 内部的不同特征。

因此，`MixerBlock` 分成两步：

| 阶段 | 信息混合方向 | 解决的问题 |
|---|---|---|
| Token Mixing | 沿 token 维度 $T$ 混合 | 让不同 token 交流 |
| Channel Mixing | 沿通道维度 $C$ 混合 | 让单个 token 内部的不同特征交流 |

# 4. 类定义逐行解释

## 4.1 定义模块

```python
class MixerBlock(nn.Module):
```

`MixerBlock` 继承自：

```python
nn.Module
```

在 PyTorch 中，自定义神经网络模块通常都要继承 `nn.Module`。

这样，PyTorch 才能自动管理：

- 可训练参数；
- 梯度；
- 模型保存与加载；
- CPU 和 GPU 之间的迁移；
- 训练模式与推理模式。

---

## 4.2 初始化函数

```python
def __init__(self, tokens_mlp_dim, channels_mlp_dim, drop_path_rate):
```

三个输入参数分别表示：

| 参数 | 含义 | 对应维度 |
|---|---|---|
| `tokens_mlp_dim` | token 数量 | $T$ |
| `channels_mlp_dim` | 每个 token 的通道数 | $C$ |
| `drop_path_rate` | 传入 `Mlp` 的 dropout 概率 | 通常在 $[0,1)$ 内 |

需要特别注意：变量名 `drop_path_rate` 容易产生误解。

当前代码并没有显式使用 `DropPath` 或 stochastic depth。它只是将该数值传给：

```python
drop=drop_path_rate
```

因此，在当前代码中，它实际控制的是 `Mlp` 内部的 **Dropout** 概率。

---

## 4.3 调用父类初始化

```python
super().__init__()
```

这行代码用于初始化 `nn.Module` 的内部功能。

自定义 PyTorch 模块时，通常都需要保留这一行。

---

## 4.4 第一个 LayerNorm

```python
self.norm1 = nn.LayerNorm(channels_mlp_dim)
```

如果输入形状为：

$$
[B,T,C]
$$

那么：

```python
nn.LayerNorm(C)
```

会沿最后一个维度 $C$ 做归一化。

对于第 $b$ 个样本、第 $i$ 个 token，LayerNorm 会计算该 token 的通道均值：

$$
\mu_{b,i}=\frac{1}{C}\sum_{j=1}^{C}x_{b,i,j}
$$

以及方差：

$$
\operatorname{Var}_{b,i}=\frac{1}{C}\sum_{j=1}^{C}(x_{b,i,j}-\mu_{b,i})^2
$$

然后归一化：

$$
\hat{x}_{b,i,j}=\frac{x_{b,i,j}-\mu_{b,i}}{\sqrt{\operatorname{Var}_{b,i}+\epsilon}}
$$

最后再使用可训练参数进行缩放和平移：

$$
y_{b,i,j}=\gamma_j\hat{x}_{b,i,j}+\beta_j
$$

LayerNorm 的作用是让特征数值更加稳定，从而改善训练过程。

---

## 4.5 通道混合 MLP

```python
self.channels_mlp = Mlp(
    in_features=channels_mlp_dim,
    hidden_features=channels_mlp_dim,
    act_layer=nn.GELU,
    drop=drop_path_rate
)
```

这个 MLP 处理最后一个维度：

$$
C
$$

因此，它会对每个 token 独立地执行特征变换。

如果输入为：

$$
[B,T,C]
$$

则输出仍为：

$$
[B,T,C]
$$

对于每个 token，其计算可写成：

$$
\operatorname{ChannelMLP}(z)=W_{c,2}\,\operatorname{GELU}(W_{c,1}z+b_{c,1})+b_{c,2}
$$

因为：

$$
W_{c,1},W_{c,2}\in\mathbb{R}^{C\times C}
$$

所以它会混合一个 token 内部的不同通道。

---

## 4.6 第二个 LayerNorm

```python
self.norm2 = nn.LayerNorm(channels_mlp_dim)
```

这个 LayerNorm 用在 Channel Mixing 之前。

它的输入和输出形状仍然为：

$$
[B,T,C]
$$

---

## 4.7 Token 混合 MLP

```python
self.tokens_mlp = Mlp(
    in_features=tokens_mlp_dim,
    hidden_features=tokens_mlp_dim,
    act_layer=nn.GELU,
    drop=drop_path_rate
)
```

这个 MLP 的输入维度是：

$$
T
$$

但原始输入张量的最后一个维度是：

$$
C
$$

为了让 `tokens_mlp` 沿 token 维度工作，必须在前向传播中先交换维度。

这就是代码中两次 `permute(0, 2, 1)` 的原因。

---

# 5. 前向传播过程逐行解释

完整的前向传播函数为：

```python
def forward(self, x):
    y = self.norm1(x)
    y = y.permute(0, 2, 1)
    y = self.tokens_mlp(y)
    y = y.permute(0, 2, 1)
    x = x + y
    y = self.norm2(x)
    return x + self.channels_mlp(y)
```

下面逐行分析。

---

## 5.1 输入张量

```python
x
```

假设：

$$
x\in\mathbb{R}^{B\times T\times C}
$$

例如：

$$
B=2,\quad T=4,\quad C=3
$$

那么张量形状为：

$$
[2,4,3]
$$

---

## 5.2 第一次归一化

```python
y = self.norm1(x)
```

形状变化：

$$
[B,T,C]\longrightarrow[B,T,C]
$$

形状不变，只是数值被归一化。

---

## 5.3 交换 token 维度和通道维度

```python
y = y.permute(0, 2, 1)
```

`permute(0, 2, 1)` 表示：

- 原来的第 $0$ 维仍然放在第 $0$ 位；
- 原来的第 $2$ 维移动到第 $1$ 位；
- 原来的第 $1$ 维移动到第 $2$ 位。

因此：

$$
[B,T,C]\longrightarrow[B,C,T]
$$

为什么必须交换？

因为 PyTorch 中的全连接层通常沿最后一个维度计算。

交换后，最后一个维度变成：

$$
T
$$

于是 `tokens_mlp` 就可以沿 token 维度进行混合。

---

## 5.4 执行 Token Mixing

```python
y = self.tokens_mlp(y)
```

此时：

$$
y\in\mathbb{R}^{B\times C\times T}
$$

`tokens_mlp` 会处理最后一个维度 $T$。

对于固定的样本 $b$ 和固定的通道 $c$，它会取出：

$$
\begin{bmatrix}
y_{b,c,1}\\
y_{b,c,2}\\
\vdots\\
y_{b,c,T}
\end{bmatrix}
$$

然后通过 MLP 将不同 token 的值组合起来。

因此，每个 token 都能够获得其他 token 的信息。

形状保持不变：

$$
[B,C,T]\longrightarrow[B,C,T]
$$

---

## 5.5 将维度交换回去

```python
y = y.permute(0, 2, 1)
```

形状变化：

$$
[B,C,T]\longrightarrow[B,T,C]
$$

这样，张量重新回到后续模块习惯使用的格式。

---

## 5.6 第一次残差连接

```python
x = x + y
```

这里把 Token Mixing 的结果加回原始输入。

可以写成：

$$
X^{(1)}=X+\operatorname{TokenMixing}(\operatorname{LayerNorm}_1(X))
$$

残差连接的核心思想是：

> 新模块不需要从零重建全部特征，只需要学习“在原始特征基础上应该增加什么修正量”。

它通常可以：

- 保留原始信息；
- 缓解深层网络中的梯度消失；
- 提高训练稳定性；
- 让网络更容易优化。

---

## 5.7 第二次归一化

```python
y = self.norm2(x)
```

形状保持不变：

$$
[B,T,C]\longrightarrow[B,T,C]
$$

这一步为后面的 Channel Mixing 做准备。

---

## 5.8 执行 Channel Mixing 并添加残差连接

```python
return x + self.channels_mlp(y)
```

`channels_mlp` 直接沿最后一个维度 $C$ 计算。

因此，不需要再次 `permute()`。

对每个 token 来说，它会取出一个长度为 $C$ 的特征向量：

$$
\begin{bmatrix}
x_{b,i,1}\\
x_{b,i,2}\\
\vdots\\
x_{b,i,C}
\end{bmatrix}
$$

然后混合这些通道特征。

最终计算为：

$$
X^{(2)}=X^{(1)}+\operatorname{ChannelMixing}(\operatorname{LayerNorm}_2(X^{(1)}))
$$

输出形状为：

$$
[B,T,C]
$$

---

# 6. 用一张形状变化表看完整流程

| 步骤 | 对应代码 | 输入形状 | 输出形状 | 作用 |
|---|---|---|---|---|
| 输入 | `x` | $[B,T,C]$ | $[B,T,C]$ | 接收 token 特征 |
| 第一次归一化 | `y = self.norm1(x)` | $[B,T,C]$ | $[B,T,C]$ | 稳定数值 |
| 第一次置换 | `y = y.permute(0, 2, 1)` | $[B,T,C]$ | $[B,C,T]$ | 将 token 维度移到末尾 |
| Token Mixing | `y = self.tokens_mlp(y)` | $[B,C,T]$ | $[B,C,T]$ | 混合不同 token |
| 第二次置换 | `y = y.permute(0, 2, 1)` | $[B,C,T]$ | $[B,T,C]$ | 恢复原顺序 |
| 第一次残差 | `x = x + y` | $[B,T,C]$ | $[B,T,C]$ | 保留原特征并添加修正量 |
| 第二次归一化 | `y = self.norm2(x)` | $[B,T,C]$ | $[B,T,C]$ | 稳定数值 |
| Channel Mixing | `self.channels_mlp(y)` | $[B,T,C]$ | $[B,T,C]$ | 混合每个 token 内部的通道 |
| 第二次残差 | `x + self.channels_mlp(y)` | $[B,T,C]$ | $[B,T,C]$ | 输出最终特征 |

# 7. 用数学公式概括整个模块

设输入为：

$$
X\in\mathbb{R}^{B\times T\times C}
$$

定义维度置换操作：

$$
P:[B,T,C]\longrightarrow[B,C,T]
$$

则 Token Mixing 阶段可以写成：

$$
X^{(1)}=X+P^{-1}\left(\operatorname{TokenMLP}\left(P\left(\operatorname{LN}_1(X)\right)\right)\right)
$$

然后，Channel Mixing 阶段为：

$$
X^{(2)}=X^{(1)}+\operatorname{ChannelMLP}\left(\operatorname{LN}_2(X^{(1)})\right)
$$

最终输出为：

$$
\boxed{\operatorname{MixerBlock}(X)=X^{(2)}}
$$

# 8. 用一个直观类比理解

可以把输入张量想象成一个班级：

- 一共有 $T$ 个学生；
- 每个学生掌握 $C$ 门课程的知识；
- 一次处理 $B$ 个班级。

## Token Mixing

Token Mixing 类似于：

> 对于每一门课程，让所有学生互相交流。

例如，在数学这一列中，学生 $1$、学生 $2$、学生 $3$ 彼此分享信息。

它强调的是：

$$
\text{不同 token 之间的关系}
$$

## Channel Mixing

Channel Mixing 类似于：

> 对于每一个学生，将他掌握的数学、语文、英语等不同课程知识进行综合。

它强调的是：

$$
\text{同一个 token 内部不同特征之间的关系}
$$

两步结合后，既能让学生之间交流，也能让每个学生内部整合知识。

# 9. 为什么不像 Transformer 那样使用注意力？

Transformer 常使用自注意力机制：

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\mathsf{T}}{\sqrt{d}}\right)V
$$

自注意力会根据输入内容，动态计算 token 之间的关系。

而当前 `MixerBlock` 不使用注意力矩阵。它直接使用一个 MLP 在 token 维度上混合信息。

可以粗略比较为：

| 方法 | token 之间如何交互 | 特点 |
|---|---|---|
| Transformer | 使用注意力权重动态交互 | 灵活，但实现更复杂 |
| MLP-Mixer | 使用固定形状的 MLP 进行混合 | 结构直观，计算流程简单 |

这里的“固定”不是说参数永远不变，而是说：训练结束后，token 混合方式由 MLP 权重决定；它不像注意力机制那样针对每个输入显式生成一张新的注意力矩阵。

# 10. GELU 和 Dropout 是什么？

## 10.1 GELU 激活函数

代码中写了：

```python
act_layer=nn.GELU
```

GELU 是一种非线性激活函数。

如果没有激活函数，多层线性层叠加后仍然等价于一个线性变换，模型表达能力会受限。

GELU 的常见定义为：

$$
\operatorname{GELU}(x)=x\Phi(x)
$$

其中，$\Phi(x)$ 是标准正态分布的累积分布函数。

初学阶段只需要记住：

> GELU 为网络加入非线性，使模型能够学习更复杂的规律。

---

## 10.2 Dropout

代码中写了：

```python
drop=drop_path_rate
```

Dropout 会在训练阶段随机将一部分神经元输出置零。

如果 dropout 概率为 $p$，则每个元素大约有 $p$ 的概率被随机丢弃。

它的作用通常是：

- 减少过拟合；
- 提高模型泛化能力。

在推理阶段，Dropout 通常会自动关闭。

---

# 11. 为什么 `tokens_mlp_dim` 必须与 token 数量一致？

`tokens_mlp` 定义为：

```python
self.tokens_mlp = Mlp(in_features=tokens_mlp_dim, ...)
```

在执行它之前，张量被转为：

$$
[B,C,T]
$$

由于 MLP 会读取最后一个维度，所以必须满足：

$$
\boxed{\texttt{tokens\_mlp\_dim}=T}
$$

否则，全连接层输入维度不匹配，程序会报错。

例如：

```python
block = MixerBlock(
    tokens_mlp_dim=196,
    channels_mlp_dim=768,
    drop_path_rate=0.1
)
```

那么输入必须满足：

$$
x\in\mathbb{R}^{B\times196\times768}
$$

---

# 12. 为什么 `channels_mlp_dim` 必须与通道数一致？

`LayerNorm` 和 `channels_mlp` 都要求最后一个维度等于：

```python
channels_mlp_dim
```

因此必须满足：

$$
\boxed{\texttt{channels\_mlp\_dim}=C}
$$

如果 `channels_mlp_dim=768`，则输入最后一个维度必须为 $768$。

假设创建模块：

```python
block = MixerBlock(

)
```

输入：

```python
x.shape == (2, 4, 3)
```

即：

$$

$$

那么前向传播时：

```text
x                    : [2, 4, 3]

norm2(x)             : [2, 4, 3]
channels_mlp(...)    : [2, 4, 3]
最终输出              : [2, 4, 3]
```

输入输出形状完全一致。

# 14. MLP 内部的参数大致是什么形状？

当前代码将隐藏层维度设置为输入维度本身。

## 14.1 Token MLP

```python
Mlp(
    in_features=T,
    hidden_features=T
)
```

在常见实现中，它包含两层线性层：

$$
T\longrightarrow T\longrightarrow T
$$

对应权重矩阵形状大致为：

$$
W_{t,1}\in\mathbb{R}^{T\times T}
$$

$$
W_{t,2}\in\mathbb{R}^{T\times T}
$$

## 14.2 Channel MLP

```python
Mlp(
    in_features=C,
    hidden_features=C
)
```

其结构为：

$$
C\longrightarrow C\longrightarrow C
$$

对应权重矩阵形状大致为：

$$
W_{c,1}\in\mathbb{R}^{C\times C}
$$

$$
W_{c,2}\in\mathbb{R}^{C\times C}
$$

# 15. 参数量如何估算？

在常见的 `Mlp` 默认设置下，每个 MLP 通常包含两层带偏置的线性层。

## 15.1 Token MLP 参数量

$$
2T^2+2T
$$

## 15.2 Channel MLP 参数量

$$
2C^2+2C
$$

## 15.3 两个 LayerNorm 参数量

每个 LayerNorm 通常包含缩放参数和偏移参数，共：

$$
2C
$$

两个 LayerNorm 共：

$$
4C
$$

## 15.4 总参数量

因此，整个模块的参数量大约为：

$$
\boxed{2T^2+2T+2C^2+6C}
$$

这里没有计入 Dropout，因为 Dropout 没有可训练参数。

注意：精确参数量仍取决于当前环境中 `timm.models.layers.Mlp` 的具体实现和默认参数。

# 16. 这段代码的设计特点

## 16.1 使用 Pre-Norm 结构

Token Mixing 前先做：

```python
y = self.norm1(x)
```

Channel Mixing 前也先做：

```python
y = self.norm2(x)
```

这种结构称为 Pre-Norm：

$$
X+F(\operatorname{LN}(X))
$$

它通常比先残差再归一化的结构更容易训练深层网络。

---

## 16.2 两次残差连接

该模块中存在两次残差连接：

$$
X^{(1)}=X+F_{\text{token}}(X)
$$

$$
X^{(2)}=X^{(1)}+F_{\text{channel}}(X^{(1)})
$$

这使得 Token Mixing 和 Channel Mixing 都只需要学习修正量。

---

## 16.3 Token Mixing 对 token 数量敏感

由于 `tokens_mlp` 的输入维度固定为 $T$，该模块通常要求 token 数量保持固定。

例如，模型按照：

$$
T=196
$$

构造后，一般不能直接输入：

$$
T=256
$$

否则 MLP 的输入维度会不匹配。

这是 MLP-Mixer 与某些更灵活结构之间的重要区别。

# 17. 容易产生的误解

## 17.1 `channels_mlp` 为什么定义在 `tokens_mlp` 前面，却后执行？

初始化函数中：

```python
self.channels_mlp = ...
self.tokens_mlp = ...
```

但在 `forward()` 中，先执行：

```python
y = self.tokens_mlp(y)
```

后执行：

```python
self.channels_mlp(y)
```

这没有问题。

模块定义顺序不等于执行顺序。真正的计算顺序由 `forward()` 决定。

---

## 17.2 `drop_path_rate` 是 DropPath 吗？

在当前代码中不是。

因为它被传给：

```python
drop=drop_path_rate
```

所以实际控制的是 `Mlp` 内部的 Dropout。

如果确实要使用 DropPath，通常还需要额外创建专门的 DropPath 模块。

---

## 17.3 为什么 Channel Mixing 不需要 `permute()`？

因为输入张量原本就是：

$$
[B,T,C]
$$

最后一维已经是通道维度 $C$。

全连接层默认沿最后一个维度计算，所以可以直接使用 `channels_mlp`。

---

## 17.4 为什么 Token Mixing 需要两次 `permute()`？

原始输入最后一维是 $C$，但 Token MLP 要处理 $T$。

因此先交换：

$$
[B,T,C]\longrightarrow[B,C,T]
$$

完成 Token Mixing 后，再恢复：

$$
[B,C,T]\longrightarrow[B,T,C]
$$

---

## 17.5 这段代码有注意力机制吗？

没有。

代码中没有：

- Query；
- Key；
- Value；
- softmax 注意力矩阵；
- 多头注意力。

它只使用 LayerNorm、MLP、维度置换和残差连接。

# 18. 如何自己运行一个最小示例？

需要先安装 PyTorch 和 `timm`。

```python
import torch
import torch.nn as nn
from timm.models.layers import Mlp

class MixerBlock(nn.Module):
    def __init__(self, tokens_mlp_dim, channels_mlp_dim, drop_path_rate):
        super().__init__()
        self.norm1 = nn.LayerNorm(channels_mlp_dim)
        self.channels_mlp = Mlp(
            in_features=channels_mlp_dim,
            hidden_features=channels_mlp_dim,
            act_layer=nn.GELU,
            drop=drop_path_rate
        )
        self.norm2 = nn.LayerNorm(channels_mlp_dim)
        self.tokens_mlp = Mlp(
            in_features=tokens_mlp_dim,
            hidden_features=tokens_mlp_dim,
            act_layer=nn.GELU,
            drop=drop_path_rate
        )

    def forward(self, x):
        y = self.norm1(x)
        y = y.permute(0, 2, 1)
        y = self.tokens_mlp(y)
        y = y.permute(0, 2, 1)
        x = x + y
        y = self.norm2(x)
        return x + self.channels_mlp(y)

block = MixerBlock(
    tokens_mlp_dim=4,
    channels_mlp_dim=3,
    drop_path_rate=0.1
)

x = torch.randn(2, 4, 3)
y = block(x)

print("输入形状：", x.shape)
print("输出形状：", y.shape)
```

预期输出：

```text
输入形状： torch.Size([2, 4, 3])
输出形状： torch.Size([2, 4, 3])
```

# 19. 如何调试维度错误？

在 `forward()` 中临时加入：

```python
def forward(self, x):
    print("input:", x.shape)

    y = self.norm1(x)
    print("after norm1:", y.shape)

    y = y.permute(0, 2, 1)
    print("after first permute:", y.shape)

    y = self.tokens_mlp(y)
    print("after tokens_mlp:", y.shape)

    y = y.permute(0, 2, 1)
    print("after second permute:", y.shape)

    x = x + y
    print("after token residual:", x.shape)

    y = self.norm2(x)
    print("after norm2:", y.shape)

    out = x + self.channels_mlp(y)
    print("output:", out.shape)

    return out
```

若在 `tokens_mlp` 处报错，优先检查：

$$
T=\texttt{tokens\_mlp\_dim}
$$

若在 `LayerNorm` 或 `channels_mlp` 处报错，优先检查：

$$
C=\texttt{channels\_mlp\_dim}
$$

# 20. 一段高度概括的伪代码

```text
输入 x，形状为 [B, T, C]

对 x 做 LayerNorm
交换 T 和 C 的位置，得到 [B, C, T]
沿 T 维执行 MLP，让 token 之间交换信息
交换回来，得到 [B, T, C]
与原始 x 相加，形成第一次残差连接

再次做 LayerNorm
沿 C 维执行 MLP，让每个 token 内部的特征交换信息
与上一阶段结果相加，形成第二次残差连接

输出 [B, T, C]
```

# 21. 最终总结

这段代码的本质可以概括为：

$$
\boxed{\text{先在 token 维度混合信息，再在 channel 维度混合信息}}
$$

完整公式为：

$$
X^{(1)}=X+P^{-1}\left(\operatorname{TokenMLP}\left(P\left(\operatorname{LN}_1(X)\right)\right)\right)
$$

$$
X^{(2)}=X^{(1)}+\operatorname{ChannelMLP}\left(\operatorname{LN}_2(X^{(1)})\right)
$$

其中：

- `LayerNorm` 用于稳定特征分布；
- `permute()` 用于将 token 维度移动到 MLP 能够处理的位置；
- `tokens_mlp` 负责 token 之间的信息交互；
- `channels_mlp` 负责单个 token 内部不同通道之间的信息交互；
- 两次残差连接用于保留原始信息并提升训练稳定性；
- 输入与输出形状保持不变，均为 $[B,T,C]$。
