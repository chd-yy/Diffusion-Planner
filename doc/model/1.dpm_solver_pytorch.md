# diffusion_planner/model/diffusion_utils/dpm_solver_pytorch.py 详解

本文档解释 `diffusion_planner/model/diffusion_utils/dpm_solver_pytorch.py` 的代码结构、类、函数、变量、输入输出数据结构和调用关系。

这个文件实现的是 DPM-Solver / DPM-Solver++ 采样器。它不参与训练 loss 的反向传播，主要用于推理阶段从噪声轨迹中快速求解出干净轨迹。

## 3. 核心概念

### 3.1 VP 扩散过程

`NoiseScheduleVP` 表示 VP 类型的前向扩散过程。

前向过程可以写成：

```text
x_t = alpha_t * x_0 + sigma_t * noise
```

其中：

```text
x_0      干净数据
x_t      t 时刻的带噪数据
alpha_t  信号系数
sigma_t  噪声系数
noise    标准高斯噪声
```

VP 过程满足：

```text
alpha_t^2 + sigma_t^2 = 1
```

### 3.2 lambda_t

代码中大量使用：

```text
lambda_t = log(alpha_t) - log(sigma_t)
```
![alt text](image-1.png)

DPM-Solver 的很多更新公式不是直接在时间 `t` 上均匀前进，而是在 `lambda` 空间里计算步长：

```text
h = lambda_t - lambda_s
```

这里：

```text
s -> 当前时间
t -> 目标时间
```

反向采样通常是从噪声大的时间走向噪声小的时间。

### 3.3 DPM-Solver 与 DPM-Solver++

`DPM_Solver` 支持两种算法形式：

```text
algorithm_type == "dpmsolver"
    更新公式使用 noise prediction，也就是 epsilon。

algorithm_type == "dpmsolver++"
    更新公式使用 data prediction，也就是 x_0。
```

本项目默认使用：

```text
algorithm_type="dpmsolver++"
```

原因是 `dpmsolver++` 通常适合使用数据预测形式的采样，并且项目中的 `DiT` 支持 `model_type="x_start"`。

## 4. NoiseScheduleVP

```python
class NoiseScheduleVP:
```

### 4.1 类作用

`NoiseScheduleVP` 封装 VP 扩散噪声调度。

它统一提供：

```text
log(alpha_t)
alpha_t
sigma_t
lambda_t
inverse_lambda(lambda_t)
```

后续 `DPM_Solver` 所有采样公式都依赖它。

### 4.2 支持的 schedule

```text
schedule="discrete"
    适用于离散 DDPM 训练步。
    通过 betas 或 alphas_cumprod 构造 log_alpha_array。
    再用 interpolate_fn 在连续时间上插值。

schedule="linear"
    适用于连续时间 VPSDE。
    beta(t) 在 continuous_beta_0 和 continuous_beta_1 之间线性变化。
```

本项目在 `sampling.py` 中使用：

```python
NoiseScheduleVP(schedule='linear')
```

## 5. NoiseScheduleVP.__init__

```python
def __init__(
    self,
    schedule='discrete',
    betas=None,
    alphas_cumprod=None,
    continuous_beta_0=0.1,
    continuous_beta_1=20.,
    dtype=torch.float32,

```

### 5.1 函数作用

初始化噪声调度器。

根据 `schedule` 的不同，构造离散时间插值表，或者保存连续线性 beta 参数。

### 5.2 输入数据结构

#### `schedule`

```text

```

```text
"discrete"
"linear"
```

#### `betas`

类型：

```text
Optional[torch.Tensor]
```

形状：

```text
[N]
```

含义：

```text
离散 DDPM 每一步的 beta 值
```

只在 `schedule="discrete"` 时使用。

#### `alphas_cumprod`

类型：

```text
Optional[torch.Tensor]
```

形状：

```text
[N]
```

含义：

```text
DDPM 中的 alpha_bar 累乘值
```

如果没有传 `betas`，必须传 `alphas_cumprod`。

#### `continuous_beta_0`

类型：

```text
float
```

连续线性 VP SDE 的最小 beta。

#### `continuous_beta_1`

类型：

```text
float
```

连续线性 VP SDE 的最大 beta。

#### `dtype`

类型：

```text
torch.dtype
```

用于保存离散插值表的 dtype。

### 5.3 输出

构造函数没有返回值。

它会设置成员变量：

```text
self.schedule
self.T
self.total_N
self.log_alpha_array
self.t_array
self.beta_0
self.beta_1
```

### 5.4 离散分支步骤

当：

```python
schedule == "discrete"
```

步骤如下：

1. 如果传入 `betas`：

```python
log_alphas = 0.5 * torch.log(1 - betas).cumsum(dim=0)
```

含义：

```text
alpha_bar_n = cumprod(1 - beta_n)
alpha_t = sqrt(alpha_bar_n)
log(alpha_t) = 0.5 * log(alpha_bar_n)
```

2. 如果没有传 `betas`，则使用 `alphas_cumprod`：

```python
log_alphas = 0.5 * torch.log(alphas_cumprod)
```

3. 设置：

```python
self.T = 1.
```

4. 调用：

```python
self.log_alpha_array = self.numerical_clip_alpha(log_alphas)
```

用于裁剪数值不稳定的末端点。

5. 保存离散时间表：

```python
self.t_array = torch.linspace(0., 1., self.total_N + 1)[1:]
```

形状：

```text
[1, total_N]
```

离散步 `i` 映射到连续时间：

```text
t_i = (i + 1) / N
```

### 5.5 连续 linear 分支步骤

当：

```python
schedule == "linear"
```

直接设置：

```python
self.T = 1.
self.total_N = 1000
self.beta_0 = continuous_beta_0
self.beta_1 = continuous_beta_1
```

这里 `total_N=1000` 主要用于默认 `t_end = 1 / total_N`。

## 6. NoiseScheduleVP.numerical_clip_alpha

```python
def numerical_clip_alpha(self, log_alphas, clipped_lambda=-5.1):
```

### 6.1 函数作用

对离散噪声表中的末端 `log_alpha` 做裁剪，避免极低 logSNR 区域造成数值不稳定。

### 6.2 输入数据结构

```text
log_alphas -> torch.Tensor, shape [N]
clipped_lambda -> float
```

`log_alphas` 表示每个离散时间步的 `log(alpha_t)`。

### 6.3 输出数据结构

```text
torch.Tensor, shape [N']，N' <= N
```

如果末端不稳定，会截掉最后若干个点。

### 6.4 步骤解释

1. 根据 VP 关系计算：

```python
log_sigmas = 0.5 * torch.log(1. - torch.exp(2. * log_alphas))
```

2. 计算 half-logSNR：

```python
lambs = log_alphas - log_sigmas
```

3. 在反转后的 `lambs` 中查找低于阈值的位置：

```python
idx = torch.searchsorted(torch.flip(lambs, [0]), clipped_lambda)
```

4. 如果需要裁剪：

```python
log_alphas = log_alphas[:-idx]
```

5. 返回裁剪后的 `log_alphas`。

## 7. NoiseScheduleVP.marginal_log_mean_coeff

```python
def marginal_log_mean_coeff(self, t):
```

### 7.1 函数作用

计算：

```text
log(alpha_t)
```

这是计算 `alpha_t`、`sigma_t`、`lambda_t` 的基础。

### 7.2 输入数据结构

```text
t -> torch.Tensor, shape [B] 或 [N]
```

时间值位于：

```text
[0, self.T]
```

### 7.3 输出数据结构

```text
torch.Tensor, shape [B] 或 [N]
```

每个时间点对应一个 `log(alpha_t)`。

### 7.4 分支逻辑

#### discrete

```python
interpolate_fn(t.reshape((-1, 1)), self.t_array, self.log_alpha_array)
```

用预先保存的离散关键点对 `log(alpha_t)` 做分段线性插值。

#### linear

```python
return -0.25 * t ** 2 * (self.beta_1 - self.beta_0) - 0.5 * t * self.beta_0
```

这是线性 beta VP SDE 的解析积分：

```text
log(alpha_t) = -0.5 * integral_0^t beta(s) ds
```

其中：

```text
beta(t) = beta_0 + t * (beta_1 - beta_0)
```

## 9. NoiseScheduleVP.marginal_std

```python
def marginal_std(self, t):
```

### 9.1 函数作用

计算：

```text
sigma_t = sqrt(1 - alpha_t^2)
```

### 9.2 输入

```text
t -> torch.Tensor, shape [B] 或 [N]
```

### 9.3 输出

```text
sigma_t -> torch.Tensor, shape [B] 或 [N]
```

### 9.4 实现

```python
return torch.sqrt(1. - torch.exp(2. * self.marginal_log_mean_coeff(t)))
```

因为：

```text
exp(2 * log(alpha_t)) = alpha_t^2
```

## 10. NoiseScheduleVP.marginal_lambda

```python
def marginal_lambda(self, t):
```

### 10.1 函数作用

计算 half-logSNR：

```text
lambda_t = log(alpha_t) - log(sigma_t)
```

### 10.2 输入

```text
t -> torch.Tensor, shape [B] 或 [N]
```

### 10.3 输出

```text
lambda_t -> torch.Tensor, shape [B] 或 [N]
```

### 10.4 步骤

```python
log_mean_coeff = self.marginal_log_mean_coeff(t)
log_std = 0.5 * torch.log(1. - torch.exp(2. * log_mean_coeff))
return log_mean_coeff - log_std
```

## 11. NoiseScheduleVP.inverse_lambda

```python
def inverse_lambda(self, lamb):
```

### 11.1 函数作用

把 `lambda_t` 反解回时间 `t`。

很多采样策略在 `lambda` 空间均匀取点，然后需要通过这个函数回到真实时间。

### 11.2 输入

```text
lamb -> torch.Tensor, shape [B] 或 [N]
```

### 11.3 输出

```text
t -> torch.Tensor, shape [B] 或 [N]
```

### 11.4 linear 分支

对于连续线性 VP SDE，使用解析反解：

```python
tmp = 2. * (beta_1 - beta_0) * logaddexp(-2 * lamb, 0)
Delta = beta_0**2 + tmp
t = tmp / (sqrt(Delta) + beta_0) / (beta_1 - beta_0)
```

其中 `torch.logaddexp` 用来稳定计算：

```text
log(1 + exp(-2 * lambda))
```

### 11.5 discrete 分支

离散分支没有解析公式，步骤是：

1. 根据 `lambda` 恢复 `log_alpha`：

```python
log_alpha = -0.5 * torch.logaddexp(0, -2 * lamb)
```

2. 翻转 `log_alpha_array` 和 `t_array`。

3. 调用 `interpolate_fn()` 反插值得到 `t`。

## 14. model_wrapper.noise_pred_fn

```python
def noise_pred_fn(x, t_continuous, cond=None):
```

### 14.1 函数作用

调用底层模型，并把模型输出转换成噪声预测 `epsilon`。

### 14.2 输入

```text
x -> torch.Tensor, shape 与采样状态一致
t_continuous -> torch.Tensor, shape [B]
cond -> Optional[torch.Tensor 或其他条件对象]
```

在本项目推理中，`x` 通常来自：

```text
xT 或中间 xt -> [B, P, (1 + future_len) * 4]
```

其中：

```text
B -> batch size
P -> 1 + predicted_neighbor_num
```

### 14.3 输出

```text
noise -> torch.Tensor, shape 与 x 相同
```

### 14.4 步骤

1. 转换时间：

```python
t_input = get_model_input_time(t_continuous)
```

2. 调用模型：

```python
output = model(x, t_input, **model_kwargs)
```

或有条件时：

```python
output = model(x, t_input, cond, **model_kwargs)
```

3. 根据 `model_type` 转成 noise。

#### `model_type == "noise"`

```python
return output
```

模型输出本身就是噪声。

#### `model_type == "x_start"`

```python
alpha_t = noise_schedule.marginal_alpha(t_continuous)
sigma_t = noise_schedule.marginal_std(t_continuous)
return (x - alpha_t * output) / sigma_t
```

来自：

```text
x_t = alpha_t * x_0 + sigma_t * epsilon
epsilon = (x_t - alpha_t * x_0) / sigma_t
```

其中 `output` 是模型预测的 `x_0`。

#### `model_type == "v"`

```python
return alpha_t * output + sigma_t * x
```

这是 velocity parameterization 到 noise 的转换。

#### `model_type == "score"`

```python
return -sigma_t * output
```

因为：

```text
epsilon = -sigma_t * score
```

## 15. model_wrapper.cond_grad_fn

```python
def cond_grad_fn(x, t_input):
```

### 15.1 函数作用

用于 classifier guidance。

它计算：

```text
grad_x log p(condition | x_t)
```

也就是条件打分函数对当前样本 `x_t` 的梯度。

### 15.2 输入

```text
x -> torch.Tensor, shape 与采样状态一致
t_input -> torch.Tensor, shape [B]
```

### 15.3 输出

```text
cond_grad -> torch.Tensor, shape 与 x 相同
```

### 15.4 步骤

1. 开启梯度：

```python
with torch.enable_grad():
```

2. 从原计算图分离当前 `x`，只对当前 `x_t` 求梯度：

```python
x_in = x.detach().requires_grad_(True)
```

3. 调用 classifier：

```python
log_prob = classifier_fn(x_in, t_input, condition, **classifier_kwargs)
```

4. 对 `log_prob.sum()` 求关于 `x_in` 的梯度：

```python
return torch.autograd.grad(log_prob.sum(), x_in)[0]
```

## 16. model_wrapper.model_fn

```python
def model_fn(x, t_continuous):
```

### 16.1 函数作用

这是 `model_wrapper()` 返回给 `DPM_Solver` 的统一模型接口。

不管底层模型是什么参数化方式、是否使用 guidance，最终都返回：

```text
predicted_noise
```

### 16.2 输入

```text
x -> torch.Tensor, shape 与采样状态一致
t_continuous -> torch.Tensor, shape [B]
```

### 16.3 输出

```text
noise -> torch.Tensor, shape 与 x 相同
```

### 16.4 guidance 分支

#### `guidance_type == "uncond"`

```python
return noise_pred_fn(x, t_continuous)
```

本项目没有 guidance 时走这个分支。

#### `guidance_type == "classifier"`

```python
cond_grad = cond_grad_fn(x, t_input)
sigma_t = noise_schedule.marginal_std(t_continuous)
noise = noise_pred_fn(x, t_continuous)
return noise - guidance_scale * sigma_t * cond_grad
```

本项目如果 `self._guidance_fn is not None`，会走这个分支。

#### `guidance_type == "classifier-free"`

分别计算无条件和有条件 noise：

```python
noise_uncond = noise_pred_fn(..., cond=unconditional_condition)
noise = noise_pred_fn(..., cond=condition)
return noise_uncond + guidance_scale * (noise - noise_uncond)
```

当前项目默认没有使用 classifier-free guidance。

## 17. DPM_Solver

```python
class DPM_Solver:
```

### 17.1 类作用

`DPM_Solver` 负责沿扩散 ODE 反向积分。

输入是高噪声状态：

```text
x_T
```

输出是低噪声或干净状态：

```text
x_0 或 x_{t_end}
```

## 19. DPM_Solver.dynamic_thresholding_fn

```python
def dynamic_thresholding_fn(self, x0, t):
```

### 19.1 函数作用

对模型预测的 `x0` 做动态阈值裁剪。

这主要用于图像像素空间扩散模型，避免大 guidance scale 下预测值爆炸。

本项目轨迹采样通常不启用这个功能。

### 19.2 输入

```text
x0 -> torch.Tensor, shape [B, ...]
t -> torch.Tensor, shape [B] 或 [1]
```

### 19.3 输出

```text
x0 -> torch.Tensor, shape 与输入 x0 相同
```

### 19.4 步骤

1. 对每个 batch 样本展开所有维度：

```python
torch.abs(x0).reshape((x0.shape[0], -1))
```

2. 取分位数：

```python
s = torch.quantile(..., p, dim=1)
```

3. 保证阈值至少为 `thresholding_max_val`：

```python
s = max(s, thresholding_max_val)
```

4. 裁剪并缩放：

```python
x0 = torch.clamp(x0, -s, s) / s
```

## 21. DPM_Solver.data_prediction_fn

```python
def data_prediction_fn(self, x, t):
```

### 21.1 函数作用

把 noise prediction 转换为 data prediction：

```text
x_0 prediction
```

然后可选应用 `correcting_x0_fn`。

### 21.2 输入

```text
x -> torch.Tensor, shape [B, ...]
t -> torch.Tensor, shape [1] 或 [B]
```

### 21.3 输出

```text
x0 -> torch.Tensor, shape 与 x 相同
```

### 21.4 步骤

1. 预测噪声：

```python
noise = self.noise_prediction_fn(x, t)
```

2. 计算：

```python
alpha_t = noise_schedule.marginal_alpha(t)
sigma_t = noise_schedule.marginal_std(t)
```

3. 根据前向公式反解：

```text
x_t = alpha_t * x_0 + sigma_t * noise
x_0 = (x_t - sigma_t * noise) / alpha_t
```

代码：

```python
x0 = (x - sigma_t * noise) / alpha_t
```

4. 如果有 `correcting_x0_fn`，应用修正：

```python
x0 = self.correcting_x0_fn(x0, t)
```

## 23. DPM_Solver.get_time_steps

```python
def get_time_steps(self, skip_type, t_T, t_0, N, device):
```

### 23.1 函数作用

生成从采样起点 `t_T` 到终点 `t_0` 的 `N + 1` 个时间节点。

`N` 个区间对应 `N` 次采样更新。

### 23.2 输入

```text
skip_type -> str
t_T -> float
t_0 -> float
N -> int
device -> torch.device
```

### 23.3 输出

```text
timesteps -> torch.Tensor, shape [N + 1]
```

### 23.4 skip_type 分支

#### `skip_type == "logSNR"`

先在 `lambda` 空间均匀取点：

```python
logSNR_steps = torch.linspace(lambda_T, lambda_0, N + 1)
```

再反解回时间：

```python
return noise_schedule.inverse_lambda(logSNR_steps)
```

本项目默认使用这个。

#### `skip_type == "time_uniform"`

直接在时间 `t` 上均匀取点：

```python
return torch.linspace(t_T, t_0, N + 1)
```

#### `skip_type == "time_quadratic"`

在 `sqrt(t)` 空间均匀，然后平方：

```python
t = torch.linspace(t_T**0.5, t_0**0.5, N + 1).pow(2)
```

## 24. DPM_Solver.get_orders_and_timesteps_for_singlestep_solver

```python
def get_orders_and_timesteps_for_singlestep_solver(self, steps, order, skip_type, t_T, t_0, device):
```

### 24.1 函数作用

为 `method="singlestep"` 分配每个外层区间使用的求解阶数。

例如总 NFE 是 10，最大阶数是 3，就需要把 10 次模型调用组合成若干个一阶、二阶、三阶区间。

### 24.2 输入

```text
steps -> int，总模型评估次数 NFE
order -> int，最大阶数，1/2/3
skip_type -> str
t_T -> float
t_0 -> float
device -> torch.device
```

### 24.3 输出

```text
timesteps_outer -> torch.Tensor, shape [K + 1]
orders -> List[int], length K
```

其中 `orders[i]` 表示第 `i` 个外层区间用几阶求解器。

### 24.4 分配逻辑

#### order 3

优先使用三阶，余数补二阶或一阶：

```text
steps % 3 == 0 -> [..., 3, 2, 1]
steps % 3 == 1 -> [..., 3, 1]
steps % 3 == 2 -> [..., 3, 2]
```

#### order 2

优先使用二阶：

```text
steps 偶数 -> 全部二阶
steps 奇数 -> 若干二阶 + 一个一阶
```

#### order 1

全部一阶。

## 26. DPM_Solver.dpm_solver_first_update

```python
def dpm_solver_first_update(self, x, s, t, model_s=None, return_intermediate=False):
```

### 26.1 函数作用

一阶单步更新，从时间 `s` 更新到时间 `t`。

它等价于 DDIM 风格的一阶更新。

### 26.2 输入

```text
x -> torch.Tensor, shape [B, ...]，s 时刻状态
s -> torch.Tensor, shape [1]
t -> torch.Tensor, shape [1]
model_s -> Optional[torch.Tensor], shape 与 x 相同
return_intermediate -> bool
```

### 26.3 输出

如果 `return_intermediate=False`：

```text
x_t -> torch.Tensor, shape 与 x 相同
```

如果 `return_intermediate=True`：

```text
(x_t, {"model_s": model_s})
```

### 26.4 步骤

1. 计算：

```text
lambda_s, lambda_t
h = lambda_t - lambda_s
log_alpha_s, log_alpha_t
sigma_s, sigma_t
alpha_t
```

2. 如果 `algorithm_type == "dpmsolver++"`：

```python
model_s = x0 prediction
phi_1 = expm1(-h)
x_t = sigma_t / sigma_s * x - alpha_t * phi_1 * model_s
```

3. 如果 `algorithm_type == "dpmsolver"`：

```python
model_s = noise prediction
phi_1 = expm1(h)
x_t = exp(log_alpha_t - log_alpha_s) * x - sigma_t * phi_1 * model_s
```

## 27. DPM_Solver.singlestep_dpm_solver_second_update

```python
def singlestep_dpm_solver_second_update(
    self,
    x,
    s,
    t,
    r1=0.5,
    model_s=None,
    return_intermediate=False,
    solver_type='dpmsolver'
):
```

### 27.1 函数作用

二阶单步更新。

它在区间 `[s, t]` 中间增加一个节点 `s1`，用 `model_s1 - model_s` 估计模型沿时间的变化，从而获得二阶修正。

### 27.2 输入

```text
x -> torch.Tensor, shape [B, ...]
s -> torch.Tensor, shape [1]
t -> torch.Tensor, shape [1]
r1 -> float，中间节点在 lambda 区间的位置比例
model_s -> Optional[torch.Tensor], shape 与 x 相同
return_intermediate -> bool
solver_type -> "dpmsolver" 或 "taylor"
```

### 27.3 输出

如果 `return_intermediate=False`：

```text
x_t -> torch.Tensor, shape 与 x 相同
```

如果 `return_intermediate=True`：

```text
(x_t, {"model_s": model_s, "model_s1": model_s1})
```

### 27.4 步骤

1. 计算总 lambda 步长：

```python
h = lambda_t - lambda_s
```

2. 构造中间节点：

```python
lambda_s1 = lambda_s + r1 * h
s1 = inverse_lambda(lambda_s1)
```

3. 如果没有传 `model_s`，计算起点模型值：

```python
model_s = self.model_fn(x, s)
```

4. 用一阶公式预测中间状态 `x_s1`。

5. 在 `s1` 处重新评估模型：

```python
model_s1 = self.model_fn(x_s1, s1)
```

6. 根据 `solver_type` 使用 `dpmsolver` 或 `taylor` 的二阶系数更新到 `x_t`。

## 28. DPM_Solver.singlestep_dpm_solver_third_update

```python
def singlestep_dpm_solver_third_update(
    self,
    x,
    s,
    t,
    r1=1./3.,
    r2=2./3.,
    model_s=None,
    model_s1=None,
    return_intermediate=False,
    solver_type='dpmsolver'
):
```

### 28.1 函数作用

三阶单步更新。

它在区间 `[s, t]` 中构造两个中间节点 `s1` 和 `s2`，用多个模型值估计一阶和二阶变化。

### 28.2 输入

```text
x -> torch.Tensor, shape [B, ...]
s -> torch.Tensor, shape [1]
t -> torch.Tensor, shape [1]
r1 -> float，第一个中间节点比例
r2 -> float，第二个中间节点比例
model_s -> Optional[torch.Tensor]
model_s1 -> Optional[torch.Tensor]
return_intermediate -> bool
solver_type -> "dpmsolver" 或 "taylor"
```

### 28.3 输出

如果 `return_intermediate=False`：

```text
x_t -> torch.Tensor, shape 与 x 相同
```

如果 `return_intermediate=True`：

```text
(x_t, {"model_s": model_s, "model_s1": model_s1, "model_s2": model_s2})
```

### 28.4 步骤

1. 计算：

```text
h = lambda_t - lambda_s
lambda_s1 = lambda_s + r1 * h
lambda_s2 = lambda_s + r2 * h
s1 = inverse_lambda(lambda_s1)
s2 = inverse_lambda(lambda_s2)
```

2. 计算起点模型值 `model_s`。

3. 如果没有传 `model_s1`，先预测 `x_s1`，再计算 `model_s1`。

4. 用 `model_s` 和 `model_s1` 构造第二个中间状态 `x_s2`。

5. 计算：

```python
model_s2 = self.model_fn(x_s2, s2)
```

6. 根据 `solver_type`：

```text
dpmsolver -> 直接用 model_s2 - model_s 做高阶修正
taylor    -> 显式构造 D1 和 D2
```

7. 输出 `x_t`。

## 29. DPM_Solver.multistep_dpm_solver_second_update

```python
def multistep_dpm_solver_second_update(self, x, model_prev_list, t_prev_list, t, solver_type="dpmsolver"):
```

### 29.1 函数作用

二阶多步更新。

它复用前两个时间点已经计算过的模型值，不再额外计算中间节点。

### 29.2 输入

```text
x -> torch.Tensor, shape [B, ...]，当前状态
model_prev_list -> List[torch.Tensor]，至少两个历史模型值
t_prev_list -> List[torch.Tensor]，至少两个历史时间点
t -> torch.Tensor, shape [1]，目标时间
solver_type -> "dpmsolver" 或 "taylor"
```

### 29.3 输出

```text
x_t -> torch.Tensor, shape 与 x 相同
```

### 29.4 步骤

1. 取最近两个历史模型值：

```python
model_prev_1, model_prev_0 = model_prev_list[-2], model_prev_list[-1]
```

2. 取对应时间：

```python
t_prev_1, t_prev_0 = t_prev_list[-2], t_prev_list[-1]
```

3. 计算历史步长和当前步长：

```python
h_0 = lambda_prev_0 - lambda_prev_1
h = lambda_t - lambda_prev_0
r0 = h_0 / h
```

4. 构造一阶差分：

```python
D1_0 = (1. / r0) * (model_prev_0 - model_prev_1)
```

5. 根据 `algorithm_type` 和 `solver_type` 更新 `x_t`。

## 30. DPM_Solver.multistep_dpm_solver_third_update

```python
def multistep_dpm_solver_third_update(self, x, model_prev_list, t_prev_list, t, solver_type='dpmsolver'):
```

### 30.1 函数作用

三阶多步更新。

它复用最近三个时间点的模型值，构造一阶和二阶差分修正。

### 30.2 输入

```text
x -> torch.Tensor, shape [B, ...]
model_prev_list -> List[torch.Tensor]，长度 3
t_prev_list -> List[torch.Tensor]，长度 3
t -> torch.Tensor, shape [1]
solver_type -> str
```

### 30.3 输出

```text
x_t -> torch.Tensor, shape 与 x 相同
```

### 30.4 步骤

1. 取三个历史模型值：

```python
model_prev_2, model_prev_1, model_prev_0 = model_prev_list
```

2. 取三个历史时间：

```python
t_prev_2, t_prev_1, t_prev_0 = t_prev_list
```

3. 计算三段 lambda 步长：

```python
h_1 = lambda_prev_1 - lambda_prev_2
h_0 = lambda_prev_0 - lambda_prev_1
h = lambda_t - lambda_prev_0
r0, r1 = h_0 / h, h_1 / h
```

4. 构造差分：

```python
D1_0 = (1. / r0) * (model_prev_0 - model_prev_1)
D1_1 = (1. / r1) * (model_prev_1 - model_prev_2)
D1 = D1_0 + (r0 / (r0 + r1)) * (D1_0 - D1_1)
D2 = (1. / (r0 + r1)) * (D1_0 - D1_1)
```

5. 根据 `algorithm_type` 更新 `x_t`。

## 33. DPM_Solver.dpm_solver_adaptive

```python
def dpm_solver_adaptive(
    self,
    x,
    order,
    t_T,
    t_0,
    h_init=0.05,
    atol=0.0078,
    rtol=0.05,
    theta=0.9,
    t_err=1e-5,
    solver_type='dpmsolver'
):
```

### 33.1 函数作用

自适应步长求解器。

它通过低阶解和高阶解的差来估计局部误差，然后动态调整 lambda 空间步长。

### 33.2 输入

```text
x -> torch.Tensor, shape [B, ...]
order -> int，只支持 2 或 3
t_T -> float，起始时间
t_0 -> float，终止时间
h_init -> float，初始 lambda 步长
atol -> float，绝对误差容忍度
rtol -> float，相对误差容忍度
theta -> float，安全缩放因子
t_err -> float，终止时间误差阈值
solver_type -> str
```

### 33.3 输出

```text
x -> torch.Tensor, shape 与输入 x 相同
```

### 33.4 步骤

1. 初始化当前时间：

```python
s = t_T
lambda_s = marginal_lambda(s)
lambda_0 = marginal_lambda(t_0)
h = h_init
```

2. 根据 `order` 选择 embedded 低阶/高阶组合：

```text
order 2 -> 一阶 + 二阶
order 3 -> 二阶 + 三阶
```

3. 循环直到 `s` 接近 `t_0`：

```python
while abs(s - t_0) > t_err:
```

4. 提出候选下一步：

```python
t = inverse_lambda(lambda_s + h)
```

5. 分别计算低阶解和高阶解：

```python
x_lower
x_higher
```

6. 计算归一化误差：

```python
E = norm((x_higher - x_lower) / delta)
```

7. 如果 `E <= 1`，接受当前步。

8. 根据误差更新下一步步长：

```python
h = min(theta * h * E ** (-1 / order), lambda_0 - lambda_s)
```

### 33.5 注意

`sample()` 中如果 `return_intermediate=True`，不允许使用 `adaptive`，因为自适应步长的实际步数不是预先固定的。

## 34. DPM_Solver.add_noise

```python
def add_noise(self, x, t, noise=None):
```

### 34.1 函数作用

前向加噪工具。

计算：

```text
x_t = alpha_t * x + sigma_t * noise
```

### 34.2 输入

```text
x -> torch.Tensor, shape [B, ...]
t -> torch.Tensor, shape [M]
noise -> Optional[torch.Tensor]
```

如果 `noise` 为 `None`，会自动生成：

```text
noise -> [M, B, ...]
```

### 34.3 输出

如果 `M == 1`：

```text
xt -> torch.Tensor, shape [B, ...]
```

如果 `M > 1`：

```text
xt -> torch.Tensor, shape [M, B, ...]
```

### 34.4 步骤

1. 计算 `alpha_t`、`sigma_t`。
2. 如果没有噪声，随机生成。
3. 给 `x` 增加最前面的时间维。
4. 用 `expand_dims()` 广播 `alpha_t`、`sigma_t`。
5. 计算 `xt`。

## 36. DPM_Solver.sample

```python
def sample(
    self,
    x,
    steps=20,
    t_start=None,
    t_end=None,
    order=2,
    skip_type='time_uniform',
    method='multistep',
    lower_order_final=True,
    denoise_to_zero=False,
    solver_type='dpmsolver',
    atol=0.0078,
    rtol=0.05,
    return_intermediate=False,
):
```

### 36.1 函数作用

`DPM_Solver` 的主入口。

它从起始时间 `t_start` 的状态 `x` 出发，沿扩散 ODE 积分到 `t_end`。

在反向生成中：

```text
t_start 通常是 T
t_end 通常是 1 / total_N 或更小
```

### 36.2 输入

```text
x -> torch.Tensor, shape [B, ...]
steps -> int，模型评估次数或采样步数
t_start -> Optional[float]
t_end -> Optional[float]
order -> int, 1/2/3
skip_type -> "logSNR" | "time_uniform" | "time_quadratic"
method -> "singlestep" | "multistep" | "singlestep_fixed" | "adaptive"
lower_order_final -> bool
denoise_to_zero -> bool
solver_type -> "dpmsolver" | "taylor"
atol -> float
rtol -> float
return_intermediate -> bool
```

在本项目中，`x` 通常是：

```text
[B, P, (1 + future_len) * 4]
```

例如：

```text
B = batch size
P = 1 + predicted_neighbor_num
future_len = 80
x.shape = [B, P, 324]
```

因为：

```text
(1 + 80) * 4 = 324
```

其中第 0 个时间步是 current state，后面是 future 状态。

### 36.3 输出

如果 `return_intermediate=False`：

```text
x_end -> torch.Tensor, shape 与输入 x 相同
```

如果 `return_intermediate=True`：

```text
(x_end, intermediates)
```

其中：

```text
intermediates -> List[torch.Tensor]
```

### 36.4 初始化步骤

1. 设置默认终止时间：

```python
t_0 = 1. / total_N if t_end is None else t_end
```

2. 设置默认起始时间：

```python
t_T = T if t_start is None else t_start
```

3. 检查时间必须大于 0。

4. 初始化：

```python
device = x.device
intermediates = []
```

5. 在 `torch.no_grad()` 中执行采样。

### 36.5 method == "adaptive"

```python
x = self.dpm_solver_adaptive(...)
```

特点：

```text
忽略固定 steps
根据误差自适应调整步长
```

### 36.6 method == "multistep"

这是本项目默认使用的采样方式。

步骤：

1. 生成时间节点：

```python
timesteps = self.get_time_steps(skip_type, t_T, t_0, steps, device)
```

形状：

```text
[steps + 1]
```

2. 初始化第一帧模型值：

```python
t_prev_list = [timesteps[0]]
model_prev_list = [self.model_fn(x, timesteps[0])]
```

3. 如果存在 `correcting_xt_fn`，修正当前状态。

本项目中会强制：

```text
xt[:, :, 0, :] = current_states
```

4. 用低阶方法启动多步缓存：

```python
for step in range(1, order):
    x = self.multistep_dpm_solver_update(..., order=step)
```

例如 `order=2` 时，先做一次一阶更新。

5. 缓存足够后，用固定 `order` 的多步更新：

```python
for step in range(order, steps + 1):
    x = self.multistep_dpm_solver_update(..., order=step_order)
```

6. 如果 `lower_order_final=True` 且 `steps < 10`，末尾降低阶数以提升稳定性。

7. 维护滑动窗口：

```text
t_prev_list
model_prev_list
```

只保留最近 `order` 个历史值。

### 36.7 method == "singlestep"

步骤：

1. 调用：

```python
get_orders_and_timesteps_for_singlestep_solver(...)
```

获取每个外层区间的阶数。

2. 对每个外层区间：

```python
x = self.singlestep_dpm_solver_update(...)
```

特点：

```text
每个区间独立完成
不复用跨区间历史模型值
```

### 36.8 method == "singlestep_fixed"

固定每个外层区间都使用指定阶数：

```python
K = steps // order
orders = [order] * K
```

如果 `steps` 不能被 `order` 整除，剩余 NFE 会被舍弃。

### 36.9 denoise_to_zero

采样主体结束后，如果：

```python
denoise_to_zero=True
```

则执行：

```python
x = self.denoise_to_zero_fn(x, t)
```

本项目默认启用，所以最终会多一次 `x_0` 预测。

### 36.10 return_intermediate

如果：

```python
return_intermediate=True
```

返回：

```python
return x, intermediates
```

否则：

```python
return x
```

## 37. interpolate_fn

```python
def interpolate_fn(x, xp, yp):
```

### 37.1 函数作用

可微分的分段线性插值函数。

主要用于：

```text
discrete NoiseScheduleVP 中 t -> log_alpha
discrete NoiseScheduleVP 中 log_alpha -> t
```

### 37.2 输入

```text
x -> torch.Tensor, shape [N, C]
xp -> torch.Tensor, shape [C, K]
yp -> torch.Tensor, shape [C, K]
```

含义：

```text
x   查询点
xp  x 轴关键点
yp  y 轴关键点
```

DPM-Solver 中通常：

```text
C = 1
```

### 37.3 输出

```text
y -> torch.Tensor, shape [N, C]
```

### 37.4 步骤

1. 把查询点 `x` 和关键点 `xp` 拼在一起：

```python
all_x = torch.cat([x.unsqueeze(2), xp.unsqueeze(0).repeat((N, 1, 1))], dim=2)
```

2. 排序，找到每个查询点在关键点中的位置。

3. 根据位置确定左右端点索引。

4. 对边界外的查询点使用最外侧两个关键点做线性外推。

5. 从 `yp` 中 gather 左右端点值。

6. 应用线性插值公式：

```text
y = y0 + (x - x0) * (y1 - y0) / (x1 - x0)
```

### 37.5 输出含义

返回每个查询点对应的插值结果。

## 38. expand_dims

```python
def expand_dims(v, dims):
```

### 38.1 函数作用

把形状 `[N]` 的时间系数扩展成可广播形状：

```text
[N, 1, 1, ..., 1]
```

### 38.2 输入

```text
v -> torch.Tensor, shape [N]
dims -> int
```

### 38.3 输出

```text
torch.Tensor, shape [N, 1, 1, ..., 1]
```

总维度数等于 `dims`。

### 38.4 例子

如果：

```text
v.shape = [B]
dims = 3
```

则：

```text
expand_dims(v, 3).shape = [B, 1, 1]
```

这样可以和：

```text
x.shape = [B, P, D]
```

广播相乘。

代码：

```python
return v[(...,) + (None,) * (dims - 1)]
```

## 39. 本项目中的完整推理数据流

以 `Decoder.forward()` 推理分支为例。

### 39.1 构造初始噪声轨迹

```python
xT = torch.cat(
    [
        current_states[:, :, None],
        torch.randn(B, P, future_len, 4).to(current_states.device) * 0.5
    ],
    dim=2
).reshape(B, P, -1)
```

结构：

```text
xT -> [B, P, (1 + future_len) * 4]
```

其中：

```text
第 0 个时间步 -> current_states
后面 future_len 个时间步 -> 随机噪声
```

### 39.2 current state 约束

`decoder.py` 定义：

```python
def initial_state_constraint(xt, t, step):
    xt = xt.reshape(B, P, -1, 4)
    xt[:, :, 0, :] = current_states
    return xt.reshape(B, P, -1)
```

它通过：

```python
dpm_solver_params={
    "correcting_xt_fn": initial_state_constraint,
}
```

传给 `DPM_Solver`。

所以每一步采样后都会保证：

```text
轨迹第 0 帧始终等于当前状态
```

### 39.3 包装模型

```python
model_fn = model_wrapper(...)
```

把 `DiT.forward(x, t, cross_c, route_lanes, neighbor_current_mask)` 包装成：

```python
model_fn(x, t_continuous) -> noise
```

### 39.4 采样

```python
x0 = dpm_solver.sample(
    xT,

```

输出：

```text

```

### 39.5 反归一化并去掉 current

```python
x0 = self._state_normalizer.inverse(x0.reshape(B, P, -1, 4))[:, :, 1:]
```

得到：


字段：

```text
[x, y, cos_heading, sin_heading]
```

## 41. 阅读建议

如果只是为了理解本项目推理，建议按这个顺序看：

1. `sampling.py` 中的 `dpm_sampler()`。
2. `model_wrapper()` 如何把 `DiT` 包装成 noise prediction。
3. `DPM_Solver.sample()` 的 `method="multistep"` 分支。
4. `DPM_Solver.multistep_dpm_solver_update()`。
5. `DPM_Solver.multistep_dpm_solver_second_update()`。
6. `NoiseScheduleVP.marginal_alpha()`、`marginal_std()`、`marginal_lambda()`。

对于本项目，优先关注：

```text
NoiseScheduleVP(schedule="linear")
model_wrapper(model_type="x_start" 或 "score")
DPM_Solver(algorithm_type="dpmsolver++")
sample(method="multistep", order=2, skip_type="logSNR")
correcting_xt_fn=initial_state_constraint
```

其他分支如 `discrete`、`classifier-free`、`singlestep`、`adaptive`、`dynamic_thresholding` 是通用 DPM-Solver 实现保留的能力，不是当前默认训练/推理路径的核心。
