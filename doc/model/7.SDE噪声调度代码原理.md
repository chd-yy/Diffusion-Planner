> 本文解释一个扩散模型中的 SDE 工具文件。  
> 文件定义了一个抽象的随机微分方程接口，并实现了线性噪声调度下的 VP-SDE。  
> 此外，文件中还保留了一个尚未启用的指数调度 `subVPSDE_exp` 草稿。

# 1. 先用一句话概括这段代码

这段代码用于描述：

$$
\text{原始数据}
\longrightarrow
\text{逐渐加入噪声}
\longrightarrow
\text{接近高斯噪声}
$$

的连续时间过程。

它提供了以下能力：

1. 根据当前状态 $x$ 和时间 $t$，计算 SDE 的漂移项和扩散项；

3. 单独计算噪声标准差；
4. 为后续的扩散模型训练、采样和 DPM-Solver 提供噪声调度信息。

# 3. 什么是 SDE？

SDE 是 **Stochastic Differential Equation** 的缩写，中文叫作：

> 随机微分方程

一般形式为：

$$
\mathrm{d}x_t
=
f(x_t,t)\,\mathrm{d}t
+
g(t)\,\mathrm{d}W_t
$$

其中：

| 符号 | 含义 |
|---|---|
| $x_t$ | 时刻 $t$ 的样本 |
| $\mathrm{d}x_t$ | 极短时间内样本发生的变化 |
| $f(x_t,t)$ | 漂移项，决定确定性移动方向 |
| $g(t)$ | 扩散系数，决定噪声强度 |
| $\mathrm{d}W_t$ | 布朗运动增量，可理解为连续时间高斯噪声 |
| $\mathrm{d}t$ | 一个极短的时间间隔 |

---

## 3.1 漂移项是什么意思？

漂移项为：

$$
f(x_t,t)\,\mathrm{d}t
$$

它表示：

> 如果暂时忽略随机噪声，样本会朝哪个方向移动。

例如：

$$
f(x_t,t)=-x_t
$$

则：

$$
\mathrm{d}x_t=-x_t\,\mathrm{d}t
$$

如果当前：

$$
x_t=4
$$

则变化方向为负，样本向原点靠近。

如果当前：

$$
x_t=-4
$$

则变化方向为正，样本仍然向原点靠近。

---

## 3.2 扩散项是什么意思？

扩散项为：

$$
g(t)\,\mathrm{d}W_t
$$

布朗运动增量满足：

$$
\mathrm{d}W_t
\sim
\mathcal{N}(0,\mathrm{d}t)
$$

也可以直观地写成：

$$
\mathrm{d}W_t
=
\sqrt{\mathrm{d}t}\,\varepsilon
$$

其中：

$$
\varepsilon
\sim
\mathcal{N}(0,I)
$$

因此：

$$
g(t)\,\mathrm{d}W_t
=
g(t)\sqrt{\mathrm{d}t}\,\varepsilon
$$

表示每经过一个极短时间段，就会加入一小部分高斯噪声。

---

# 4. 扩散模型为什么需要 SDE？

扩散模型的前向过程会逐渐破坏原始数据。

例如，对于轨迹预测：

$$
x_0
=
\text{真实轨迹}
$$

随着时间增加：

$$
x_t
=
\text{带噪轨迹}
$$

最终：

$$
x_T
\approx
\text{高斯噪声}
$$

训练完成后，生成过程反过来进行：

$$
\text{高斯噪声}
\longrightarrow
\text{逐步去噪}
\longrightarrow
\text{合理轨迹}
$$

SDE 用连续时间方式描述前向加噪过程。

---

# 5. `STD_MIN = 1e-6` 是什么？

代码：

```python
STD_MIN = 1e-6
```

表示：

$$
\texttt{STD\_MIN}
=
10^{-6}
$$

它是一个很小的正数。

在扩散过程接近：

$$
t=0
$$

时，噪声标准差通常趋近于：

$$
0
$$

如果后续计算出现：

$$
\frac{1}{\sigma_t}
$$

或者：

$$
\log\sigma_t
$$

那么：

$$
\sigma_t=0
$$

会导致除零或无穷大。

因此，可以设置下限：

$$
\sigma_t
\leftarrow
\max(\sigma_t,10^{-6})
$$

当前文件中，`STD_MIN` 只在尚未启用的：

在线性 VP-SDE 中：

$$

$$

# 6. 什么是抽象基类？

代码：

```python
class SDE(abc.ABC):
```

表示 `SDE` 是一个抽象基类。

可以将它理解为：

> 一份接口说明书。

它规定：任何具体的 SDE 子类都必须提供哪些方法。

但是，`SDE` 自己并不描述某一种具体噪声过程。

---

## 6.1 为什么需要抽象基类？

不同扩散模型可以使用不同 SDE：

- VP-SDE；
- VE-SDE；
- sub-VP-SDE；
- 其他自定义 SDE。

虽然数学形式不同，但后续训练和采样代码通常都需要调用类似的方法：

```python
sde.sde(x, t)
sde.marginal_prob(x, t)
sde.diffusion_coeff(t)
sde.marginal_prob_std(t)
```

使用抽象基类后，后续模块只需要依赖统一接口，不必了解具体实现。

---

## 6.2 `abc.ABC` 是什么？

代码：

```python
import abc

class SDE(abc.ABC):
```

其中：

- `abc` 是 Python 标准库；
- `ABC` 是 Abstract Base Class 的缩写；
- 中文叫作抽象基类。

---

## 6.3 `@abc.abstractmethod` 是什么？

例如：

```python
@abc.abstractmethod
def sde(self, x, t):
    pass
```

它表示：

> 子类必须实现 `sde(...)` 方法。

如果某个子类没有实现所有抽象方法，就不能正常实例化。

---

## 6.4 `@property` 是什么？

代码：

```python
@property
@abc.abstractmethod
def T(self):
    pass
```

外部访问时写成：

```python
sde.T
```

而不是：

```python
sde.T()
```

`T` 表示扩散过程的终止时间。

# 7. `SDE` 抽象基类中的四个核心接口

---

## 7.1 `T`

代码：

```python
@property
@abc.abstractmethod
def T(self):
    pass
```

作用：

> 返回 SDE 的终止时间。

例如，后续线性 VP-SDE 中：

```python
@property
def T(self):
    return 1.0
```

表示时间范围为：

$$
t\in[0,1]
$$

---

## 7.2 `sde(x,t)`

代码：

```python
@abc.abstractmethod
def sde(self, x, t):
    pass
```

作用：

> 返回当前状态和当前时间对应的漂移系数与扩散系数。

一般形式：

$$
\mathrm{d}x_t
=
f(x_t,t)\,\mathrm{d}t
+
g(t)\,\mathrm{d}W_t
$$

返回：

$$
\left(
f(x_t,t),
g(t)
\right)
$$

---

## 7.3 `marginal_prob(x,t)`

代码：

```python
@abc.abstractmethod
def marginal_prob(self, x, t):
    pass
```

作用：

> 给定初始样本 $x_0$ 和时间 $t$，直接计算 $x_t$ 的条件分布参数。

对于常见高斯形式：

$$
x_t
=
\alpha_t x_0
+
\sigma_t\varepsilon
$$

其中：

$$
\varepsilon\sim\mathcal{N}(0,I)
$$

对应分布为：

$$
q(x_t\mid x_0)
=
\mathcal{N}
\left(
x_t;
\alpha_t x_0,
\sigma_t^2I
\right)
$$

该函数返回：

$$
\text{mean}
=
\alpha_t x_0
$$

以及：

$$
\text{std}
=
\sigma_t
$$

---

## 7.4 `diffusion_coeff(t)`

代码：

```python
@abc.abstractmethod
def diffusion_coeff(self, t):
    pass
```

作用：

> 只计算 SDE 中的扩散系数 $g(t)$。

如果只需要噪声强度，就没必要同时计算漂移项。

---

## 7.5 `marginal_prob_std(t)`

代码：

```python
@abc.abstractmethod
def marginal_prob_std(self, t):
    pass
```

作用：

> 只计算边缘分布标准差 $\sigma_t$。

例如，在 score 参数化中经常需要：

$$
s_\theta(x_t,t)
=
-\frac{\varepsilon_\theta(x_t,t)}{\sigma_t}
$$

这时，只需要标准差，不需要均值。

---

# 8. 什么是 VP-SDE？

代码：

```python
class VPSDE_linear(SDE):
```

表示实现一个线性调度下的 VP-SDE。

VP-SDE 是：

> Variance Preserving Stochastic Differential Equation

中文通常翻译为：

> 方差保持型随机微分方程

其标准形式为：

$$
\boxed{
\mathrm{d}x_t
=
-\frac{1}{2}\beta(t)x_t\,\mathrm{d}t
+
\sqrt{\beta(t)}\,\mathrm{d}W_t
}
$$

其中：

- 漂移项逐渐缩小原始信号；
- 扩散项不断加入高斯噪声。

---

# 9. 什么是线性调度？

代码初始化：

```python
def __init__(self, beta_max=20.0, beta_min=0.1):
    self._beta_max = beta_max
    self._beta_min = beta_min
```

线性调度定义为：

$$
\boxed{
\beta(t)
=
\beta_{\min}
+
(\beta_{\max}-\beta_{\min})t
}
$$

当：

$$
t=0
$$

时：

$$
\beta(0)=\beta_{\min}
$$

当：

$$
t=1
$$

时：

$$
\beta(1)=\beta_{\max}
$$

默认值为：

$$
\beta_{\min}=0.1
$$

$$
\beta_{\max}=20
$$

所以：

$$
\beta(t)
=
0.1+19.9t
$$

---

## 9.1 $\beta(t)$ 表示什么？

$\beta(t)$ 不是“当前已经积累了多少噪声”。

它更接近：

> 当前时刻附近，每单位时间注入噪声的速率。

当 $\beta(t)$ 较小时：

- 原始信号衰减较慢；
- 新加入的噪声较少。

当 $\beta(t)$ 较大时：

- 原始信号衰减较快；
- 新加入的噪声更多。

---

代码：

```python

def T(self):
    return 1.0
```

表示扩散时间范围为：

$$
t\in[0,1]
$$

其中：

- $t=0$：接近原始数据；
- $t=1$：接近强噪声状态。

# 11. `VPSDE_linear.sde(x,t)` 的原理

代码核心：

```python
beta_t = (self._beta_max - self._beta_min) * t + self._beta_min
drift = -0.5 * beta_t * x
diffusion = torch.sqrt(beta_t)
return drift, diffusion
```

对应：

$$
\beta(t)
=
\beta_{\min}
+
(\beta_{\max}-\beta_{\min})t
$$

$$
\boxed{
f(x_t,t)
=
-\frac{1}{2}\beta(t)x_t
}
$$

$$
\boxed{
g(t)
=
\sqrt{\beta(t)}
}
$$

最终 SDE 为：

$$
\boxed{
\mathrm{d}x_t
=
-\frac{1}{2}\beta(t)x_t\,\mathrm{d}t
+
\sqrt{\beta(t)}\,\mathrm{d}W_t
}
$$

---

## 11.1 漂移项为什么带负号？

漂移项为：

$$
-\frac{1}{2}\beta(t)x_t
$$

由于：

$$
\beta(t)>0
$$

它与 $x_t$ 方向相反。

因此，漂移项会不断将样本拉向原点。

例如，当：

$$
x_t=4
$$

且：

$$
\beta(t)=2
$$

时：

$$
-\frac{1}{2}\beta(t)x_t
=
-\frac{1}{2}\times2\times4
=
-4
$$

样本向较小方向移动。

---

## 11.2 为什么扩散系数是 $\sqrt{\beta(t)}$？

布朗运动增量满足：

$$
\operatorname{Var}(\mathrm{d}W_t)
=
\mathrm{d}t
$$

乘以：

$$
\sqrt{\beta(t)}
$$

后：

$$
\operatorname{Var}
\left(
\sqrt{\beta(t)}\,\mathrm{d}W_t
\right)
=
\beta(t)\,\mathrm{d}t
$$

因此，单位时间中的噪声方差增长率就是：

$$
\beta(t)
$$

# 12. 为什么代码需要 reshape？

在 `sde(...)` 中：

```python
shape = x.shape
reshape = [-1] + [1, ] * (len(shape) - 1)
t = t.reshape(reshape)
```

这是为了让时间张量可以与高维输入自动广播。

---

## 12.1 一个轨迹张量例子

假设：

$$
x.shape=[B,P,D]
$$

例如：

$$
x.shape=[32,6,324]
$$

时间张量形状为：

$$
t.shape=[B]
$$

即：

$$
t.shape=[32]
$$

代码构造：

```python
reshape = [-1, 1, 1]
```

然后：

```python
t = t.reshape(-1, 1, 1)
```

得到：

$$
t.shape=[32,1,1]
$$

这样：

$$
\beta(t)
$$

就可以沿着 $P$ 和 $D$ 维自动广播。

每个 batch 样本使用自己的扩散时间。

---

## 12.2 一个图像张量例子

假设：

$$
x.shape=[B,C,H,W]
$$

则：

```python
reshape = [-1, 1, 1, 1]
```

时间张量变成：

$$
[B,1,1,1]
$$

于是，同一个样本中的所有像素共享同一个时间 $t$。

---

## 12.3 广播后的形状

如果：

$$
x\in\mathbb{R}^{B\times P\times D}
$$

并且：

$$
\beta_t\in\mathbb{R}^{B\times1\times1}
$$

那么：

$$
\beta_t x
$$

会自动得到：

$$
B\times P\times D
$$

的结果。

# 14. VP-SDE 的边缘分布形式

线性 VP-SDE 可以得到：

$$
\boxed{
x_t
=
\alpha_t x_0
+
\sigma_t\varepsilon
}
$$

其中：

$$
\varepsilon\sim\mathcal{N}(0,I)
$$

因此：

$$
\boxed{
q(x_t\mid x_0)
=
\mathcal{N}
\left(
x_t;
\alpha_t x_0,
\sigma_t^2I
\right)
}
$$

其中：

$$
\alpha_t
=
\exp
\left(
-\frac{1}{2}
\int_0^t
\beta(s)\,\mathrm{d}s
\right)
$$

---

# 15. $\alpha_t$ 是怎么推导出来的？

先忽略随机噪声，仅看漂移部分：

$$
\frac{\mathrm{d}x_t}{\mathrm{d}t}
=
-\frac{1}{2}\beta(t)x_t
$$

考虑条件均值：

$$
m(t)
=
\mathbb{E}[x_t\mid x_0]
$$

由于高斯噪声均值为零：

$$
\mathbb{E}[\mathrm{d}W_t]=0
$$

所以均值满足：

$$
\frac{\mathrm{d}m(t)}{\mathrm{d}t}
=
-\frac{1}{2}\beta(t)m(t)
$$

两边除以 $m(t)$：

$$
\frac{1}{m(t)}
\frac{\mathrm{d}m(t)}{\mathrm{d}t}
=
-\frac{1}{2}\beta(t)
$$

左侧是：

$$
\frac{\mathrm{d}}{\mathrm{d}t}
\log m(t)
$$

从 $0$ 到 $t$ 积分：

$$
\log m(t)-\log m(0)
=
-\frac{1}{2}
\int_0^t
\beta(s)\,\mathrm{d}s
$$

由于：

$$
m(0)=x_0
$$

因此：

$$
m(t)
=
\exp
\left(
-\frac{1}{2}
\int_0^t
\beta(s)\,\mathrm{d}s
\right)x_0
$$

定义：

$$
\boxed{
\alpha_t
=
\exp
\left(
-\frac{1}{2}
\int_0^t
\beta(s)\,\mathrm{d}s
\right)
}
$$

于是：

$$
\boxed{
\mathbb{E}[x_t\mid x_0]
=
\alpha_t x_0
}
$$

---

# 16. 线性调度下如何计算 $\alpha_t$？

已知：

$$
\beta(s)
=
\beta_{\min}
+
(\beta_{\max}-\beta_{\min})s
$$

先积分：

$$
\int_0^t
\beta(s)\,\mathrm{d}s
=
\int_0^t
\left[
\beta_{\min}
+
(\beta_{\max}-\beta_{\min})s
\right]
\,\mathrm{d}s
$$

分别积分：

$$
\int_0^t
\beta_{\min}\,\mathrm{d}s
=
\beta_{\min}t
$$

$$
\int_0^t
(\beta_{\max}-\beta_{\min})s\,\mathrm{d}s
=
\frac{1}{2}
(\beta_{\max}-\beta_{\min})t^2
$$

所以：

$$
\int_0^t
\beta(s)\,\mathrm{d}s
=
\beta_{\min}t
+
\frac{1}{2}
(\beta_{\max}-\beta_{\min})t^2
$$

代入 $\alpha_t$：

$$
\alpha_t
=
\exp
\left[
-\frac{1}{2}\beta_{\min}t
-
\frac{1}{4}
(\beta_{\max}-\beta_{\min})t^2
\right]
$$

因此：

$$
\boxed{
\log\alpha_t
=
-\frac{1}{2}\beta_{\min}t
-
\frac{1}{4}
(\beta_{\max}-\beta_{\min})t^2
}
$$

---

# 18. $\sigma_t$ 是怎么得到的？

VP-SDE 满足：

$$
\boxed{
\alpha_t^2+\sigma_t^2=1
}
$$

因此：

$$
\boxed{
\sigma_t
=
\sqrt{1-\alpha_t^2}
}
$$

由于：

$$
\alpha_t
=
\exp(\log\alpha_t)
$$

所以：

$$
\alpha_t^2
=
\exp(2\log\alpha_t)
$$

因此：

$$
\boxed{
\sigma_t
=
\sqrt{
1-\exp(2\log\alpha_t)
}
}
$$

代码：

```python
std = torch.sqrt(1 - torch.exp(2. * mean_log_coeff))
```

与公式完全对应。

---

# 19. `marginal_prob(x,t)` 的完整数学含义

代码：

```python
mean = torch.exp(mean_log_coeff) * x
std = torch.sqrt(1 - torch.exp(2. * mean_log_coeff))
return mean, std
```

表示：

$$
\boxed{
q(x_t\mid x_0)
=
\mathcal{N}
\left(
x_t;
\alpha_t x_0,
\sigma_t^2I
\right)
}
$$

其中：

$$
\boxed{
\alpha_t
=
\exp
\left[
-\frac{1}{2}\beta_{\min}t
-
\frac{1}{4}
(\beta_{\max}-\beta_{\min})t^2
\right]
}
$$

$$
\boxed{
\sigma_t
=
\sqrt{
1-\alpha_t^2
}
}
$$

---

# 20. 为什么直接算边缘分布很有用？

一种低效做法是逐步模拟：

$$
x_0
\longrightarrow
x_{\Delta t}
\longrightarrow
x_{2\Delta t}
\longrightarrow
\cdots
\longrightarrow
x_t
$$

但有了解析公式后，可以一次完成：

$$
x_t
=
\alpha_t x_0+\sigma_t\varepsilon
$$

其中：

$$
\varepsilon
\sim
\mathcal{N}(0,I)
$$

训练时可以直接随机采样任意时间 $t$，不必逐步加噪。

# 21. `diffusion_coeff(t)` 的作用

代码：

```python
def diffusion_coeff(self, t):
    beta_t = (self._beta_max - self._beta_min) * t + self._beta_min
    diffusion = torch.sqrt(beta_t)
    return diffusion
```

它单独返回：

$$
\boxed{
g(t)
=
\sqrt{\beta(t)}
}
$$

适用于只需要扩散系数的场景。

例如，反向 SDE 或 probability flow ODE 的公式中可能会单独使用：

$$
g(t)
$$

# 22. `marginal_prob_std(t)` 的作用

代码：

```python
discount = torch.exp(
    -0.5 * t ** 2 * (self._beta_max - self._beta_min)
    - self._beta_min * t
)

std = torch.sqrt(1 - discount)
return std
```

这里：

$$
\texttt{discount}
=
\exp
\left[
-\frac{1}{2}
(\beta_{\max}-\beta_{\min})t^2
-
\beta_{\min}t
\right]
$$

注意：

$$
\alpha_t
=
\exp
\left[
-\frac{1}{4}
(\beta_{\max}-\beta_{\min})t^2
-
\frac{1}{2}\beta_{\min}t
\right]
$$

所以：

$$
\boxed{
\texttt{discount}
=
\alpha_t^2
}
$$

因此：

$$
\boxed{
\texttt{std}
=
\sqrt{1-\alpha_t^2}
=
\sigma_t
}
$$

# 23. `marginal_prob(...)` 和 `marginal_prob_std(...)` 有什么区别？

| 方法 | 输入 | 输出 | 使用场景 |
|---|---|---|---|
| `marginal_prob(x,t)` | 原始样本和时间 | 均值与标准差 | 直接构造带噪样本 |
| `marginal_prob_std(t)` | 时间 | 标准差 | score 缩放、损失函数或采样器 |

例如，构造带噪样本：

```python
mean, std = sde.marginal_prob(x0, t)

xt = mean + std * noise
```

对应：

$$
x_t
=
\alpha_t x_0
+
\sigma_t\varepsilon
$$

# 27. 指数调度中的关键积分

如果：

$$
\beta(t)=\sigma^t
$$

则：

$$
\int_0^t
\beta(s)\,\mathrm{d}s
=
\int_0^t
\sigma^s\,\mathrm{d}s
$$

由于：

$$
\int
\sigma^s\,\mathrm{d}s
=
\frac{\sigma^s}{\log\sigma}
$$

所以：

$$
\boxed{
\int_0^t
\sigma^s\,\mathrm{d}s
=
\frac{
\sigma^t-1
}{
\log\sigma
}
}
$$

为了简化，可以定义：

$$
I(t)
=
\frac{
\sigma^t-1
}{
\log\sigma
}
$$

# 30. `subVPSDE_exp` 中有哪些需要特别注意的地方？

这个类已经通过：

```python
raise NotImplementedError
```

明确标记为未启用。

即使删除这行代码，也建议先检查以下问题。

---

## 30.1 `torch.log(self._sigma)` 的输入类型

默认：

```python
self._sigma = 25.0
```

是 Python 浮点数。

但是：

```python
torch.log(self._sigma)
```

通常希望输入是 PyTorch 张量。

启用该类前，需要确认类型兼容性，例如是否应该使用：

```python
torch.log(torch.as_tensor(self._sigma, device=t.device))
```

或者使用 Python 的：

```python
math.log(self._sigma)
```

这里仅指出风险，不直接修改原始代码。

---

## 30.2 名为 `std` 的变量没有开平方

代码：

```python
std = torch.clamp(1 - discount, min=STD_MIN)
```

没有写成：

```python
torch.sqrt(...)
```

这与普通 VP-SDE 中：

$$
\sigma_t
=
\sqrt{1-\alpha_t^2}
$$

的形式不同。

在标准 sub-VP-SDE 的一些常见写法中，边缘分布标准差确实可能写成：

$$
1-\exp[-I(t)]
$$

而不是其平方根。

因此，不能仅根据变量名 `std` 判断代码一定错误。

但是，如果要启用该类，仍然应该结合项目采用的数学定义和采样器公式进行核对。

---

## 30.3 均值系数需要进一步核对

对于漂移：

$$
-\frac{1}{2}\beta(t)x
$$

常见信号衰减系数通常为：

$$
\exp
\left[
-\frac{1}{2}
\int_0^t
\beta(s)\,\mathrm{d}s
\right]
$$

而当前代码中的 `mean` 使用：

$$
\exp[-I(t)]x
$$

与上式相比，指数系数存在差异。

由于该类已明确禁用，无法仅凭当前文件确认这是：

- 作者有意采用的特殊参数化；
- 尚未完成的草稿；
- 或需要修正的实现。

因此，当前项目中应优先使用已经启用的：

```python
VPSDE_linear
```

# 36. 与噪声预测参数化的关系

扩散模型中常见：

$$
x_t
=
\alpha_t x_0+\sigma_t\varepsilon
$$

其中：

$$
\varepsilon\sim\mathcal{N}(0,I)
$$

条件 score 为：

$$
\nabla_{x_t}
\log q(x_t\mid x_0)
=
-\frac{
x_t-\alpha_t x_0
}{
\sigma_t^2
}
$$

由于：

$$
x_t-\alpha_t x_0
=
\sigma_t\varepsilon
$$

所以：

$$
\boxed{
\nabla_{x_t}
\log q(x_t\mid x_0)
=
-\frac{\varepsilon}{\sigma_t}
}
$$

也就是：

$$
\boxed{
\varepsilon
=
-\sigma_t
\operatorname{score}(x_t,t)
}
$$

因此，`marginal_prob_std(t)` 在 score 模型、噪声预测模型和采样器之间的转换中非常重要。
