# DiT 条件 Transformer 模块：从零开始理解代码原理

> 本文面向刚开始学习深度学习、Transformer 和扩散模型的读者。  
> 本文讲解的代码包含五个核心部分：`modulate(...)`、`scale(...)`、`TimestepEmbedder`、`DiTBlock` 和 `FinalLayer`。

---

# 1. 这段代码整体上在做什么？

这段代码实现的是扩散模型中的一组 **条件 Transformer 模块**。

它的核心任务可以概括为：

> 输入一组需要更新的 token，结合扩散时间步和外部上下文信息，输出经过条件控制后的新特征，最后再映射到目标输出空间。

在轨迹规划、图像生成或其他扩散模型中，网络需要知道两个问题：

1. 当前输入处于扩散过程的哪个时间步；
2. 当前生成结果应当参考哪些外部条件。

这段代码分别使用以下变量表示这些信息：

| 变量 | 常见形状 | 含义 |
|---|---|---|
| `x` | `[B,P,D]` | 当前需要处理的 token 特征 |
| `y` | `[B,D]` | 条件向量，通常包含时间步嵌入 |
| `cross_c` | `[B,C,D]` | 外部上下文 token，例如场景编码或地图编码 |
| `attn_mask` | `[B,P]` | `x` 中无效 token 的屏蔽标记 |

其中：

- $B$：batch size，一次处理多少个样本；
- $P$：需要更新的 token 数量；
- $C$：外部上下文 token 数量；
- $D$：每个 token 的隐藏特征维度。

代码的整体数据流可以写成：

$$
\text{时间步 }t
\longrightarrow
\text{时间步嵌入 }y
$$

$$
(x,y)
\longrightarrow
\text{条件调制后的自注意力}
\longrightarrow
\text{条件调制后的 MLP}
$$

$$
(x,\text{cross\_c})
\longrightarrow
\text{交叉注意力}
\longrightarrow
\text{第二个 MLP}
\longrightarrow
\text{最终输出层}
$$

# 2. 阅读代码前需要掌握的最少知识

## 2.1 什么是张量？

张量可以理解为多维数组。

例如，一个形状为：

$$
[B,P,D]
$$

的张量表示：

- 有 $B$ 个样本；
- 每个样本包含 $P$ 个 token；
- 每个 token 使用 $D$ 个数字描述。

假设：

$$
B=2,\qquad P=4,\qquad D=3
$$

那么张量形状为：

$$
[2,4,3]
$$

表示一次输入两个样本，每个样本有四个 token，每个 token 有三个特征。

---

## 2.2 什么是 token？

一个 token 是模型处理的一个基本信息单元。

不同任务中，token 的具体含义不同：

| 任务 | token 的可能含义 |
|---|---|
| 文本处理 | 一个单词或子词 |
| 图像生成 | 一个图像小块 |
| 自动驾驶规划 | 某个轨迹点、某辆车或一个场景元素 |

在这段代码中，可以先将 token 理解为：

> 一组需要由 Transformer 更新的特征向量。

---

## 2.3 什么是隐藏特征维度？

假设某个 token 被表示为：

$$
x_i\in\mathbb{R}^{D}
$$

这表示该 token 由 $D$ 个数字描述。

例如，当：

$$
D=192
$$

时，每个 token 都是一个 $192$ 维向量。

这些数字不一定能够直接解释为“速度”“位置”或“颜色”。它们通常是神经网络学习到的抽象特征。

---

## 2.4 什么是残差连接？

残差连接的基本形式为：

$$
x_{\text{new}}=x+F(x)
$$

其中：

- $x$ 是旧特征；
- $F(x)$ 是某个神经网络模块学习到的新信息；
- $x_{\text{new}}$ 是更新后的特征。

直观上，残差连接表示：

> 保留原始信息，同时增加一部分新信息。

它通常能够提高深层网络的训练稳定性。

---

# 4. `modulate(...)`：根据条件向量调整特征

代码中的第一个辅助函数为：

```python
def modulate(x, shift, scale, only_first=False):
    if only_first:
        x_first, x_rest = x[:, :1], x[:, 1:]
        x = torch.cat([
            x_first * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1),
            x_rest
        ], dim=1)
    else:
        x = x * (1 + scale.unsqueeze(1)) + shift.unsqueeze(1)
    return x
```

它实现的公式为：

$$
\boxed{
\operatorname{modulate}(x)=x\odot(1+s)+b
}
$$

其中：

- $x$：原始特征；
- $s$：缩放参数，对应代码中的 `scale`；
- $b$：平移参数，对应代码中的 `shift`；
- $\odot$：逐元素相乘。

---

## 4.1 为什么要调整特征？

扩散模型在不同时间步面对的任务不同。

- 噪声很大时，模型应先恢复整体结构；
- 噪声较小时，模型应进一步修复细节。

因此，模型不能用完全相同的方式处理所有时间步。

`modulate(...)` 的作用就是：

> 使用条件向量生成的 `shift` 和 `scale`，改变网络内部特征的处理方式。

可以将它类比为根据任务难度动态调节音量和偏置。

---

## 4.2 为什么公式使用 `1 + scale`？

代码没有直接计算：

$$
x\odot s+b
$$

而是计算：

$$
x\odot(1+s)+b
$$

原因是：当神经网络输出：

$$
s=0,\qquad b=0
$$

时，有：

$$
x\odot(1+0)+0=x
$$

也就是说，调制操作自动退化为恒等映射。

这通常更有利于稳定训练。

---

## 4.3 为什么需要 `unsqueeze(1)`？

假设：

$$
x\in\mathbb{R}^{B\times P\times D}
$$

而：

$$
\text{scale},\text{shift}\in\mathbb{R}^{B\times D}
$$

`scale` 和 `shift` 缺少 token 维度 $P$。

执行：

```python
scale.unsqueeze(1)
```

以后，形状变为：

$$
[B,1,D]
$$

PyTorch 会自动将它广播为：

$$
[B,P,D]
$$

因此，同一个样本中的所有 token 会使用相同的条件调制参数。

形状变化为：

$$
[B,D]
\xrightarrow{\texttt{unsqueeze(1)}}
[B,1,D]
\xrightarrow{\text{broadcast}}
[B,P,D]
$$

---

## 4.4 `only_first=True` 是什么意思？

当：

```python
only_first=True
```

时，代码只调整索引为 $0$ 的第一个 token：

$$
x[:,0,:]
$$

其余 token 保持原样。

代码先拆分：

```python
x_first, x_rest = x[:, :1], x[:, 1:]
```

然后只更新 `x_first`，最后再拼接回来。

这适用于以下设计：

> 第一个 token 是特殊 token，例如代表自车、全局摘要或分类信息的 token。

需要注意：在当前展示的 `DiTBlock` 和 `FinalLayer` 中，调用 `modulate(...)` 时没有传入 `only_first=True`。因此，默认行为是调制所有 token。

---

# 5. `scale(...)`：只执行缩放，不执行平移

代码中的第二个辅助函数为：

```python
def scale(x, scale, only_first=False):
    if only_first:
        x_first, x_rest = x[:, :1], x[:, 1:]
        x = torch.cat([
            x_first * (1 + scale.unsqueeze(1)),
            x_rest
        ], dim=1)
    else:
        x = x * (1 + scale.unsqueeze(1))
    return x
```

它实现：

$$
\boxed{
x_{\text{new}}=x\odot(1+s)
}
$$

与 `modulate(...)` 相比，它少了平移项：

$$
b
$$

因此：

- `modulate(...)`：缩放并平移；
- `scale(...)`：只缩放。

在当前展示的类中，`scale(...)` 没有被实际调用。它可能是为了其他模块或后续实验预先保留的工具函数。

# 6. `TimestepEmbedder`：将扩散时间步转换为向量

## 6.1 为什么标量时间步不能直接使用？

扩散模型中的时间步通常是一个标量：

$$
t
$$

例如：

$$
t=0.1,\quad t=0.5,\quad t=0.9
$$

但神经网络内部处理的隐藏特征通常是高维向量，例如：

$$
y\in\mathbb{R}^{192}
$$

因此，需要将标量时间步转换为高维表示：

$$
t
\longrightarrow
y_t
$$

`TimestepEmbedder` 完成的就是这个转换。

---

## 6.2 整体结构

代码为：

```python
class TimestepEmbedder(nn.Module):
    def __init__(self, hidden_size, frequency_embedding_size=256):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(frequency_embedding_size, hidden_size, bias=True),
            nn.SiLU(),
            nn.Linear(hidden_size, hidden_size, bias=True),
        )
        self.frequency_embedding_size = frequency_embedding_size
```

数据流为：

$$
t
\longrightarrow
\text{正弦余弦编码}
\longrightarrow
\text{Linear}
\longrightarrow
\text{SiLU}
\longrightarrow
\text{Linear}
\longrightarrow
 y_t
$$

---

## 6.3 正弦和余弦编码的公式

代码核心部分为：

```python
half = dim // 2
freqs = torch.exp(
    -math.log(max_period)
    * torch.arange(start=0, end=half, dtype=torch.float32)
    / half
).to(device=t.device)

args = t[:, None].float() * freqs[None]
embedding = torch.cat([torch.cos(args), torch.sin(args)], dim=-1)
```

令：

$$
h=\left\lfloor\frac{d}{2}\right\rfloor
$$

其中 $d$ 是频率编码维度。

第 $i$ 个频率为：

$$
\omega_i
=
\exp\left(
-\log(M)\frac{i}{h}
\right)
$$

其中：

- $M$ 对应 `max_period`；
- 默认：

$$
M=10000
$$

利用指数和对数性质，也可以写成：

$$
\omega_i=M^{-i/h}
$$

然后，对每个时间步 $t$ 计算：

$$
t\omega_0,
\quad
 t\omega_1,
\quad
\ldots,
\quad
 t\omega_{h-1}
$$

最终嵌入为：

$$
\boxed{
\operatorname{emb}(t)
=
[
\cos(t\omega_0),\ldots,\cos(t\omega_{h-1}),
\sin(t\omega_0),\ldots,\sin(t\omega_{h-1})
]
}
$$

---

## 6.4 为什么使用不同频率？

可以将不同频率类比为不同尺度的钟表：

- 高频变化快，擅长区分接近的时间步；
- 低频变化慢，擅长描述整体时间位置。

组合多个频率以后，模型就能区分不同时间步，并学习时间变化规律。

---

## 6.5 形状如何变化？

假设：

$$
t\in\mathbb{R}^{B}
$$

并且：

$$
d=256
$$

则：

$$
h=128
$$

形状变化如下：

| 表达式 | 形状 |
|---|---|
| `t` | `[B]` |
| `t[:,None]` | `[B,1]` |
| `freqs` | `[128]` |
| `freqs[None]` | `[1,128]` |
| `args` | `[B,128]` |
| `cos(args)` | `[B,128]` |
| `sin(args)` | `[B,128]` |
| 拼接后的 `embedding` | `[B,256]` |

---

## 6.6 为什么奇数维度需要补零？

如果：

$$
d=255
$$

那么：

$$
h=\left\lfloor\frac{255}{2}\right\rfloor=127
$$

正弦和余弦拼接以后只有：

$$
127+127=254
$$

维。

因此，代码会补充一列零：

```python
if dim % 2:
    embedding = torch.cat([
        embedding,
        torch.zeros_like(embedding[:, :1])
    ], dim=-1)
```

使最终形状严格等于：

$$
[B,d]
$$

---

## 6.7 为什么还要经过 MLP？

正弦和余弦编码是固定规则，不包含可训练参数。

随后使用：

```python
self.mlp(t_freq)
```

可以让模型学习：

> 如何将固定频率编码转换成最适合当前任务的时间条件特征。

完整公式可以写成：

$$
\boxed{
y_t=W_2\operatorname{SiLU}(W_1\operatorname{emb}(t)+b_1)+b_2
}
$$

# 7. `DiTBlock`：核心条件 Transformer 模块

## 7.1 什么是 DiT？

DiT 是：

> Diffusion Transformer

也就是将 Transformer 用作扩散模型中的神经网络骨干。

普通 Transformer 善于建模 token 之间的关系。DiT 在此基础上加入扩散时间条件，使网络能够根据当前噪声等级调整计算方式。

---

## 7.2 `DiTBlock` 接收哪些输入？

代码的 `forward(...)` 方法为：

```python
def forward(self, x, cross_c, y, attn_mask):
```

各变量含义如下：

| 变量 | 常见形状 | 含义 |
|---|---|---|
| `x` | `[B,P,D]` | 当前需要更新的 token |
| `cross_c` | `[B,C,D]` | 外部上下文 token |
| `y` | `[B,D]` | 条件向量，通常包含时间步信息 |
| `attn_mask` | `[B,P]` | 无效 `x` token 的屏蔽标记 |

---

## 7.3 模块整体结构

当前代码中的 `DiTBlock` 可以画成：

```text
x
│
├─ LayerNorm
├─ 由 y 生成的 shift_msa、scale_msa 进行调制
├─ Self-Attention
├─ 由 y 生成的 gate_msa 控制残差强度
└─ 残差相加

x
│
├─ LayerNorm
├─ 由 y 生成的 shift_mlp、scale_mlp 进行调制
├─ MLP 1
├─ 由 y 生成的 gate_mlp 控制残差强度
└─ 残差相加

x
│
├─ LayerNorm
├─ Cross-Attention：从 cross_c 中读取信息
└─ 直接覆盖 x

x
│
├─ LayerNorm
├─ MLP 2
└─ 直接覆盖 x
```

# 8. 自注意力：让 `x` 中的 token 互相交流

## 8.1 自注意力的基本目的

假设 `x` 中包含多个 token：

$$
x_1,x_2,\ldots,x_P
$$

自注意力希望让每个 token 根据其他 token 的信息更新自己。

例如，在轨迹规划中：

- 某个轨迹点可能需要参考其他轨迹点；
- 某辆车可能需要关注周围车辆；
- 某个局部特征可能需要结合全局上下文。

---

## 8.2 Query、Key 和 Value

对输入矩阵：

$$
X\in\mathbb{R}^{P\times D}
$$

通常构造：

$$
Q=XW_Q
$$

$$
K=XW_K
$$

$$
V=XW_V
$$

其中：

- $Q$：Query，表示“我正在寻找什么”；
- $K$：Key，表示“我可以提供什么”；
- $V$：Value，表示“真正传递出去的信息”。

注意力输出为：

$$
\boxed{
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}
\left(
\frac{QK^{\mathsf{T}}}{\sqrt{d_k}}
\right)V
}
$$

其中：

$$
QK^{\mathsf{T}}
$$

衡量 token 之间的匹配程度。

---

## 8.3 代码中的自注意力

代码为：

```python
self.attn = nn.MultiheadAttention(
    dim,
    heads,
    dropout,
    batch_first=True
)
```

以及：

```python
self.attn(
    modulated_x,
    modulated_x,
    modulated_x,
    key_padding_mask=attn_mask
)[0]
```

因为 Query、Key 和 Value 都来自：

```python
modulated_x
```

所以这是 **自注意力**。

---

## 8.4 多头注意力是什么意思？

假设：

$$
D=192
$$

注意力头数量为：

$$
H=6
$$

那么每个头处理：

$$
d_{\text{head}}=\frac{192}{6}=32
$$

维特征。

不同注意力头可以学习不同关系，例如：

- 某个头关注近距离关系；
- 某个头关注长期关系；
- 某个头关注地图上下文；
- 某个头关注运动趋势。

注意：`dim` 必须能够被 `heads` 整除。

---

## 8.5 `key_padding_mask` 是什么？

代码将：

```python
attn_mask
```

传给：

```python
key_padding_mask=attn_mask
```

因此这里的 `attn_mask` 实际上是 **padding mask**。

通常：

- `False`：该 token 有效；
- `True`：该 token 无效，需要忽略。

无效 token 不应成为其他 token 读取信息的来源。

注意：这与用于限制 token 两两关系的二维因果 mask 不是同一种掩码。

---

# 9. adaptive LayerNorm：让时间条件控制网络内部计算

## 9.1 普通 LayerNorm 做什么？

对某个 token 特征：

$$
x\in\mathbb{R}^{D}
$$

LayerNorm 会计算：

$$
\mu=\frac{1}{D}\sum_{i=1}^{D}x_i
$$

$$
\sigma^2=\frac{1}{D}\sum_{i=1}^{D}(x_i-\mu)^2
$$

然后归一化：

$$
\hat{x}_i
=
\frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}
$$

作用是让特征数值更加稳定。

---

## 9.2 什么是 adaptive LayerNorm？

普通 LayerNorm 对所有样本采用固定的仿射参数。

adaptive LayerNorm 则让条件向量 $y$ 动态生成调制参数：

$$
\text{shift}(y),\qquad \text{scale}(y)
$$

然后执行：

$$
\boxed{
\operatorname{adaLN}(x,y)
=
\operatorname{LayerNorm}(x)
\odot
(1+\operatorname{scale}(y))
+
\operatorname{shift}(y)
}
$$

因此，不同时间步可以采用不同的特征处理方式。

---

## 9.3 六组条件参数从哪里来？

代码为：

```python
self.adaLN_modulation = nn.Sequential(
    nn.SiLU(),
    nn.Linear(dim, 6 * dim, bias=True)
)
```

输入：

$$
y\in\mathbb{R}^{B\times D}
$$

输出：

$$
[B,6D]
$$

随后：

```python
shift_msa, scale_msa, gate_msa, \
shift_mlp, scale_mlp, gate_mlp = \
    self.adaLN_modulation(y).chunk(6, dim=1)
```

将输出拆成六组：

| 参数 | 作用 |
|---|---|
| `shift_msa` | 调整自注意力前的特征平移 |
| `scale_msa` | 调整自注意力前的特征缩放 |
| `gate_msa` | 控制自注意力残差分支强度 |
| `shift_mlp` | 调整第一个 MLP 前的特征平移 |
| `scale_mlp` | 调整第一个 MLP 前的特征缩放 |
| `gate_mlp` | 控制第一个 MLP 残差分支强度 |

每一组形状均为：

$$
[B,D]
$$

# 10. 条件控制的自注意力分支

代码为：

```python
modulated_x = modulate(
    self.norm1(x),
    shift_msa,
    scale_msa
)

x = x + gate_msa.unsqueeze(1) * self.attn(
    modulated_x,
    modulated_x,
    modulated_x,
    key_padding_mask=attn_mask
)[0]
```

可以写成公式：

$$
\widetilde{x}
=
\operatorname{adaLN}_{\text{msa}}(x,y)
$$

$$
\boxed{
x
\leftarrow
x+
 g_{\text{msa}}(y)
\odot
\operatorname{SelfAttention}(\widetilde{x})
}
$$

其中：

$$
g_{\text{msa}}(y)
$$

对应代码中的：

```python
gate_msa
```

---

## 10.1 `gate_msa` 有什么用？

`gate_msa` 是一个门控参数。

它决定自注意力分支对结果的影响强度。

- 当：

$$
g_{\text{msa}}=0
$$

时：

$$
x_{\text{new}}=x
$$

自注意力分支暂时不起作用。

- 当：

$$
g_{\text{msa}}
$$

绝对值较大时，自注意力分支对输出影响更强。

因此，网络可以根据条件动态决定：

> 当前时间步需要多大程度依赖自注意力。

---

# 11. 条件控制的第一个 MLP 分支

代码为：

```python
modulated_x = modulate(
    self.norm2(x),
    shift_mlp,
    scale_mlp
)

x = x + gate_mlp.unsqueeze(1) * self.mlp1(modulated_x)
```

公式为：

$$
\widetilde{x}
=
\operatorname{adaLN}_{\text{mlp}}(x,y)
$$

$$
\boxed{
x
\leftarrow
x+
 g_{\text{mlp}}(y)
\odot
\operatorname{MLP}_1(\widetilde{x})
}
$$

其中：

- 自注意力负责不同 token 之间的信息交换；
- MLP 负责每个 token 内部的特征加工。

---

## 11.1 第一个 MLP 的结构

代码为：

```python
mlp_hidden_dim = int(dim * mlp_ratio)
approx_gelu = lambda: nn.GELU(approximate="tanh")

self.mlp1 = Mlp(
    in_features=dim,
    hidden_features=mlp_hidden_dim,
    act_layer=approx_gelu,
    drop=0
)
```

当：

$$
D=192
$$

且：

$$
\texttt{mlp\_ratio}=4
$$

时：

$$
D_{\text{hidden}}=192\times4=768
$$

忽略 Dropout 时，MLP 可写成：

$$
\boxed{
\operatorname{MLP}(x)
=
W_2\operatorname{GELU}(W_1x+b_1)+b_2
}
$$

其维度变化为：

$$
192
\longrightarrow
768
\longrightarrow
192
$$

# 12. 交叉注意力：让 `x` 从外部上下文读取信息

## 12.1 自注意力与交叉注意力的区别

自注意力中：

$$
Q,K,V
$$

都来自同一个输入。

交叉注意力中：

- Query 来自当前需要更新的 token；
- Key 和 Value 来自外部上下文。

代码为：

```python
x = self.cross_attn(
    self.norm3(x),
    cross_c,
    cross_c
)[0]
```

因此：

$$
Q=\operatorname{LayerNorm}(x)W_Q
$$

$$
K=\text{cross\_c}W_K
$$

$$
V=\text{cross\_c}W_V
$$

交叉注意力为：

$$
\boxed{
\operatorname{CrossAttention}(x,c)
=
\operatorname{softmax}
\left(
\frac{Q_xK_c^{\mathsf{T}}}{\sqrt{d_k}}
\right)V_c
}
$$

---

## 12.2 直观理解

假设 `x` 表示待生成轨迹的 token，而 `cross_c` 表示编码后的场景信息：

- 周围车辆；
- 道路结构；
- 车道线；
- 静态障碍物；
- 信号灯。

交叉注意力允许每个轨迹 token 主动查询：

> 当前最应该参考哪些场景元素？

---

## 12.3 形状如何变化？

假设：

$$
x\in\mathbb{R}^{B\times P\times D}
$$

以及：

$$
\text{cross\_c}\in\mathbb{R}^{B\times C\times D}
$$

那么交叉注意力输出仍然为：

$$
[B,P,D]
$$

因为每个 `x` token 都会从外部上下文中读取信息，并生成一个新的 $D$ 维表示。

---

# 13. 当前代码中值得特别注意的设计：交叉注意力后没有残差连接

代码写的是：

```python
x = self.cross_attn(self.norm3(x), cross_c, cross_c)[0]
```

而不是：

```python
x = x + self.cross_attn(self.norm3(x), cross_c, cross_c)[0]
```

因此，交叉注意力输出会直接覆盖旧的 `x`。

同理，代码写的是：

```python
x = self.mlp2(self.norm4(x))
```

而不是：

```python
x = x + self.mlp2(self.norm4(x))
```

因此，第二个 MLP 的输出也会直接覆盖旧的 `x`。

这并不一定是错误，但与常见 Transformer 的写法不同。

常见 Transformer 更常使用：

$$
x\leftarrow x+\operatorname{Attention}(\operatorname{Norm}(x))
$$

$$
x\leftarrow x+\operatorname{MLP}(\operatorname{Norm}(x))
$$

阅读或调试代码时，需要明确这一点。

# 14. `FinalLayer`：将隐藏特征映射到最终输出

## 14.1 整体作用

`DiTBlock` 输出的仍然是隐藏特征：

$$
x\in\mathbb{R}^{B\times P\times D}
$$

但任务最终通常需要输出特定维度的数据，例如：

- 预测噪声；
- 预测轨迹状态；
- 预测速度；
- 预测坐标。

`FinalLayer` 用于将隐藏特征转换为目标输出。

---

## 14.2 初始化代码

```python
class FinalLayer(nn.Module):
    def __init__(self, hidden_size, output_size):
        super().__init__()
        self.norm_final = nn.LayerNorm(hidden_size)

        self.proj = nn.Sequential(
            nn.LayerNorm(hidden_size),
            nn.Linear(hidden_size, hidden_size * 4, bias=True),
            nn.GELU(approximate="tanh"),
            nn.LayerNorm(hidden_size * 4),
            nn.Linear(hidden_size * 4, output_size, bias=True)
        )

        self.adaLN_modulation = nn.Sequential(
            nn.SiLU(),
            nn.Linear(hidden_size, 2 * hidden_size, bias=True)
        )
```

---

## 14.3 使用条件向量生成最终调制参数

代码为：

```python
shift, scale = self.adaLN_modulation(y).chunk(2, dim=1)
```

输入：

$$
y\in\mathbb{R}^{B\times D}
$$

输出：

$$
[B,2D]
$$

拆分后：

$$
\text{shift},\text{scale}\in\mathbb{R}^{B\times D}
$$

然后：

```python
x = modulate(self.norm_final(x), shift, scale)
```

公式为：

$$
\boxed{
\widetilde{x}
=
\operatorname{LayerNorm}(x)
\odot(1+\operatorname{scale}(y))
+
\operatorname{shift}(y)
}
$$

---

## 14.4 最终投影

代码为：

```python
x = self.proj(x)
```

维度变化为：

$$
D
\longrightarrow
4D
\longrightarrow
\text{output\_size}
$$

如果：

$$
D=192
$$

以及：

$$
\text{output\_size}=4
$$

那么：

$$
192
\longrightarrow
768
\longrightarrow
4
$$

最终输出形状为：

$$
[B,P,4]
$$

# 18. 与普通 Transformer 相比，这段代码增加了什么？

普通 Transformer Block 常见结构为：

$$
x\leftarrow x+\operatorname{SelfAttention}(\operatorname{LayerNorm}(x))
$$

$$
x\leftarrow x+\operatorname{MLP}(\operatorname{LayerNorm}(x))
$$

当前 `DiTBlock` 增加了：

1. 时间条件向量 $y$；
2. 自适应 LayerNorm 调制；
3. 条件门控；
4. 交叉注意力；
5. 第二个 MLP。

因此，它不仅可以让 token 互相交流，还可以：

- 根据扩散时间步调整内部计算；
- 从外部场景信息中主动读取内容。

# 19. `adaLN-Zero` 名称需要如何理解？

类注释中写道：

```python
A DiT block with adaptive layer norm zero (adaLN-Zero)
```

adaLN-Zero 的核心思想通常是：

> 将条件调制分支中的某些输出层初始化为零，使网络在训练初期更接近恒等映射，再逐渐学习条件控制。

例如，如果：

$$
g_{\text{msa}}=0
$$

以及：

$$
g_{\text{mlp}}=0
$$

那么残差更新近似为：

$$
x_{\text{new}}=x
$$

但是需要特别注意：

> 当前文件片段中只定义了调制层，没有显式展示“将权重初始化为零”的代码。

零初始化可能在模型的其他位置完成，也可能尚未实现。仅根据当前片段，不能断言零初始化已经执行。

# 21. 常见问题

## 21.1 为什么条件向量 `y` 的形状是 `[B,D]`，而不是 `[B,P,D]`？

因为同一个样本中的 token 通常处于同一个扩散时间步。

因此，每个样本只需要一组条件参数：

$$
y_b\in\mathbb{R}^{D}
$$

再通过广播将其应用到该样本的所有 token。

---

## 21.2 为什么时间步使用正弦和余弦编码？

因为标量 $t$ 的表达能力较弱。

将它映射到多个频率以后，网络更容易区分不同时间位置，并学习平滑的时间变化规律。

---

## 21.3 自注意力和交叉注意力分别做什么？

自注意力：

$$
\text{让 }x\text{ 内部的 token 互相交流}
$$

交叉注意力：

$$
\text{让 }x\text{ 主动读取 cross\_c 中的外部信息}
$$

---

## 21.4 为什么还要加 MLP？

注意力主要负责信息搬运和组合。

MLP 负责对每个 token 内部的特征进行更复杂的非线性加工。

两者作用互补。

---

## 21.5 `gate_msa` 和 `gate_mlp` 是标量吗？

不是。

它们的形状通常为：

$$
[B,D]
$$

经过：

```python
unsqueeze(1)
```

以后变为：

$$
[B,1,D]
$$

再沿 token 维度广播。

因此，不同特征通道可以具有不同的门控强度。

# 23. 极简伪代码

```python
# 1. 把标量时间步变成条件向量
y = timestep_embedder(t)

# 2. 根据 y 生成自注意力和 MLP 分支的调制参数
shift_msa, scale_msa, gate_msa, \
shift_mlp, scale_mlp, gate_mlp = modulation(y)

# 3. 条件控制的自注意力
h = modulate(layer_norm(x), shift_msa, scale_msa)
x = x + gate_msa * self_attention(h)

# 4. 条件控制的 MLP
h = modulate(layer_norm(x), shift_mlp, scale_mlp)
x = x + gate_mlp * mlp_1(h)

# 5. 从外部上下文中读取信息
x = cross_attention(layer_norm(x), cross_c, cross_c)

# 6. 再进行一次特征变换
x = mlp_2(layer_norm(x))

# 7. 最终输出层再次进行条件调制并投影
x = modulate(layer_norm(x), shift_final, scale_final)
out = projection(x)
```

# 25. 最终总结

这段代码实现了一个适用于扩散模型的条件 Transformer 组件。

最关键的思想是：

1. 使用 `TimestepEmbedder` 将标量时间步 $t$ 转换为条件向量 $y$；
2. 使用 `modulate(...)` 让条件向量动态调整 LayerNorm 后的特征；
3. 使用 `gate_msa` 和 `gate_mlp` 控制残差分支强度；
4. 使用自注意力让 `x` 内部 token 互相交流；
5. 使用交叉注意力让 `x` 从 `cross_c` 中读取外部场景信息；
6. 使用 `FinalLayer` 将隐藏特征映射为任务所需的最终输出。

可以将其压缩成一句话：

> 这是一个能够感知扩散时间、整合外部上下文，并输出目标预测结果的条件 Transformer 模块。
