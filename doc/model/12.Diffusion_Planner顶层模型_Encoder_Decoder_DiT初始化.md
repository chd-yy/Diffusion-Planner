# Diffusion Planner 顶层模型代码详解：从 Encoder、Decoder 到 DiT 初始化

## 0. 这份代码在整个项目中做什么？

这份代码定义了 Diffusion Planner 的**顶层模型结构**。

它本身并不直接实现：

- 具体的场景编码算法；
- 具体的注意力计算；
- 具体的扩散采样循环；
- 具体的轨迹损失函数；
- 具体的碰撞规避引导。

它更像一个“总装配器”：

```text
输入场景
    ↓
Diffusion_Planner_Encoder
    ↓
Encoder
    ↓
场景特征 encoder_outputs
    ↓
Diffusion_Planner_Decoder
    ↓
Decoder
    ↓
扩散模型生成轨迹 decoder_outputs
```

这份代码还负责一件非常重要的事情：

> 为 Encoder 和 Decoder 内部的神经网络参数设置合理的初始值。

因此，这个文件可以理解为：

```text
模型总入口 + 子模块包装器 + 权重初始化策略
```

---

# 1. 原始代码骨架

去掉详细注释后，代码的主要结构如下：

```python
import torch
import torch.nn as nn

from diffusion_planner.model.module.encoder import Encoder
from diffusion_planner.model.module.decoder import Decoder


class Diffusion_Planner(nn.Module):
    def __init__(self, config):
        super().__init__()

        self.encoder = Diffusion_Planner_Encoder(config)
        self.decoder = Diffusion_Planner_Decoder(config)

    @property
    def sde(self):
        return self.decoder.decoder.sde
    
    def forward(self, inputs):
        encoder_outputs = self.encoder(inputs)
        decoder_outputs = self.decoder(encoder_outputs, inputs)

        return encoder_outputs, decoder_outputs


class Diffusion_Planner_Encoder(nn.Module):
    def __init__(self, config):
        super().__init__()

        self.encoder = Encoder(config)
        self.initialize_weights()

    def initialize_weights(self):
        def _basic_init(m):
            if isinstance(m, nn.Linear):
                torch.nn.init.xavier_uniform_(m.weight)
                if isinstance(m, nn.Linear) and m.bias is not None:
                    nn.init.constant_(m.bias, 0)
            elif isinstance(m, nn.LayerNorm):
                nn.init.constant_(m.bias, 0)
                nn.init.constant_(m.weight, 1.0)
            elif isinstance(m, nn.Embedding):
                nn.init.normal_(m.weight, mean=0.0, std=0.02)

        self.apply(_basic_init)

        nn.init.normal_(self.encoder.pos_emb.weight, std=0.02)
        nn.init.normal_(self.encoder.neighbor_encoder.type_emb.weight, std=0.02)
        nn.init.normal_(self.encoder.lane_encoder.speed_limit_emb.weight, std=0.02)
        nn.init.normal_(self.encoder.lane_encoder.traffic_emb.weight, std=0.02)

    def forward(self, inputs):
        encoder_outputs = self.encoder(inputs)
        return encoder_outputs
    

class Diffusion_Planner_Decoder(nn.Module):
    def __init__(self, config):
        super().__init__()

        self.decoder = Decoder(config)
        self.initialize_weights()

    def initialize_weights(self):
        def _basic_init(m):
            if isinstance(m, nn.Linear):
                torch.nn.init.xavier_uniform_(m.weight)
                if isinstance(m, nn.Linear) and m.bias is not None:
                    nn.init.constant_(m.bias, 0)
            elif isinstance(m, nn.LayerNorm):
                nn.init.constant_(m.bias, 0)
                nn.init.constant_(m.weight, 1.0)
            elif isinstance(m, nn.Embedding):
                nn.init.normal_(m.weight, mean=0.0, std=0.02)

        self.apply(_basic_init)

        nn.init.normal_(self.decoder.dit.t_embedder.mlp[0].weight, std=0.02)
        nn.init.normal_(self.decoder.dit.t_embedder.mlp[2].weight, std=0.02)

        for block in self.decoder.dit.blocks:
            nn.init.constant_(block.adaLN_modulation[-1].weight, 0)
            nn.init.constant_(block.adaLN_modulation[-1].bias, 0)

        nn.init.constant_(self.decoder.dit.final_layer.adaLN_modulation[-1].weight, 0)
        nn.init.constant_(self.decoder.dit.final_layer.adaLN_modulation[-1].bias, 0)
        nn.init.constant_(self.decoder.dit.final_layer.proj[-1].weight, 0)
        nn.init.constant_(self.decoder.dit.final_layer.proj[-1].bias, 0)

    def forward(self, encoder_outputs, inputs):
        decoder_outputs = self.decoder(encoder_outputs, inputs)
        return decoder_outputs
```

# 2. 先理解最外层：`Diffusion_Planner`

## 2.1 为什么继承 `nn.Module`？

```python
class Diffusion_Planner(nn.Module):
```

PyTorch 中，神经网络通常继承：

```python
nn.Module
```

这样才能使用 PyTorch 提供的模型管理机制，例如：

```python
model.parameters()
model.to("cuda")
model.train()
model.eval()
model.state_dict()
model.load_state_dict(...)
```

如果不继承 `nn.Module`，PyTorch 就无法自动发现模型中的参数。

---

## 2.2 为什么必须调用 `super().__init__()`？

```python
def __init__(self, config):
    super().__init__()
```

这一步会初始化 `nn.Module` 的内部机制。

只有调用它以后，PyTorch 才能正确注册：

- 子模块；
- 可训练参数；
- 缓冲区；
- 训练模式状态；
- 保存和加载所需的信息。

可以将其理解为：

> 告诉 PyTorch：这个 Python 类是一个神经网络模块，请开始管理它内部的层和参数。

---

## 2.3 顶层模型由哪两部分组成？

```python
self.encoder = Diffusion_Planner_Encoder(config)
self.decoder = Diffusion_Planner_Decoder(config)
```

模型被拆成两部分：

```text
Encoder：理解场景
Decoder：根据场景生成轨迹
```

直观类比：

```text
Encoder 像驾驶员的观察与理解系统：
- 前方有什么车？
- 哪条车道可以走？
- 红绿灯是什么状态？
- 导航想去哪里？

Decoder 像驾驶员的规划系统：
- 在当前场景下，未来应该怎么行驶？
```

# 3. `forward()`：数据如何流过模型？

## 3.1 外部调用方式

在 PyTorch 中，通常不会手动调用：

```python
model.forward(inputs)
```

而是直接写：

```python
encoder_outputs, decoder_outputs = model(inputs)
```

PyTorch 会自动调用：

```python
forward()
```

---

## 3.2 第一步：编码场景

```python
encoder_outputs = self.encoder(inputs)
```

这一行将原始输入送入 Encoder。

`inputs` 通常是一个字典，可能包含：

- 自车历史轨迹；
- 邻居车辆历史轨迹；
- 车道线；
- 地图元素；
- 交通灯状态；
- 车道限速；
- 导航信息；
- 有效性掩码。

Encoder 会把这些原始数据转换成高维特征。

形式上可以写成：

$$
\text{encoder\_outputs}
=
\operatorname{Encoder}(\text{inputs})
$$

---

## 3.3 第二步：Decoder 生成轨迹

```python
decoder_outputs = self.decoder(encoder_outputs, inputs)
```

Decoder 同时接收：

```python
encoder_outputs
```

以及：

```python
inputs
```

这说明 Decoder 不仅使用 Encoder 提取出的高维语义特征，还可能直接读取原始输入中的某些信息。

例如：

- 当前自车状态；
- 掩码；
- 轨迹归一化信息；
- 扩散采样所需的辅助变量；
- 邻居车辆信息；
- 训练标签。

形式上可以写成：

$$
\text{decoder\_outputs}
=
\operatorname{Decoder}
\left(
\text{encoder\_outputs},
\text{inputs}
\right)
$$

---

## 3.4 为什么同时返回两部分输出？

```python
return encoder_outputs, decoder_outputs
```

顶层模型不只返回最终轨迹，而是同时返回：

```python
encoder_outputs
decoder_outputs
```

这样做的好处包括：

- 训练时可以使用 Encoder 的中间结果；
- 调试时可以检查场景特征；
- 可视化时可以分析注意力或 token；
- Decoder 之外的损失函数可能还需要 Encoder 输出；
- 更容易定位问题发生在哪一部分。

# 4. `@property`：为什么可以直接访问 `model.sde`？

## 4.1 代码

```python
@property
def sde(self):
    return self.decoder.decoder.sde
```

外部可以写：

```python
model.sde
```

而不是：

```python
model.sde()
```

---

## 4.2 什么是 SDE？

SDE 是：

```text
Stochastic Differential Equation
```

即随机微分方程。

在扩散模型中，SDE 通常用来描述前向加噪过程。

例如，VP-SDE 常写成：

$$
\mathrm{d}x
=
-\frac{1}{2}\beta(t)x\,\mathrm{d}t
+
\sqrt{\beta(t)}\,\mathrm{d}w
$$

其中：

| 符号 | 含义 |
|---|---|
| $x$ | 当前样本 |
| $t$ | 扩散时间 |
| $\beta(t)$ | 噪声强度 |
| $\mathrm{d}w$ | 随机噪声增量 |

---

## 4.3 为什么属性路径是两层 `decoder`？

层级关系如下：

```text
Diffusion_Planner
    ↓ self.decoder
Diffusion_Planner_Decoder
    ↓ self.decoder
真正的 Decoder
    ↓ self.sde
SDE 对象
```

因此：

```python
self.decoder.decoder.sde
```

并不是写错了。

两个 `decoder` 代表不同层级：

```text
外层 decoder：包装器
内层 decoder：真正执行轨迹生成的 Decoder
```

---

# 5. 为什么还要再套一层 Encoder 包装器？

## 5.1 代码结构

```python
class Diffusion_Planner_Encoder(nn.Module):
    def __init__(self, config):
        super().__init__()

        self.encoder = Encoder(config)
        self.initialize_weights()
```

这层包装器的作用主要是：

1. 创建真正的 `Encoder`；
2. 对 Encoder 内部参数进行初始化；
3. 在 `forward()` 中调用真正的 Encoder。

---

## 5.2 为什么不直接在顶层写 `Encoder(config)`？

理论上可以。

例如：

```python
self.encoder = Encoder(config)
```

但独立包装后，结构更清晰：

```text
Diffusion_Planner_Encoder
    ├── 创建 Encoder
    ├── 初始化 Encoder
    └── 调用 Encoder
```

这样可以将：

```text
网络结构实现
```

和：

```text
项目级初始化策略
```

分离开。

# 6. Encoder 的基础初始化

## 6.1 局部函数 `_basic_init`

```python
def _basic_init(m):
```

这里定义了一个局部函数。

参数：

```python
m
```

表示当前正在处理的某个神经网络子模块。

后面：

```python
self.apply(_basic_init)
```

会递归遍历当前模块内部的所有子模块，并逐个执行：

```python
_basic_init(m)
```

---

## 6.2 `self.apply()` 是什么？

```python
self.apply(_basic_init)
```

`apply()` 会递归遍历：

- 当前模块自身；
- 所有直接子模块；
- 子模块内部的子模块；
- 更深层模块。

例如，如果 Encoder 内部有：

```text
Encoder
    ├── Linear
    ├── TransformerBlock
    │   ├── Linear
    │   ├── LayerNorm
    │   └── MLP
    │       ├── Linear
    │       └── Linear
    └── Embedding
```

那么所有匹配的层都会被初始化。

---

# 7. `nn.Linear` 为什么使用 Xavier 初始化？

## 7.1 代码

```python
if isinstance(m, nn.Linear):
    torch.nn.init.xavier_uniform_(m.weight)

    if isinstance(m, nn.Linear) and m.bias is not None:
        nn.init.constant_(m.bias, 0)
```

---

## 7.2 什么是全连接层？

一个全连接层通常执行：

$$
y=Wx+b
$$

其中：

| 符号 | 含义 |
|---|---|
| $x$ | 输入向量 |
| $W$ | 权重矩阵 |
| $b$ | 偏置 |
| $y$ | 输出向量 |

---

## 7.3 为什么不能随便初始化？

如果权重初始值过大，信号和梯度可能越来越大：

```text
梯度爆炸
```

如果权重初始值过小，信号和梯度可能越来越小：

```text
梯度消失
```

---

## 7.4 Xavier 初始化的思想

Xavier 初始化希望让信号在经过网络层时，方差大致保持稳定。

对于输入维度：

$$
n_{\text{in}}
$$

和输出维度：

$$
n_{\text{out}}
$$

Xavier 均匀初始化会从类似下面的范围中采样权重：

$$
W_{ij}
\sim
\mathcal{U}
\left(
-\sqrt{\frac{6}{n_{\text{in}}+n_{\text{out}}}},
\sqrt{\frac{6}{n_{\text{in}}+n_{\text{out}}}}
\right)
$$

直观理解：

> 输入维度和输出维度越大，单个权重的初始绝对值通常越小。

---

## 7.5 为什么偏置初始化为 `0`？

```python
nn.init.constant_(m.bias, 0)
```

初始时不希望额外加入人为偏移，因此通常将偏置设为：

$$
b=0
$$

---

## 7.6 代码中的重复判断

```python
if isinstance(m, nn.Linear):
    ...
    if isinstance(m, nn.Linear) and m.bias is not None:
```

外层已经确认：

```python
isinstance(m, nn.Linear)
```

所以内层再次判断一次类型是重复的。

更简洁的写法是：

```python
if isinstance(m, nn.Linear):
    nn.init.xavier_uniform_(m.weight)

    if m.bias is not None:
        nn.init.constant_(m.bias, 0)
```

原始代码逻辑没有问题，只是略显冗余。

---

# 8. `nn.LayerNorm` 为什么初始化为 `weight=1`、`bias=0`？

## 8.1 代码

```python
elif isinstance(m, nn.LayerNorm):
    nn.init.constant_(m.bias, 0)
    nn.init.constant_(m.weight, 1.0)
```

---

## 8.2 LayerNorm 做什么？

LayerNorm 会先对输入进行归一化，再应用可学习缩放和平移：

$$
\operatorname{LayerNorm}(x)
=
\gamma
\frac{x-\mu}{\sqrt{\sigma^2+\varepsilon}}
+
\beta
$$

其中：

| 符号 | 含义 |
|---|---|
| $\mu$ | 均值 |
| $\sigma^2$ | 方差 |
| $\gamma$ | 可学习缩放参数，对应 `weight` |
| $\beta$ | 可学习偏移参数，对应 `bias` |

---

## 8.3 为什么这样初始化？

设置：

$$
\gamma=1
$$

$$
\beta=0
$$

意味着训练刚开始时：

> LayerNorm 只执行标准化，不额外放大、缩小或平移结果。

这是非常常见的初始化方式。

---

# 9. `nn.Embedding` 为什么用正态分布初始化？

## 9.1 代码

```python
elif isinstance(m, nn.Embedding):
    nn.init.normal_(m.weight, mean=0.0, std=0.02)
```

---

## 9.2 什么是 Embedding？

Embedding 的作用是：

> 将一个离散类别编号映射成一个可训练的高维向量。

例如，交通灯状态可能有：

```text
0：红灯
1：黄灯
2：绿灯
3：未知
```

Embedding 可以把它们映射成向量：

```text
红灯 → [ 0.01, -0.02, ... ]
黄灯 → [ 0.03,  0.01, ... ]
绿灯 → [-0.02,  0.04, ... ]
```

训练过程中，这些向量会不断更新。

---

## 9.3 为什么标准差使用 `0.02`？

```python
std=0.02
```

意味着初始嵌入向量都比较小，避免训练初期引入过强扰动。

这种初始化方式在 Transformer 类模型中很常见。

# 13. 什么是 DiT？

## 13.1 DiT 的全称

DiT 是：

```text
Diffusion Transformer
```

即扩散 Transformer。

它使用 Transformer 结构完成扩散模型中的去噪预测。

---

## 13.2 输入和输出

在轨迹扩散模型中，DiT 可能接收：

- 当前带噪轨迹；
- 扩散时间步；
- Encoder 输出的场景条件；
- 掩码；
- 其他辅助信息。

然后输出：

- 噪声预测；
- velocity 预测；
- score 预测；
- 或其他等价参数化结果。

---

## 13.3 为什么需要时间步嵌入？

同一条轨迹在不同扩散时刻的噪声强度不同。

例如：

```text
t 很小：
轨迹已经比较干净，只需要微调。

t 很大：
轨迹几乎是随机噪声，需要大幅修正。
```

所以网络必须知道当前时刻：

$$
t
$$

# 14. 时间步嵌入 MLP 的初始化

## 14.1 代码

```python
nn.init.normal_(self.decoder.dit.t_embedder.mlp[0].weight, std=0.02)
nn.init.normal_(self.decoder.dit.t_embedder.mlp[2].weight, std=0.02)
```

---

## 14.2 为什么是 `mlp[0]` 和 `mlp[2]`？

一个常见的时间嵌入 MLP 结构类似：

```python
nn.Sequential(
    nn.Linear(...),   # mlp[0]
    nn.SiLU(),        # mlp[1]
    nn.Linear(...),   # mlp[2]
)
```

因此：

```python
mlp[0]
mlp[2]
```

通常是两个全连接层。

---

## 14.3 为什么显式重新初始化？

前面的：

```python
self.apply(_basic_init)
```

已经会初始化 Linear 层。

但代码又对时间嵌入 MLP 的权重使用：

```python
std=0.02
```

的正态分布重新初始化。

说明作者希望时间嵌入层使用特定的初始化策略，而不是通用 Xavier 初始化。

# 15. adaLN 是什么？

## 15.1 全称

adaLN 通常表示：

```text
Adaptive Layer Normalization
```

即自适应层归一化。

---

## 15.2 普通 LayerNorm

普通 LayerNorm 为：

$$
\operatorname{LN}(x)
=
\gamma
\frac{x-\mu}{\sqrt{\sigma^2+\varepsilon}}
+
\beta
$$

其中：

$$
\gamma
$$

和：

$$
\beta
$$

是可学习参数，但对于所有样本通常相同。

---

## 15.3 Adaptive LayerNorm

adaLN 会根据条件动态生成调制参数。

例如，条件可能包含：

- 扩散时间步；
- 场景特征；
- 自车状态；
- 地图条件。

于是：

$$
\gamma
=
\gamma(c)
$$

$$
\beta
=
\beta(c)
$$

其中：

$$
c
$$

是条件向量。

这样，同一个 Transformer block 可以针对不同扩散时刻、不同场景采用不同的特征调制方式。

---

# 16. 为什么 adaLN 最后一层初始化为零？

## 16.1 代码

```python
for block in self.decoder.dit.blocks:
    nn.init.constant_(block.adaLN_modulation[-1].weight, 0)
    nn.init.constant_(block.adaLN_modulation[-1].bias, 0)
```

每个 DiT block 中的 adaLN 调制层最后一层被初始化为：

$$
W=0
$$

$$
b=0
$$

---

## 16.2 直观解释

假设调制层输出：

$$
m=Wc+b
$$

如果：

$$
W=0
$$

$$
b=0
$$

则训练初期：

$$
m=0
$$

也就是说：

> 条件调制模块在训练刚开始时，不会立刻对主干网络产生强烈干扰。

随着训练进行，参数会逐渐学会合适的调制方式。

---

## 16.3 为什么这样更稳定？

深层 Transformer 中，如果每个 block 刚开始就受到随机条件调制，可能导致信号变化过大。

零初始化使网络从一个更简单、更接近恒等映射的状态开始。

可以类比为：

```text
先让网络学会基本传递信息，
再逐渐学会根据条件进行复杂调整。
```

---

# 17. 为什么最终输出层也初始化为零？

## 17.1 代码

```python
nn.init.constant_(self.decoder.dit.final_layer.adaLN_modulation[-1].weight, 0)
nn.init.constant_(self.decoder.dit.final_layer.adaLN_modulation[-1].bias, 0)

nn.init.constant_(self.decoder.dit.final_layer.proj[-1].weight, 0)
nn.init.constant_(self.decoder.dit.final_layer.proj[-1].bias, 0)
```

---

## 17.2 最终投影层做什么？

最终投影层通常将隐藏特征映射成模型输出。

例如：

$$
h
\rightarrow
\epsilon_\theta(x_t,t)
$$

或者：

$$
h
\rightarrow
v_\theta(x_t,t)
$$

---

## 17.3 为什么输出从零开始？

如果最终投影层权重和偏置都初始化为零，则训练刚开始时：

$$
\operatorname{output}\approx0
$$

这样做有两个好处：

1. 模型初始行为简单、可控；
2. 避免随机大输出扰乱扩散模型训练。

直观类比：

```text
模型一开始先保持沉默，
然后逐渐学会应该输出什么修正量。
```

# 23. 代码中值得注意的细节

## 23.1 `self.apply(_basic_init)` 会初始化包装器内所有子模块

代码写的是：

```python
self.apply(_basic_init)
```

而不是：

```python
self.encoder.apply(_basic_init)
```

或：

```python
self.decoder.apply(_basic_init)
```

由于当前包装器中的主要子模块就是内部 Encoder 或 Decoder，所以效果基本一致。

不过需要意识到：

> 如果未来在包装器中增加其他神经网络层，它们也会一起被初始化。

---

## 23.2 专门初始化会覆盖基础初始化

例如：

```python
self.apply(_basic_init)
```

先对所有 Linear 层执行 Xavier 初始化。

随后：

```python
nn.init.normal_(self.decoder.dit.t_embedder.mlp[0].weight, std=0.02)
```

会再次修改时间嵌入层权重。

因此最终以**后执行的初始化**为准。

---

## 23.3 零初始化不等于“这些层永远不会学习”

例如：

```python
nn.init.constant_(block.adaLN_modulation[-1].weight, 0)
```

只是设置训练起点。

训练时，优化器仍然会更新这些参数。

---

## 23.4 顶层 `sde` 属性是只读入口

外部可以写：

```python
model.sde
```

但当前代码没有定义 setter，因此它主要作为只读访问入口。

# 24. 一个简化示例

假设 Encoder 做的事情是：

```python
scene_feature = encoder(inputs)
```

Decoder 做的事情是：

```python
trajectory = decoder(scene_feature, inputs)
```

那么整个模型可以简化为：

```python
class SimplePlanner(nn.Module):
    def __init__(self):
        super().__init__()

        self.encoder = Encoder()
        self.decoder = Decoder()

    def forward(self, inputs):
        features = self.encoder(inputs)
        trajectory = self.decoder(features, inputs)

        return features, trajectory
```

当前代码在这个基础上增加了：

- 统一的初始化策略；
- Encoder 特定嵌入初始化；
- Decoder 的 DiT 特定初始化；
- `sde` 属性访问入口。

# 26. 初始化策略总表

| 层或参数 | 初始化方式 | 目的 |
|---|---|---|
| `nn.Linear.weight` | Xavier 均匀初始化 | 尽量保持层间信号方差稳定 |
| `nn.Linear.bias` | `0` | 初始时不引入额外偏移 |
| `nn.LayerNorm.weight` | `1` | 初始时不额外缩放归一化结果 |
| `nn.LayerNorm.bias` | `0` | 初始时不额外平移归一化结果 |
| `nn.Embedding.weight` | 正态分布，`std=0.02` | 使用较小随机值初始化离散类别向量 |
| Encoder 特定嵌入 | 正态分布，`std=0.02` | 明确控制位置、类型、限速和交通灯嵌入 |
| DiT 时间嵌入 MLP | 正态分布，`std=0.02` | 使用扩散 Transformer 常见初始化策略 |
| DiT block 的 adaLN 最后一层 | `0` | 让条件调制从接近无影响的状态开始 |
| DiT 最终 adaLN 最后一层 | `0` | 稳定最终输出层的条件调制 |
| DiT 最终投影层 | `0` | 使模型初始输出接近零 |
