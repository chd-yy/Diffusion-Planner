# diffusion_planner/data_process/agent_process.py 详解

本文档详细解释 `diffusion_planner/data_process/agent_process.py` 中的函数、变量、类型和调用关系。这个文件负责把 nuPlan 原始 tracked objects 转成模型需要的动态 agent 历史、静态目标特征，以及训练用的周车未来轨迹标签。

最终它参与生成 `.npz` 里的这些字段：

```text
neighbor_agents_past
neighbor_agents_future
static_objects
```

其中 `neighbor_agents_past` 和 `static_objects` 也会在闭环推理时作为模型输入。

## 文件位置

```text
diffusion_planner/data_process/agent_process.py
```

## 上游和下游调用关系

离线训练预处理链路：

```text
DataProcessor.work()
    -> sampled_tracked_objects_to_array_list(sampled_past_observations)
    -> sampled_static_objects_to_array_list(present_tracked_objects)
    -> agent_past_process(...)
    -> sampled_tracked_objects_to_array_list(sampled_future_observations)
    -> agent_future_process(...)
    -> np.savez(...)
```

闭环仿真/推理链路：

```text
DataProcessor.observation_adapter()
    -> sampled_tracked_objects_to_array_list(observation_buffer)
    -> sampled_static_objects_to_array_list(observation_buffer[-1])
    -> agent_past_process(...)
    -> convert_to_model_inputs()
```

训练读取链路：

```text
DiffusionPlannerData.__getitem__()
    -> data['neighbor_agents_past']
    -> data['neighbor_agents_future']
    -> data['static_objects']

train_epoch()
    -> inputs['neighbor_agents_past']
    -> inputs['static_objects']
    -> neighbors_future
```

## _extract_agent_array()

函数定义：

```python
def _extract_agent_array(tracked_objects, track_token_ids, object_types):
```

作用：从一帧 nuPlan `tracked_objects` 中筛选指定类别的动态目标，并转换成 `AgentInternalIndex` 规定格式的 numpy 数组。

输入：

| 参数 | 含义 |
| --- | --- |
| `tracked_objects` | 当前帧所有 tracked objects |
| `track_token_ids` | track token 到整数 id 的映射字典 |
| `object_types` | 需要保留的目标类别列表 |

返回：

```python
return output, track_token_ids, agent_types
```

| 返回值 | 含义 |
| --- | --- |
| `output` | 当前帧 agent 状态数组 |
| `track_token_ids` | 更新后的 token 到整数 id 映射 |
| `agent_types` | 当前帧每个 agent 的 `TrackedObjectType` |

### 第一步：按类别筛选目标

```python
agents = tracked_objects.get_tracked_objects_of_types(object_types)
```

调用方传入的动态目标类别是：

```python
object_types = [
    TrackedObjectType.VEHICLE,
    TrackedObjectType.PEDESTRIAN,
    TrackedObjectType.BICYCLE,
]
```

因此只保留车辆、行人、自行车。

### 第二步：初始化输出数组

```python
output = np.zeros((len(agents), AgentInternalIndex.dim()), dtype=np.float64)
max_agent_id = len(track_token_ids)
```

`AgentInternalIndex.dim()` 是 nuPlan 规定的 agent 状态维度。

`track_token_ids` 跨帧共享，用来保证同一个 `agent.track_token` 在不同时间帧中得到同一个整数 id。

### 第三步：分配整数 track id

```python
if agent.track_token not in track_token_ids:
    track_token_ids[agent.track_token] = max_agent_id
    max_agent_id += 1

track_token_int = track_token_ids[agent.track_token]
```

nuPlan 原始 `track_token` 通常是字符串。这里把它映射为从 0 开始增长的整数，便于后续 padding 和轨迹对齐。

### 第四步：写入 agent 状态字段

```python
output[idx, AgentInternalIndex.track_token()] = float(track_token_int)
output[idx, AgentInternalIndex.vx()] = agent.velocity.x
output[idx, AgentInternalIndex.vy()] = agent.velocity.y
output[idx, AgentInternalIndex.heading()] = agent.center.heading
output[idx, AgentInternalIndex.width()] = agent.box.width
output[idx, AgentInternalIndex.length()] = agent.box.length
output[idx, AgentInternalIndex.x()] = agent.center.x
output[idx, AgentInternalIndex.y()] = agent.center.y
agent_types.append(agent.tracked_object_type)
```

这些值此时仍然是全局坐标系下的量。坐标转换在 `agent_past_process()` 和 `agent_future_process()` 里进行。

## _filter_agents_array()

函数定义：

```python
def _filter_agents_array(agents, reverse: bool = False):
```

作用：过滤多帧 agent 数组，只保留在关键帧出现过的 agent。

参数：

| 参数 | 含义 |
| --- | --- |
| `agents` | 多帧 agent array 列表 |
| `reverse` | 是否用最后一帧作为关键帧 |

关键逻辑：

```python
target_array = agents[-1] if reverse else agents[0]
```

- `reverse=True`：用最后一帧作为关键帧，常用于历史轨迹，最后一帧就是当前帧。
- `reverse=False`：用第一帧作为关键帧，常用于未来轨迹，第一帧就是当前帧。

### 分步骤解释

遍历每一帧：

```python
for i in range(len(agents)):
    rows = []
```

遍历当前帧每个 agent：

```python
agent_id = float(agents[i][j, int(AgentInternalIndex.track_token())])
```

判断该 agent 是否存在于关键帧：

```python
is_in_target_frame = bool(
    (agent_id == target_array[:, AgentInternalIndex.track_token()]).max()
)
```

如果存在，则保留：

```python
rows.append(agents[i][j, :].squeeze())
```

当前帧处理完后：

```python
if len(rows) > 0:
    agents[i] = np.stack(rows)
else:
    agents[i] = np.empty((0, agents[i].shape[1]), dtype=np.float32)
```

这个函数不做 padding，只做过滤。padding 由 `_pad_agent_states()` 或 `_pad_agent_states_with_zeros()` 完成。

## _pad_agent_states()

函数定义：

```python
def _pad_agent_states(agent_trajectories, reverse: bool):
```

作用：对多帧 agent 轨迹做“最近状态填充”，让每一帧 agent 数量和顺序一致。

这个函数用于历史轨迹处理：

```python
padded_agent_states = _pad_agent_states(agent_history, reverse=True)
```

### 为什么要 padding

nuPlan 每帧检测到的 agent 数量可能不同。例如：

```text
t0: A, B
t1: A
t2: A, B
```

模型需要固定 shape，不能每帧 agent 数量不同。这个函数会用最近一次可用状态填补缺失帧。

### 第一步：处理方向

```python
if reverse:
    agent_trajectories = agent_trajectories[::-1]
```

历史轨迹中 `reverse=True`，意味着从当前帧往过去填充。这样能保证“当前帧存在的 agent”在过去缺失时，用靠近当前的状态补齐。

### 第二步：建立 track id 到行号映射

```python
key_frame = agent_trajectories[0]
id_row_mapping = {}

for idx, val in enumerate(key_frame[:, track_id_idx]):
    id_row_mapping[int(val)] = idx
```

`key_frame` 决定输出 agent 的数量和顺序。

`id_row_mapping` 例子：

```python
{
    0: 0,
    5: 1,
    8: 2,
}
```

表示 track id 0 放第 0 行，track id 5 放第 1 行，track id 8 放第 2 行。

### 第三步：逐帧更新 current_state

```python
current_state = np.zeros((key_frame.shape[0], key_frame.shape[1]), dtype=np.float64)

for idx in range(len(agent_trajectories)):
    frame = agent_trajectories[idx]

    for row_idx in range(frame.shape[0]):
        mapped_row = id_row_mapping[int(frame[row_idx, track_id_idx])]
        current_state[mapped_row, :] = frame[row_idx, :]

    agent_trajectories[idx] = current_state.copy()
```

`current_state` 保存“最近一次看到的 agent 状态”。如果某一帧缺失某个 agent，就沿用之前保存的状态。

### 第四步：恢复时间顺序

```python
if reverse:
    agent_trajectories = agent_trajectories[::-1]
```

返回后时间顺序恢复为原始过去到现在。

## _pad_agent_states_with_zeros()

函数定义：

```python
def _pad_agent_states_with_zeros(agent_trajectories):
```

作用：对未来 agent 轨迹做 zero padding。缺失的未来状态保持为 0。

它用于：

```python
padded_agent_states = _pad_agent_states_with_zeros(local_coords_agent_states)
```

与 `_pad_agent_states()` 的区别：

| 函数 | 用途 | 缺失帧处理 |
| --- | --- | --- |
| `_pad_agent_states()` | 历史轨迹 | 用最近状态补齐 |
| `_pad_agent_states_with_zeros()` | 未来轨迹标签 | 缺失保持 0 |

### 分步骤解释

以第一帧作为关键帧：

```python
key_frame = agent_trajectories[0]
```

初始化输出：

```python
pad_agent_trajectories = np.zeros(
    (len(agent_trajectories), key_frame.shape[0], key_frame.shape[1]),
    dtype=np.float32,
)
```

逐帧填入存在的 agent：

```python
for idx in range(len(agent_trajectories)):
    frame = agent_trajectories[idx]
    mapped_rows = frame[:, track_id_idx]

    for row_idx in range(key_frame.shape[0]):
        if row_idx in mapped_rows:
            pad_agent_trajectories[idx, row_idx] = frame[frame[:, track_id_idx] == row_idx]
```

如果某个 agent 未来某帧不存在，则对应位置保持 0。

## agent_past_process()

函数定义：

```python
def agent_past_process(
    past_ego_states,
    past_tracked_objects,
    tracked_objects_types,
    num_agents,
    static_objects,
    static_objects_types,
    num_static,
    max_ped_bike,
    anchor_ego_state,
):
```

这是本文件最核心的函数之一。它生成：

```text
ego
neighbor_agents_past
selected_indices
static_objects
```

返回：

```python
return ego, agents, selected_indices, static_objects
```

### 输入参数

| 参数 | 含义 |
| --- | --- |
| `past_ego_states` | ego 历史状态数组，训练预处理时有，推理时为 None |
| `past_tracked_objects` | 多帧动态 agent 数组列表 |
| `tracked_objects_types` | 多帧动态 agent 类型列表 |
| `num_agents` | 最多保留的动态 agent 数量，默认 32 |
| `static_objects` | 当前帧静态目标数组 |
| `static_objects_types` | 静态目标类型列表 |
| `num_static` | 最多保留的静态目标数量，默认 5 |
| `max_ped_bike` | 行人/自行车最多优先保留数量，默认 10 |
| `anchor_ego_state` | 当前 ego rear axle pose `[x, y, heading]` |

### 第一步：处理 ego 历史

```python
if past_ego_states is not None:
    ego = convert_absolute_quantities_to_relative(ego_history, anchor_ego_state)
else:
    ego = None
```

训练预处理时，`past_ego_states` 来自：

```python
get_ego_past_array_from_scenario(...)
```

推理时：

```python
ego_agent_past = None
```

因此 `ego` 为 `None`。

### 第二步：过滤动态 agent 历史

```python
agent_history = _filter_agents_array(agents, reverse=True)
agent_types = tracked_objects_types[-1]
```

`reverse=True` 表示以最后一帧，也就是当前帧作为关键帧，只保留当前帧存在的 agent。

`agent_types = tracked_objects_types[-1]` 使用当前帧类别作为最终类别。

### 第三步：处理没有动态 agent 的情况

```python
if agent_history[-1].shape[0] == 0:
    agents_array = np.zeros((len(agent_history), 0, agents_states_dim))
```

如果当前帧没有动态 agent，则中间数组 agent 数量为 0。

后续最终 `agents` 会初始化成固定 `num_agents` 个，全 0。

### 第四步：动态 agent 历史 padding 和坐标转换

```python
padded_agent_states = _pad_agent_states(agent_history, reverse=True)
```

让每一帧 agent 数量和顺序一致。

逐帧转局部坐标：

```python
for agent_state in padded_agent_states:
    local_coords_agent_states.append(
        convert_absolute_quantities_to_relative(agent_state, anchor_ego_state, 'agent')
    )
```

转换后所有动态 agent 的 `x/y/heading/vx/vy` 都在 ego 局部坐标系。

### 第五步：构造 8 维 agent 基础特征

```python
agents_array = np.zeros(
    (len(local_coords_agent_states), local_coords_agent_states[0].shape[0], agents_states_dim)
)
```

形状：

```text
[num_frames, num_current_agents, 8]
```

8 维含义：

```text
x, y, cos(heading), sin(heading), vx, vy, width, length
```

代码写入：

```python
agents_array[i, :, 0] = local_coords_agent_states[i][:, AgentInternalIndex.x()]
agents_array[i, :, 1] = local_coords_agent_states[i][:, AgentInternalIndex.y()]
agents_array[i, :, 2] = np.cos(local_coords_agent_states[i][:, AgentInternalIndex.heading()])
agents_array[i, :, 3] = np.sin(local_coords_agent_states[i][:, AgentInternalIndex.heading()])
agents_array[i, :, 4] = local_coords_agent_states[i][:, AgentInternalIndex.vx()]
agents_array[i, :, 5] = local_coords_agent_states[i][:, AgentInternalIndex.vy()]
agents_array[i, :, 6] = local_coords_agent_states[i][:, AgentInternalIndex.width()]
agents_array[i, :, 7] = local_coords_agent_states[i][:, AgentInternalIndex.length()]
```

注意：代码注释写的是 `length, width`，但实际写入顺序是：

```text
width, length
```

因为第 6 维来自 `AgentInternalIndex.width()`，第 7 维来自 `AgentInternalIndex.length()`。

### 第六步：处理静态目标基础特征

```python
static_objects_array = np.zeros((static_objects.shape[0], 6))
```

6 维含义：

```text
x, y, cos(heading), sin(heading), width, length
```

如果存在静态目标：

```python
local_coords_static_objects_states = convert_absolute_quantities_to_relative(
    static_objects,
    anchor_ego_state,
    'static',
)
```

写入：

```python
static_objects_array[:, 0] = local_coords_static_objects_states[:, 0]
static_objects_array[:, 1] = local_coords_static_objects_states[:, 1]
static_objects_array[:, 2] = np.cos(local_coords_static_objects_states[:, 2])
static_objects_array[:, 3] = np.sin(local_coords_static_objects_states[:, 2])
static_objects_array[:, 4] = local_coords_static_objects_states[:, 3]
static_objects_array[:, 5] = local_coords_static_objects_states[:, 4]
```

### 第七步：选择固定数量动态 agent

最终模型需要固定 shape：

```python
agents = np.zeros(
    (num_agents, agents_array.shape[0], agents_array.shape[-1] + 3),
    dtype=np.float32,
)
```

默认形状：

```text
[32, 21, 11]
```

其中：

```text
11 = 8 个状态特征 + 3 个类别 one-hot
```

计算当前帧距离：

```python
distance_to_ego = np.linalg.norm(agents_array[-1, :, :2], axis=-1)
sorted_indices = np.argsort(distance_to_ego)
```

分类索引：

```python
ped_bike_indices = [
    i for i in sorted_indices
    if agent_types[i] in (TrackedObjectType.PEDESTRIAN, TrackedObjectType.BICYCLE)
]
vehicle_indices = [
    i for i in sorted_indices
    if agent_types[i] == TrackedObjectType.VEHICLE
]
```

筛选策略：

1. 如果总 agent 数不超过 `num_agents`，直接按距离取。
2. 如果超过 `num_agents`，优先限制行人/自行车数量不超过 `max_ped_bike`。
3. 车辆全部优先纳入候选。
4. 如果还有空位，再用剩余行人/自行车补。
5. 最后按距离排序，截断到 `num_agents`。

这样做是为了避免行人/自行车过多时挤掉车辆。

### 第八步：写入动态 agent 类别 one-hot

```python
for i, j in enumerate(selected_indices):
    agents[i, :, :agents_array.shape[-1]] = agents_array[:, j, :]

    if agent_types[j] == TrackedObjectType.VEHICLE:
        agents[i, :, agents_array.shape[-1]:] = [1, 0, 0]
    elif agent_types[j] == TrackedObjectType.PEDESTRIAN:
        agents[i, :, agents_array.shape[-1]:] = [0, 1, 0]
    else:
        agents[i, :, agents_array.shape[-1]:] = [0, 0, 1]
```

最终 `agents` 每个点的 11 维含义：

```text
x, y, cos(heading), sin(heading), vx, vy, width, length,
type_vehicle, type_pedestrian, type_bicycle
```

`selected_indices` 很重要，后续 `agent_future_process()` 会用它从未来轨迹中取对应 agent 的未来标签。

### 第九步：选择固定数量静态目标

初始化：

```python
static_objects = np.zeros((num_static, static_objects_array.shape[-1] + 4), dtype=np.float32)
```

默认形状：

```text
[5, 10]
```

其中：

```text
10 = 6 个静态目标基础特征 + 4 个类别 one-hot
```

按距离选择：

```python
static_distance_to_ego = np.linalg.norm(static_objects_array[:, :2], axis=-1)
static_indices = list(np.argsort(static_distance_to_ego))[:num_static]
```

写入类别 one-hot：

```text
CZONE_SIGN      -> [1, 0, 0, 0]
BARRIER         -> [0, 1, 0, 0]
TRAFFIC_CONE    -> [0, 0, 1, 0]
GENERIC_OBJECT  -> [0, 0, 0, 1]
```

## agent_future_process()

函数定义：

```python
def agent_future_process(anchor_ego_state, future_tracked_objects, num_agents, agent_index):
```

作用：生成动态 agent 的未来轨迹标签，用于训练 `neighbors_future_gt`。

调用位置：

```python
neighbor_agents_future = agent_future_process(
    anchor_ego_state,
    future_tracked_objects_array_list,
    self.num_agents,
    neighbor_indices,
)
```

参数：

| 参数 | 含义 |
| --- | --- |
| `anchor_ego_state` | 当前 ego rear axle pose |
| `future_tracked_objects` | 当前帧 + 未来帧 agent array 列表 |
| `num_agents` | 输出固定 agent 数量 |
| `agent_index` | `agent_past_process()` 选中的 agent 原始索引 |

### 第一步：过滤未来 agent

```python
agent_future = _filter_agents_array(future_tracked_objects)
```

默认 `reverse=False`，所以用第一帧作为关键帧。这里第一帧是当前帧：

```python
sampled_future_observations = [present_tracked_objects] + future_tracked_objects
```

因此只保留当前帧存在的 agent。

### 第二步：未来状态转 ego 局部坐标

```python
for agent_state in agent_future:
    local_coords_agent_states.append(
        convert_absolute_quantities_to_relative(agent_state, anchor_ego_state, 'agent')
    )
```

### 第三步：zero padding

```python
padded_agent_states = _pad_agent_states_with_zeros(local_coords_agent_states)
```

缺失未来帧保持为 0。训练时这些 0 会被 mask 掉：

```python
mask = torch.sum(torch.ne(neighbors_future[..., :3], 0), dim=-1) == 0
```

### 第四步：根据 agent_index 对齐历史选中的 agent

```python
agent_futures = np.zeros(
    shape=(num_agents, padded_agent_states.shape[0] - 1, 3),
    dtype=np.float32,
)

for i, j in enumerate(agent_index):
    agent_futures[i] = padded_agent_states[
        1:,
        j,
        [AgentInternalIndex.x(), AgentInternalIndex.y(), AgentInternalIndex.heading()],
    ]
```

为什么从 `1:` 开始？

因为 `padded_agent_states[0]` 是当前帧，不是未来帧。训练标签只需要未来轨迹。

输出默认形状：

```text
[32, 80, 3]
```

最后一维：

```text
x, y, heading
```

## 注意事项

1. `agent_past_process()` 中动态 agent 最终第 6、7 维实际是 `width, length`，虽然注释里有一处写成了 `length, width`。
2. `agent_past_process()` 推理时 `past_ego_states=None`，所以返回的 `ego` 是 `None`，调用方会忽略它。
3. `_pad_agent_states_with_zeros()` 依赖 track id 是从 0 开始的整数，并用 `row_idx in mapped_rows` 判断当前帧是否存在该 agent。
4. `agent_future_process()` 用 `agent_index` 对齐历史阶段选中的 agent；这是保证 `neighbor_agents_past[i]` 和 `neighbor_agents_future[i]` 属于同一个目标的关键。
5. 缺失的未来 agent 轨迹用 0 表示，训练时会通过 mask 排除。

## 函数输入输出数据结构速查

这一节补充 `agent_process.py` 每个函数的输入、输出结构。这里 `T` 表示时间帧数，`N` 表示动态 agent 数量，`S` 表示静态目标数量。

### _extract_agent_array()

```python
def _extract_agent_array(tracked_objects, track_token_ids, object_types):
```

| 项 | 数据结构 | 含义 |
|---|---|---|
| 输入 `tracked_objects` | nuPlan `TrackedObjects` | 某一帧检测/跟踪到的所有目标 |
| 输入 `track_token_ids` | `Dict[str, int]` | 跨帧维护的 track token 到整数 id 的映射 |
| 输入 `object_types` | `List[TrackedObjectType]` | 需要保留的目标类别，例如车辆、行人、自行车 |
| 输出 `output` | `np.ndarray`，形状 `[N, AgentInternalIndex.dim()]` | 当前帧筛选后的动态 agent 状态数组 |
| 输出 `track_token_ids` | `Dict[str, int]` | 更新后的 track token 映射 |
| 输出 `agent_types` | `List[TrackedObjectType]` | `output` 每一行对应的 agent 类型 |

`output` 主要字段包括 `track_token,x,y,heading,vx,vy,width,length` 等，具体列号由 `AgentInternalIndex` 决定。

### sampled_tracked_objects_to_array_list()

```python
def sampled_tracked_objects_to_array_list(past_tracked_objects):
```

| 项 | 数据结构 | 含义 |
|---|---|---|
| 输入 `past_tracked_objects` | `List[DetectionsTracks]` 或 `List[TrackedObjects]` | 多帧动态目标检测结果 |
| 输出 `output` | `List[np.ndarray]`，长度 `T`，每项形状 `[N_t, AgentInternalIndex.dim()]` | 每一帧的动态 agent 状态数组 |
| 输出 `output_types` | `List[List[TrackedObjectType]]`，长度 `T` | 每一帧每个 agent 的类别 |

这里 `N_t` 允许每帧不同，因为某个 agent 可能只在部分帧出现。

### sampled_static_objects_to_array_list()

```python
def sampled_static_objects_to_array_list(present_tracked_objects):
```

| 项 | 数据结构 | 含义 |
|---|---|---|
| 输入 `present_tracked_objects` | `DetectionsTracks` 或 `TrackedObjects` | 当前帧检测到的目标 |
| 输出 `output` | `np.ndarray`，形状 `[S, 5]` | 静态目标数组，字段为 `x,y,heading,width,length` |
| 输出 `agent_types` | `List[TrackedObjectType]` | 每个静态目标的类别 |

静态目标类别包括 `CZONE_SIGN`、`BARRIER`、`TRAFFIC_CONE`、`GENERIC_OBJECT`。

### _filter_agents_array()

```python
def _filter_agents_array(agents, reverse: bool = False):
```

| 项 | 数据结构 | 含义 |
|---|---|---|
| 输入 `agents` | `List[np.ndarray]`，长度 `T`，每项形状 `[N_t, D]` | 多帧 agent 状态，`D` 通常为 `AgentInternalIndex.dim()` |
| 输入 `reverse` | `bool` | `False` 以第一帧为关键帧；`True` 以最后一帧为关键帧 |
| 输出 | `List[np.ndarray]`，长度 `T` | 过滤后的多帧 agent 状态，只保留关键帧中出现过的 agent |

输出仍然是 list，尚未 padding；每一帧 agent 数量仍可能不同。

### _pad_agent_states()

```python
def _pad_agent_states(agent_trajectories, reverse: bool):
```

| 项 | 数据结构 | 含义 |
|---|---|---|
| 输入 `agent_trajectories` | `List[np.ndarray]`，长度 `T`，每项形状 `[N_t, D]` | 过滤后的历史 agent 状态 |
| 输入 `reverse` | `bool` | `True` 表示从当前帧向过去填充，历史处理使用这个模式 |
| 输出 | `List[np.ndarray]` 或等价序列，长度 `T`，每项形状 `[N_key, D]` | 每一帧 agent 数量和顺序一致，缺失帧用最近一次可用状态填充 |

`N_key` 由关键帧中的 agent 数量决定。`track_token` 用于把同一个 agent 对齐到同一行。

### _pad_agent_states_with_zeros()

```python
def _pad_agent_states_with_zeros(agent_trajectories):
```

| 项 | 数据结构 | 含义 |
|---|---|---|
| 输入 `agent_trajectories` | `List[np.ndarray]`，长度 `T`，每项形状 `[N_t, D]` | 未来 agent 状态 |
| 输出 | `np.ndarray`，形状 `[T, N_key, D]` | 对齐到第一帧 agent 顺序后的未来状态；缺失位置保持 0 |

这个函数用于未来标签，和 `_pad_agent_states()` 的区别是缺失帧不复制最近状态，而是用 0。

### agent_past_process()

```python
def agent_past_process(
    past_ego_states,
    past_tracked_objects,
    tracked_objects_types,
    num_agents,
    static_objects,
    static_objects_types,
    num_static,
    max_ped_bike,
    anchor_ego_state,
):
```

| 项 | 数据结构 | 含义 |
|---|---|---|
| 输入 `past_ego_states` | `np.ndarray`，形状 `[T, 7]` 或 `None` | ego 历史状态；推理阶段可为 `None` |
| 输入 `past_tracked_objects` | `List[np.ndarray]`，长度 `T` | 多帧动态 agent 状态 |
| 输入 `tracked_objects_types` | `List[List[TrackedObjectType]]` | 多帧动态 agent 类别 |
| 输入 `num_agents` | `int` | 最终保留的动态 agent 数量 |
| 输入 `static_objects` | `np.ndarray`，形状 `[S, 5]` | 当前帧静态目标 |
| 输入 `static_objects_types` | `List[TrackedObjectType]` | 静态目标类别 |
| 输入 `num_static` | `int` | 最终保留的静态目标数量 |
| 输入 `max_ped_bike` | `int` | 行人和自行车最多优先保留数量 |
| 输入 `anchor_ego_state` | `np.ndarray`，形状 `[7]` 或更长 | 当前 ego anchor，用于坐标转换 |

输出数据结构：

| 输出 | 数据结构 | 含义 |
|---|---|---|
| `ego` | `np.ndarray`，形状 `[T, 7]`，或 `None` | 转到当前 ego 坐标系下的自车历史 |
| `agents` | `np.ndarray`，形状 `[num_agents, T, 11]` | 固定数量动态 agent 历史模型输入 |
| `selected_indices` | `List[int]` 或 `np.ndarray` | 被选中的 agent 在中间 `agents_array` 中的索引，用于未来标签对齐 |
| `static_objects` | `np.ndarray`，形状 `[num_static, 10]` | 固定数量静态目标模型输入 |

`agents` 的 11 维含义：

```text
x, y, cos(heading), sin(heading), vx, vy, width, length, vehicle_onehot, pedestrian_onehot, bicycle_onehot
```

`static_objects` 的 10 维含义：

```text
x, y, cos(heading), sin(heading), width, length, czone_sign, barrier, traffic_cone, generic_object
```

### agent_future_process()

```python
def agent_future_process(anchor_ego_state, future_tracked_objects, num_agents, agent_index):
```

| 项 | 数据结构 | 含义 |
|---|---|---|
| 输入 `anchor_ego_state` | `np.ndarray`，形状 `[7]` 或更长 | 当前 ego anchor，用于将未来 agent 转到局部坐标系 |
