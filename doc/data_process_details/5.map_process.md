# diffusion_planner/data_process/map_process.py 详解

本文档详细解释 `diffusion_planner/data_process/map_process.py` 的函数、变量、类名和调用关系。这个文件负责把 nuPlan 地图 API 查询到的原始矢量地图对象，转换成 Diffusion Planner 模型可直接使用的固定尺寸地图输入。

它处理的核心地图信息包括：

- lane / lane connector 中心线
- lane 左右边界
- lane 限速
- lane 交通灯状态
- lane 所属 roadblock id
- route 上的 lanes

最终输出字段会进入训练样本 `.npz` 或闭环推理模型输入：

```text
lanes
lanes_speed_limit
lanes_has_speed_limit
route_lanes
route_lanes_speed_limit
route_lanes_has_speed_limit
```

## 文件位置

```text
diffusion_planner/data_process/map_process.py
```

## 上游和下游调用关系

`map_process.py` 被 `DataProcessor` 调用。

离线训练预处理：

```text
DataProcessor.work()
    -> get_neighbor_vector_set_map()
    -> map_process()
    -> data.update(vector_map)
    -> np.savez(...)
```

闭环仿真/推理：

```text
DataProcessor.observation_adapter()
    -> get_neighbor_vector_set_map()
    -> map_process()
    -> data.update(vector_map)
    -> convert_to_model_inputs()
```

在 `DataProcessor.__init__()` 中，地图相关配置是：

```python
self._radius = 100
self._map_features = ['LANE', 'LEFT_BOUNDARY', 'RIGHT_BOUNDARY', 'ROUTE_LANES']
self._max_elements = {
    'LANE': config.lane_num,
    'LEFT_BOUNDARY': config.lane_num,
    'RIGHT_BOUNDARY': config.lane_num,
    'ROUTE_LANES': config.route_num,
}
self._max_points = {
    'LANE': config.lane_len,
    'LEFT_BOUNDARY': config.lane_len,
    'RIGHT_BOUNDARY': config.lane_len,
    'ROUTE_LANES': config.route_len,
}
```

默认训练配置下常见尺寸是：

```text
lane_num = 70
lane_len = 20
route_num = 25
route_len = 20
```

## _get_lane_polylines()

函数定义：

```python
def _get_lane_polylines(
    map_api: AbstractMap,
    point: Point2D,
    radius: float,
) -> Tuple[MapObjectPolylines, MapObjectPolylines, MapObjectPolylines, LaneSegmentLaneIDs]:
```

作用：从 nuPlan `map_api` 中提取 `point` 附近 `radius` 范围内的 lane 和 lane connector 几何信息。

输入：

| 参数 | 含义 |
| --- | --- |
| `map_api` | nuPlan 地图 API |
| `point` | 查询中心点，通常是当前 ego rear axle 的全局坐标 |
| `radius` | 查询半径，项目默认 100 米 |

实际返回 7 个对象：

```python
return (
    MapObjectPolylines(lanes_mid),
    MapObjectPolylines(lanes_left),
    MapObjectPolylines(lanes_right),
    LaneSegmentLaneIDs(lane_ids),
    lane_speed_limit,
    lane_has_speed_limit,
    lane_roadblock_ids,
)
```

虽然类型注解只写了 4 个返回类型，但实际返回 7 项。

### 第一步：初始化容器

```python
lanes_mid = []
lanes_left = []
lanes_right = []
lane_ids = []
lane_speed_limit = []
lane_has_speed_limit = []
lane_roadblock_ids = []
```

含义：

| 变量 | 含义 |
| --- | --- |
| `lanes_mid` | lane / lane connector 的中心线 baseline path |
| `lanes_left` | 左边界 polyline |
| `lanes_right` | 右边界 polyline |
| `lane_ids` | lane 或 lane connector 的 id |
| `lane_speed_limit` | 每条 lane 的限速值 |
| `lane_has_speed_limit` | 每条 lane 是否有限速 |
| `lane_roadblock_ids` | 每条 lane 所属 roadblock id |

### 第二步：查询地图语义层

```python
layer_names = [SemanticMapLayer.LANE, SemanticMapLayer.LANE_CONNECTOR]
layers = map_api.get_proximal_map_objects(point, radius, layer_names)
```

只查询：

- `SemanticMapLayer.LANE`
- `SemanticMapLayer.LANE_CONNECTOR`

`LANE_CONNECTOR` 通常出现在路口、转弯连接区域。

### 第三步：合并 lane 和 lane connector

```python
map_objects = []
for layer_name in layer_names:
    map_objects += layers[layer_name]
```

`layers` 是按语义层分组的字典，这里合并成一个列表。

### 第四步：按离 ego 的距离排序

```python
map_objects.sort(
    key=lambda map_obj: float(get_distance_between_map_object_and_point(point, map_obj))
)
```

后续 `_convert_lane_to_fixed_size()` 也会按距离再次筛选，但这里先把地图对象按距离排序，保证更近的 lane 优先进入原始列表。

### 第五步：逐条提取 lane 几何和属性

中心线：

```python
baseline_path_polyline = [
    Point2D(node.x, node.y)
    for node in map_obj.baseline_path.discrete_path
]
lanes_mid.append(baseline_path_polyline)
```

左边界：

```python
lanes_left.append([
    Point2D(node.x, node.y)
    for node in map_obj.left_boundary.discrete_path
])
```

右边界：

```python
lanes_right.append([
    Point2D(node.x, node.y)
    for node in map_obj.right_boundary.discrete_path
])
```

lane id：

```python
lane_ids.append(map_obj.id)
```

限速：

```python
if map_obj.speed_limit_mps is None:
    lane_speed_limit.append(0.0)
    lane_has_speed_limit.append(False)
else:
    lane_speed_limit.append(map_obj.speed_limit_mps)
    lane_has_speed_limit.append(True)
```

roadblock id：

```python
lane_roadblock_ids.append(map_obj.get_roadblock_id())
```

`lane_roadblock_ids` 后续会被命名为 `lane_route`，用来判断 lane 是否属于导航 route。

## get_neighbor_vector_set_map()

函数定义：

```python
def get_neighbor_vector_set_map(
    map_api: AbstractMap,
    map_features: List[str],
    point: Point2D,
    radius: float,
    traffic_light_status_data: List[TrafficLightStatusData],
)
```

作用：根据 `map_features` 从 nuPlan 地图中提取 ego 附近的矢量地图原始数据。

调用位置：

```python
coords, traffic_light_data, speed_limit, lane_route = get_neighbor_vector_set_map(
    map_api,
    self._map_features,
    ego_coords,
    self._radius,
    traffic_light_data,
)
```

其中：

```python
self._map_features = ['LANE', 'LEFT_BOUNDARY', 'RIGHT_BOUNDARY', 'ROUTE_LANES']
```

返回：

| 返回值 | 含义 |
| --- | --- |
| `coords` | 地图几何 polyline 字典 |
| `traffic_light_data` | lane 的交通灯 one-hot 数据 |
| `speed_limit` | lane 限速信息 |
| `lane_route` | 每条 lane 所属 roadblock id |

### 第一步：把字符串 feature 转成 VectorFeatureLayer

```python
feature_layers = []
for feature_name in map_features:
    try:
        feature_layers.append(VectorFeatureLayer[feature_name])
    except KeyError:
        raise ValueError(...)
```

如果 `feature_name` 不是 nuPlan `VectorFeatureLayer` 中的合法枚举，会直接报错。

### 第二步：提取 LANE

```python
if VectorFeatureLayer.LANE in feature_layers:
    lanes_mid, lanes_left, lanes_right, lane_ids, lane_speed_limit, lane_has_speed_limit, lane_route = _get_lane_polylines(...)
```

如果需要 `LANE`，就调用 `_get_lane_polylines()`。

保存中心线：

```python
coords[VectorFeatureLayer.LANE.name] = lanes_mid
```

保存限速：

```python
speed_limit['lane_has_speed_limit'] = np.array(lane_has_speed_limit, dtype=np.bool_)
speed_limit['lane_speed_limit'] = np.array(lane_speed_limit, dtype=np.float32)
```

保存交通灯：

```python
traffic_light_data[VectorFeatureLayer.LANE.name] = get_traffic_light_encoding(
    lane_ids,
    traffic_light_status_data,
)
```

`get_traffic_light_encoding()` 是 nuPlan 提供的函数，会根据当前交通灯状态和 lane id 生成 one-hot 编码。后续每个 lane 点都会带上 4 维交通灯状态：

```text
green, yellow, red, unknown
```

保存左右边界：

```python
if VectorFeatureLayer.LEFT_BOUNDARY in feature_layers:
    coords[VectorFeatureLayer.LEFT_BOUNDARY.name] = MapObjectPolylines(lanes_left.polylines)

if VectorFeatureLayer.RIGHT_BOUNDARY in feature_layers:
    coords[VectorFeatureLayer.RIGHT_BOUNDARY.name] = MapObjectPolylines(lanes_right.polylines)
```

### 第三步：提取 polygon 类型地图层

```python
for feature_layer in feature_layers:
    if feature_layer in VectorFeatureLayerMapping.available_polygon_layers():
        polygons = get_map_object_polygons(
            map_api,
            point,
            radius,
            VectorFeatureLayerMapping.semantic_map_layer(feature_layer),
        )
        coords[feature_layer.name] = polygons
```

当前项目默认 `map_features` 主要是 lane 相关特征，`ROUTE_LANES` 并不是通过这里单独从 map API 查询出来的，而是在 `map_process()` 中根据 `route_roadblock_ids` 从 `lanes` 中筛选出来。

## _interpolate_points()

函数定义：

```python
def _interpolate_points(line, num_point):
```

作用：把一条点数不固定的 polyline 重新采样成固定 `num_point` 个点。

代码：

```python
line = LineString(line)
new_line = np.concatenate([
    line.interpolate(d).coords._coords
    for d in np.linspace(0, line.length, num_point)
])
return new_line
```

分步骤解释：

1. `LineString(line)` 把离散点序列转成 shapely 折线对象。
2. `np.linspace(0, line.length, num_point)` 在折线总长度上均匀取 `num_point` 个距离。
3. `line.interpolate(d)` 得到距离起点 `d` 处的插值点。
4. 把所有插值点拼成 `[num_point, 2]` 数组。

例子：

```text
line = [[0, 0], [10, 0]]
num_point = 3
```

输出大致是：

```text
[[0, 0], [5, 0], [10, 0]]
```

这个函数被 `_convert_lane_to_fixed_size()` 调用，用于统一中心线、左边界、右边界的点数。

## _convert_lane_to_fixed_size()

函数定义：

```python
def _convert_lane_to_fixed_size(
    ego_pose,
    feature_coords,
    speed_limit,
    lane_route,
    left_boundary,
    right_boundary,
    feature_tl_data,
    max_elements,
    max_points,
    traffic_light_encoding_dim,
):
```

作用：把原始 lane 数据转换成固定尺寸数组。

输入含义：

| 参数 | 含义 |
| --- | --- |
| `ego_pose` | 当前 ego/anchor 位姿 `[x, y, heading]` |
| `feature_coords` | 所有 lane 中心线坐标列表 |
| `speed_limit` | lane 限速字典 |
| `lane_route` | 每条 lane 所属 roadblock id |
| `left_boundary` | 所有 lane 左边界坐标列表 |
| `right_boundary` | 所有 lane 右边界坐标列表 |
| `feature_tl_data` | 每条 lane 对应交通灯编码 |
| `max_elements` | 最多保留多少条 lane，例如 70 |
| `max_points` | 每条 lane 固定采样点数，例如 20 |
| `traffic_light_encoding_dim` | 交通灯编码维度，通常为 4 |

返回：

```python
return (
    coords_array,
    left_array,
    right_array,
    tl_data_array,
    avails_array,
    lane_has_speed_limit_array,
    lane_speed_limit_array,
    lane_routes,
)
```

### 第一步：检查交通灯数据数量

```python
if feature_tl_data is not None and len(feature_coords) != len(feature_tl_data):
    raise ValueError(...)
```

如果 lane 数量和交通灯编码数量不一致，说明数据没有对齐，直接报错。

### 第二步：取出限速数组

```python
lane_has_speed_limit = speed_limit['lane_has_speed_limit']
lane_speed_limit = speed_limit['lane_speed_limit']
```

`speed_limit` 来自 `get_neighbor_vector_set_map()`。

### 第三步：初始化固定尺寸输出

```python
coords_array = np.zeros((max_elements, max_points, 2), dtype=np.float64)
left_array = np.zeros((max_elements, max_points, 2), dtype=np.float64)
right_array = np.zeros((max_elements, max_points, 2), dtype=np.float64)
```

分别保存中心线、左边界、右边界。

```python
lane_has_speed_limit_array = np.zeros((max_elements, 1), dtype=np.bool_)
lane_speed_limit_array = np.zeros((max_elements, 1), dtype=np.float32)
lane_routes = []
avails_array = np.zeros((max_elements, max_points), dtype=np.bool_)
```

`avails_array` 是有效性 mask：

```text
True: 真实 lane 点
False: padding 点
```

交通灯数组：

```python
tl_data_array = (
    np.zeros((max_elements, max_points, traffic_light_encoding_dim), dtype=np.float32)
    if feature_tl_data is not None else None
)
```

默认形状大致为：

```text
[70, 20, 4]
```

### 第四步：按距离 ego 远近选择 lane

```python
mapping = {}
for i, e in enumerate(feature_coords):
    dist = np.linalg.norm(e - ego_pose[None, :2], axis=-1).min()
    mapping[i] = dist

mapping = sorted(mapping.items(), key=lambda item: item[1])
sorted_elements = mapping[:max_elements]
```

对每条 lane：

1. `e` 是该 lane 的中心线点数组。
2. `ego_pose[None, :2]` 是 ego 的 `[x, y]`。
3. 计算该 lane 所有点到 ego 的距离。
4. 取最小距离作为 lane 到 ego 的距离。
5. 按距离排序，保留最近 `max_elements` 条。

### 第五步：对选中的 lane 插值并写入数组

```python
for idx, element_idx in enumerate(sorted_elements):
    element_coords = feature_coords[element_idx[0]]
    left_coords = left_boundary[element_idx[0]]
    right_coords = right_boundary[element_idx[0]]

    element_coords = _interpolate_points(element_coords, max_points)
    left_coords = _interpolate_points(left_coords, max_points)
    right_coords = _interpolate_points(right_coords, max_points)
```

`element_idx` 是二元组：

```text
(原始 lane 索引, 距离)
```

对中心线、左边界、右边界都插值到固定 `max_points` 个点。

写入固定数组：

```python
coords_array[idx] = element_coords
left_array[idx] = left_coords
right_array[idx] = right_coords
avails_array[idx] = True
```

写入限速和 route：

```python
lane_has_speed_limit_array[idx] = lane_has_speed_limit[element_idx[0]]
lane_speed_limit_array[idx] = lane_speed_limit[element_idx[0]]
lane_routes.append(lane_route[element_idx[0]])
```

写入交通灯：

```python
if tl_data_array is not None and feature_tl_data is not None:
    tl_data_array[idx] = feature_tl_data[element_idx[0]]
```

注意：这里 `avails_array[idx] = True` 会把该 lane 的所有 `max_points` 都标为有效，因为已经插值生成固定长度。

## _prune_route_by_connectivity()

函数定义：

```python
def _prune_route_by_connectivity(
    route_roadblock_ids: List[str],
    roadblock_ids: Set[str],
) -> List[str]:
```

作用：从完整 route 中裁剪出当前地图查询范围内连续的一段 route roadblocks。

输入：

| 参数 | 含义 |
| --- | --- |
| `route_roadblock_ids` | 修正后的完整 route roadblock id 序列 |
| `roadblock_ids` | 当前提取到的 lane 所属 roadblock id 集合 |

代码：

```python
pruned_route_roadblock_ids = []
route_start = False

for roadblock_id in route_roadblock_ids:
    if roadblock_id in roadblock_ids:
        pruned_route_roadblock_ids.append(roadblock_id)
        route_start = True
    elif route_start:
        break

return pruned_route_roadblock_ids
```

逻辑：

1. 沿原始 route 顺序遍历。
2. 忽略还没进入当前查询半径的 route roadblocks。
3. 一旦遇到当前范围内的 route roadblock，就开始收集。
4. 如果已经开始收集后又遇到一个不在当前范围内的 roadblock，说明当前局部范围内的连续 route 结束，停止。

例子：

```text
route_roadblock_ids = [R1, R2, R3, R4, R5, R6]
roadblock_ids       = {R3, R4, R5}
```

输出：

```text
[R3, R4, R5]
```

如果：

```text
roadblock_ids = {R3, R4, R6}
```

输出：

```text
[R3, R4]
```

因为 `R5` 不在当前范围内，route 已经断开，后面的 `R6` 不再保留。

## _lane_polyline_process()

函数定义：

```python
def _lane_polyline_process(polylines, left_boundary, right_boundary, avails, traffic_light):
```

作用：把局部坐标系下的 lane 中心线、方向向量、左右边界相对向量和交通灯状态拼成每个点 12 维的模型输入特征。

输入：

| 参数 | 形状 | 含义 |
| --- | --- | --- |
| `polylines` | `[num_lanes, num_points, 2]` | lane 中心线点 |
| `left_boundary` | `[num_lanes, num_points, 2]` | 左边界点 |
| `right_boundary` | `[num_lanes, num_points, 2]` | 右边界点 |
| `avails` | `[num_lanes, num_points]` | 有效性 mask |
| `traffic_light` | `[num_lanes, num_points, 4]` | 交通灯 one-hot |

输出：

```text
new_polylines: [num_lanes, num_points, 12]
```

12 维组成：

```text
0:1   center_x, center_y
2:3   direction_x, direction_y
4:5   left_boundary_dx, left_boundary_dy
6:7   right_boundary_dx, right_boundary_dy
8:11  traffic_green, traffic_yellow, traffic_red, traffic_unknown
```

### 第一步：初始化输出

```python
dim = 12
new_polylines = np.zeros(
    shape=(polylines.shape[0], polylines.shape[1], dim),
    dtype=np.float32,
)
```

### 第二步：跳过 padding lane

```python
for i in range(polylines.shape[0]):
    if avails[i][0]:
        ...
```

`avails[i][0]` 为 `True` 表示第 `i` 条 lane 是真实数据。如果是 padding lane，保持全 0。

### 第三步：计算中心线方向向量

```python
polyline = polylines[i]
polyline_vector = polyline[1:] - polyline[:-1]
polyline_vector = np.insert(polyline_vector, polyline_vector.shape[0], 0, axis=0)
```

对于 `N` 个中心线点，只能得到 `N-1` 个相邻方向向量，所以最后补一个 `[0, 0]`。

例子：

```text
polyline = [[0, 0], [2, 0], [5, 0]]
polyline_vector = [[2, 0], [3, 0], [0, 0]]
```

### 第四步：对齐左右边界方向

左边界：

```python
if np.linalg.norm(left_boundary[i, -1] - polyline[0]) < np.linalg.norm(left_boundary[i, 0] - polyline[0]):
    left_boundary[i] = np.flip(left_boundary[i], axis=0)
```

右边界：

```python
if np.linalg.norm(right_boundary[i, -1] - polyline[0]) < np.linalg.norm(right_boundary[i, 0] - polyline[0]):
    right_boundary[i] = np.flip(right_boundary[i], axis=0)
```

含义：如果边界线的最后一个点比第一个点更接近中心线起点，说明边界点序列方向可能和中心线相反，需要翻转。这样中心线第 `j` 个点和边界第 `j` 个点才大致对应。

### 第五步：计算中心线到边界的相对向量

```python
polyline_to_left = left_boundary[i] - polyline
polyline_to_right = right_boundary[i] - polyline
```

这不是保存边界点绝对坐标，而是保存：

```text
从中心线点指向左边界点的向量
从中心线点指向右边界点的向量
```

这样模型同时知道 lane 中心线位置、方向和车道宽度/边界形状。

### 第六步：拼接成 12 维特征

```python
new_polylines[i] = np.concatenate(
    [polyline, polyline_vector, polyline_to_left, polyline_to_right, traffic_light[i]],
    axis=-1,
)
```

拼接后每个点是：

```text
[center_x, center_y,
 direction_x, direction_y,
 left_dx, left_dy,
 right_dx, right_dy,
 traffic_green, traffic_yellow, traffic_red, traffic_unknown]
```

## map_process()

函数定义：

```python
def map_process(
    route_roadblock_ids,
    anchor_ego_state,
    coords,
    traffic_light_data,
    speed_limit,
    lane_route,
    map_features,
    max_elements,
    max_points,
):
```

这是本文件的主处理函数。它把 `get_neighbor_vector_set_map()` 返回的原始地图对象转换成模型输入。

输入：

| 参数 | 含义 |
| --- | --- |
| `route_roadblock_ids` | 修正后的导航 route roadblock id |
| `anchor_ego_state` | 当前 ego rear axle pose `[x, y, heading]` |
| `coords` | 原始地图 polyline 字典 |
| `traffic_light_data` | lane 交通灯编码 |
| `speed_limit` | lane 限速字典 |
| `lane_route` | 每条 lane 对应 roadblock id |
| `map_features` | 要处理的地图特征名称 |
| `max_elements` | 每类地图元素最大数量 |
| `max_points` | 每个地图元素最大点数 |

输出：

```python
vector_map_output = {
    'lanes': vector_map_lanes,
    'lanes_speed_limit': lane_speed_limit_array,
    'lanes_has_speed_limit': lane_has_speed_limit_array,
    'route_lanes': vector_map_route_lanes,
    'route_lanes_speed_limit': route_lanes_speed_limit,
    'route_lanes_has_speed_limit': route_lanes_has_speed_limit,
}
```

默认形状大致是：

| 字段 | 默认形状 | 含义 |
| --- | --- | --- |
| `lanes` | `[70, 20, 12]` | ego 附近 lane 特征 |
| `lanes_speed_limit` | `[70, 1]` | lane 限速 |
| `lanes_has_speed_limit` | `[70, 1]` | lane 是否有限速 |
| `route_lanes` | `[25, 20, 12]` | route 上的 lane 特征 |
| `route_lanes_speed_limit` | `[25, 1]` | route lane 限速 |
| `route_lanes_has_speed_limit` | `[25, 1]` | route lane 是否有限速 |

### 第一步：把 nuPlan 对象转成 list + numpy

```python
list_array_data = {}

for feature_name, feature_coords in coords.items():
    list_feature_coords = []
    for element_coords in feature_coords.to_vector():
        list_feature_coords.append(np.array(element_coords, dtype=np.float64))

    list_array_data[f"coords.{feature_name}"] = list_feature_coords
```

`coords` 原本是 nuPlan 的 `MapObjectPolylines` 等对象。这里统一转换成 Python list，里面每个元素是 numpy 数组。

如果存在交通灯数据：

```python
if feature_name in traffic_light_data:
    list_feature_tl_data = []
    for element_tl_data in traffic_light_data[feature_name].to_vector():
        list_feature_tl_data.append(np.array(element_tl_data, dtype=np.float64))

    list_array_data[f"traffic_light_data.{feature_name}"] = list_feature_tl_data
```

转换后 `list_array_data` 中常见 key：

```text
coords.LANE
coords.LEFT_BOUNDARY
coords.RIGHT_BOUNDARY
traffic_light_data.LANE
```

### 第二步：处理 LANE 并转 ego 局部坐标

```python
traffic_light_encoding_dim = LaneSegmentTrafficLightData.encoding_dim()
```

通常为 4。

遍历 `map_features`：

```python
for feature_name in map_features:
    if f"coords.{feature_name}" in list_array_data:
        ...
```

当 `feature_name == 'LANE'` 时：

```python
coords, left_coords, right_coords, tl_data, avails, lane_has_speed_limit_array, lane_speed_limit_array, lane_routes = _convert_lane_to_fixed_size(...)
```

这里得到的是固定尺寸但仍在全局坐标系下的中心线和边界。

随后转换左右边界到 ego 局部坐标：

```python
left_coords = vector_set_coordinates_to_local_frame(left_coords, avails, anchor_ego_state)
right_coords = vector_set_coordinates_to_local_frame(right_coords, avails, anchor_ego_state)
```

保存到中间结果：

```python
array_output["vector_set_map.coords.LEFT_BOUNDARY"] = left_coords
array_output["vector_set_map.coords.RIGHT_BOUNDARY"] = right_coords
```

### 第三步：判断哪些 lane 属于 route

在处理 `LANE` 时，会生成 `lane_on_route`：

```python
lane_on_route = []
pruned_lane_roadblock_ids = [route for route in route_roadblock_ids if route in lane_routes]
pruned_route_roadblock_ids = _prune_route_by_connectivity(route_roadblock_ids, pruned_lane_roadblock_ids)

    lane_on_route.append(route in pruned_route_roadblock_ids)
```

变量含义：

| 变量 | 含义 |
| --- | --- |
| `lane_routes` | 被选中的每条 lane 所属 roadblock id |
| `route_roadblock_ids` | 导航 route roadblock id 序列 |
| `pruned_lane_roadblock_ids` | 当前局部地图范围内能看到的 route roadblocks |
| `pruned_route_roadblock_ids` | 进一步裁剪成连续的一段 route |
| `lane_on_route` | 每条 lane 是否属于当前局部 route |

`lane_on_route[i] == True` 表示第 `i` 条 lane 会被写入 `route_lanes`。

### 第四步：跳过 LEFT_BOUNDARY 和 RIGHT_BOUNDARY

```python
elif feature_name == 'LEFT_BOUNDARY' or feature_name == 'RIGHT_BOUNDARY':
    continue
```

左右边界已经在处理 `LANE` 时和中心线一起处理了，所以单独遍历到它们时直接跳过。

### 第五步：转换中心线坐标到 ego 局部坐标

```python
coords = vector_set_coordinates_to_local_frame(coords, avails, anchor_ego_state)

array_output[f"vector_set_map.coords.{feature_name}"] = coords
array_output[f"vector_set_map.availabilities.{feature_name}"] = avails

if tl_data is not None:
    array_output[f"vector_set_map.traffic_light_data.{feature_name}"] = tl_data
```

对 `LANE` 来说，这里把中心线 `coords` 从全局坐标变成 ego 局部坐标。

### 第六步：生成 `lanes`

第二轮遍历 `map_features`：

```python
for feature_name in map_features:
    if feature_name == "LANE":
        ...
```

取出中间结果：

```python
polylines = array_output['vector_set_map.coords.LANE']
left_boundary = array_output["vector_set_map.coords.LEFT_BOUNDARY"]
right_boundary = array_output["vector_set_map.coords.RIGHT_BOUNDARY"]
traffic_light_state = array_output['vector_set_map.traffic_light_data.LANE']
avails = array_output['vector_set_map.availabilities.LANE']
```

调用：

```python
vector_map_lanes = _lane_polyline_process(
    polylines,
    left_boundary,
    right_boundary,
    avails,
    traffic_light_state,
)
```

得到：

```text
vector_map_lanes: [lane_num, lane_len, 12]
```

### 第七步：生成 `route_lanes`

当 `feature_name == "ROUTE_LANES"` 时：

```python
vector_map_route_lanes = np.zeros(
    (max_elements["ROUTE_LANES"], vector_map_lanes.shape[-2], vector_map_lanes.shape[-1]),
    dtype=np.float32,
)
route_lanes_speed_limit = np.zeros((max_elements["ROUTE_LANES"], 1), dtype=np.float32)
route_lanes_has_speed_limit = np.zeros((max_elements["ROUTE_LANES"], 1), dtype=np.bool_)
```

然后遍历所有 lane：

```python
loc = 0
for i in range(len(lane_on_route)):
    if lane_on_route[i] == True:
        vector_map_route_lanes[loc] = vector_map_lanes[i]
        route_lanes_speed_limit[loc] = lane_speed_limit_array[i]
        route_lanes_has_speed_limit[loc] = lane_has_speed_limit_array[i]
        loc += 1

    if loc == max_elements["ROUTE_LANES"]:
        break
```

逻辑：

1. `lane_on_route[i]` 为 True 的 lane 被认为在导航 route 上。
2. 把对应的 `vector_map_lanes[i]` 拷贝到 `vector_map_route_lanes[loc]`。
3. 同步拷贝限速和是否有限速。
4. 最多保留 `route_num` 条 route lane。

### 第八步：组织输出

```python
vector_map_output = {
    'lanes': vector_map_lanes,
    'lanes_speed_limit': lane_speed_limit_array,
    'lanes_has_speed_limit': lane_has_speed_limit_array,
    'route_lanes': vector_map_route_lanes,
    'route_lanes_speed_limit': route_lanes_speed_limit,
    'route_lanes_has_speed_limit': route_lanes_has_speed_limit,
}
```

这个字典会被 `DataProcessor` 合并到训练样本或推理输入中：

```python

```

## 注意事项

1. `get_neighbor_vector_set_map()` 默认不会单独查询 `ROUTE_LANES`，route lane 是后续从 `LANE` 中筛出来的。
2. `_get_lane_polylines()` 的类型注解返回值数量和实际返回值数量不一致，实际返回 7 项。
3. `_convert_lane_to_fixed_size()` 会按 lane 到 ego 的最近距离筛选最多 `max_elements` 条 lane。
4. `map_process()` 假设 `LANE`、`LEFT_BOUNDARY`、`RIGHT_BOUNDARY` 都存在；默认配置满足这个假设。
5. `route_lanes` 依赖 `route_roadblock_ids`，而这个列表通常已经被 `route_roadblock_correction()` 修正过。
6. 所有地图坐标在进入最终 `lanes` / `route_lanes` 前都会通过 `vector_set_coordinates_to_local_frame()` 转换到当前 ego 局部坐标系。
