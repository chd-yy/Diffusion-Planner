# diffusion_planner/utils/dataset.py 详解

本文档详细解释 `diffusion_planner/utils/dataset.py` 中的类、函数、变量、调用关系，以及每个方法的输入输出数据结构。

这个文件定义了训练数据集类：

```python
class DiffusionPlannerData(Dataset)
```

它的作用是：

1. 读取 `diffusion_planner_training.json` 这类样本列表文件。
2. 根据索引读取对应的 `.npz` 训练样本。
3. 从 `.npz` 中取出模型训练需要的字段。
4. 按固定顺序返回 tuple，供 `DataLoader` 组 batch。

## 文件位置

```text
diffusion_planner/utils/dataset.py
```

## 上下游调用关系

### 上游：DataProcessor 生成 .npz

训练样本由数据预处理生成：

```text
data_process.py
    -> DataProcessor.work(scenarios)
        -> save_to_disk(...)
            -> {save_path}/{map_name}_{token}.npz
```

同时 `data_process.py` 会生成样本列表：

```text
diffusion_planner_training.json
```

这个 JSON 文件保存 `.npz` 文件名列表。

### 中游：DiffusionPlannerData 读取 .npz

`train_predictor.py` 中：

```python
train_set = DiffusionPlannerData(
    args.train_set,
    args.train_set_list,
    args.agent_num,
    args.predicted_neighbor_num,
    args.future_len,
)
```

然后交给：

```python
train_sampler = DistributedSampler(...)
train_loader = DataLoader(...)
```

### 下游：train_epoch 使用 batch

`diffusion_planner/train_epoch.py` 中：

```python
for batch in data_epoch:
    inputs = {
        'ego_current_state': batch[0].to(args.device),
        'neighbor_agents_past': batch[2].to(args.device),
        'lanes': batch[4].to(args.device),
        'lanes_speed_limit': batch[5].to(args.device),
        'lanes_has_speed_limit': batch[6].to(args.device),
        'route_lanes': batch[7].to(args.device),
        'route_lanes_speed_limit': batch[8].to(args.device),
        'route_lanes_has_speed_limit': batch[9].to(args.device),
        'static_objects': batch[10].to(args.device),
    }

    ego_future = batch[1].to(args.device)
    neighbors_future = batch[3].to(args.device)
```

所以 `DiffusionPlannerData.__getitem__()` 返回 tuple 的顺序非常重要，不能随意调整。

## DiffusionPlannerData 类

类定义：

```python
class DiffusionPlannerData(Dataset):
```

它继承自：

```python
torch.utils.data.Dataset
```

因此需要实现：

| 方法 | 作用 |
|---|---|
| `__len__()` | 返回数据集样本数量 |
| `__getitem__(idx)` | 根据索引返回一个训练样本 |

## __init__()

函数定义：

```python
def __init__(self, data_dir, data_list, past_neighbor_num, predicted_neighbor_num, future_len):
```

### 输入数据结构

| 参数 | 数据结构 | 含义 |
|---|---|---|
| `data_dir` | `str` | `.npz` 文件所在目录，对应训练参数 `args.train_set` |
| `data_list` | `str` | 保存 `.npz` 文件名列表的 JSON 路径，对应 `args.train_set_list` |
| `past_neighbor_num` | `int` | 历史输入最多使用多少个 neighbor agent，对应 `args.agent_num` |
| `predicted_neighbor_num` | `int` | 未来监督最多预测多少个 neighbor agent，对应 `args.predicted_neighbor_num` |
| `future_len` | `int` | 未来轨迹长度，对应 `args.future_len`；当前源码保存但没有直接裁剪 |

### 输出数据结构

无显式返回，但会初始化成员变量：

| 成员变量 | 数据结构 | 含义 |
|---|---|---|
| `self.data_dir` | `str` | `.npz` 数据目录 |
| `self.data_list` | `List[str]` | 样本 `.npz` 文件名列表 |
| `self._past_neighbor_num` | `int` | 历史输入 neighbor 截断数量 |
| `self._predicted_neighbor_num` | `int` | 未来标签 neighbor 截断数量 |
| `self._future_len` | `int` | 未来轨迹长度，当前未直接使用 |

### 分步骤解释

#### 第一步：保存数据目录

```python
self.data_dir = data_dir
```

例如：

```text
data_dir = "./cache"
```

#### 第二步：读取样本列表

```python
self.data_list = openjson(data_list)
```

`data_list` 指向 JSON 文件，例如：

```text
diffusion_planner_training.json
```

读取结果类似：

```python
[
    "sg-one-north_abc123.npz",
    "us-nv-las-vegas-strip_def456.npz",
]
```

也就是：

```text
List[str]
```

#### 第三步：保存截断参数

```python
self._past_neighbor_num = past_neighbor_num
self._predicted_neighbor_num = predicted_neighbor_num
self._future_len = future_len
```

这几个参数控制读取样本时使用多少 agent。

## __getitem__()

函数定义：

```python
def __getitem__(self, idx):
```

### 作用

根据样本索引 `idx`，读取一个 `.npz` 文件，并返回模型训练所需的 11 个字段。

### 输入数据结构

| 参数 | 数据结构 | 含义 |
|---|---|---|
| `idx` | `int` | 样本索引，由 `DataLoader` 自动传入 |

### 输出数据结构

返回：

```python
tuple(data.values())
```

这是一个长度为 11 的 tuple，不是 dict。

单样本返回顺序：

| tuple index | 字段名 | 单样本 shape | 含义 |
|---|---|---|---|
| `0` | `ego_current_state` | `[10]` | 当前 ego 10 维状态 |
| `1` | `ego_future_gt` | `[future_len, 3]`，通常 `[80, 3]` | ego 未来轨迹真值，字段为 `x,y,heading` |
| `2` | `neighbor_agents_past` | `[past_neighbor_num, 21, 11]` | neighbor 历史输入 |
| `3` | `neighbors_future_gt` | `[predicted_neighbor_num, future_len, 3]` | neighbor 未来轨迹真值 |
| `4` | `lanes` | `[lane_num, lane_len, 12]` | lane 地图特征 |
| `5` | `lanes_speed_limit` | `[lane_num, 1]` | lane 限速 |
| `6` | `lanes_has_speed_limit` | `[lane_num, 1]` | lane 是否有限速 |
| `7` | `route_lanes` | `[route_num, route_len, 12]` | route lane 特征 |
| `8` | `route_lanes_speed_limit` | `[route_num, 1]` | route lane 限速 |
| `9` | `route_lanes_has_speed_limit` | `[route_num, 1]` | route lane 是否有限速 |
| `10` | `static_objects` | `[static_objects_num, 10]` | 静态目标特征 |

经过 `DataLoader(batch_size=B)` 拼 batch 后，shape 会多一个 batch 维：

| batch index | 字段名 | batch shape |
|---|---|---|
| `batch[0]` | `ego_current_state` | `[B, 10]` |
| `batch[1]` | `ego_future_gt` | `[B, future_len, 3]` |
| `batch[2]` | `neighbor_agents_past` | `[B, past_neighbor_num, 21, 11]` |
| `batch[3]` | `neighbors_future_gt` | `[B, predicted_neighbor_num, future_len, 3]` |
| `batch[4]` | `lanes` | `[B, lane_num, lane_len, 12]` |
| `batch[5]` | `lanes_speed_limit` | `[B, lane_num, 1]` |
| `batch[6]` | `lanes_has_speed_limit` | `[B, lane_num, 1]` |
| `batch[7]` | `route_lanes` | `[B, route_num, route_len, 12]` |
| `batch[8]` | `route_lanes_speed_limit` | `[B, route_num, 1]` |
| `batch[9]` | `route_lanes_has_speed_limit` | `[B, route_num, 1]` |
| `batch[10]` | `static_objects` | `[B, static_objects_num, 10]` |

### 分步骤解释

#### 第一步：拼接样本路径并读取 .npz

源码：

```python
data = opendata(os.path.join(self.data_dir, self.data_list[idx]))
```

其中：

| 变量 | 数据结构 | 含义 |
|---|---|---|
| `self.data_dir` | `str` | 样本目录 |
| `self.data_list[idx]` | `str` | 第 `idx` 个 `.npz` 文件名 |
| `os.path.join(...)` | `str` | 完整 `.npz` 路径 |
| `data` | `numpy.lib.npyio.NpzFile` | 读取出的样本数据 |

例子：

```python
path = os.path.join("./cache", "map_token.npz")
data = opendata(path)
```

#### 第二步：读取 ego 字段

源码：

```python
ego_current_state = data['ego_current_state']
ego_agent_future = data['ego_agent_future']
```

字段结构：

| 字段 | shape | 含义 |
|---|---|---|
| `ego_current_state` | `[10]` | `x,y,cos_h,sin_h,vx,vy,ax,ay,steering_angle,yaw_rate` |
| `ego_agent_future` | `[80, 3]` | ego 未来 `x,y,heading` |

后续重命名：

```python
"ego_future_gt": ego_agent_future
```

这里的 `gt` 表示 ground truth。

#### 第三步：读取并截断 neighbor 字段

源码：

```python
neighbor_agents_past = data['neighbor_agents_past'][:self._past_neighbor_num]
neighbor_agents_future = data['neighbor_agents_future'][:self._predicted_neighbor_num]
```

含义：

| 字段 | 原始 shape | 截断后 shape | 含义 |
|---|---|---|---|
| `neighbor_agents_past` | `[agent_num_in_npz, 21, 11]` | `[past_neighbor_num, 21, 11]` | 模型输入的历史 agent |
| `neighbor_agents_future` | `[agent_num_in_npz, 80, 3]` | `[predicted_neighbor_num, 80, 3]` | 需要预测的 agent 未来标签 |

为什么 past 和 future 使用不同数量：

```text
模型可以观察较多历史 agent，例如 32 个；
但只预测最近的一部分 neighbor，例如 10 个。
```

对应训练参数：

```python
args.agent_num
args.predicted_neighbor_num
```

#### 第四步：读取 lane 字段

源码：

```python
lanes = data['lanes']
lanes_speed_limit = data['lanes_speed_limit']
lanes_has_speed_limit = data['lanes_has_speed_limit']
```

字段结构：

| 字段 | shape | 含义 |
|---|---|---|
| `lanes` | `[lane_num, lane_len, 12]` | lane 点特征 |
| `lanes_speed_limit` | `[lane_num, 1]` | lane 限速 |
| `lanes_has_speed_limit` | `[lane_num, 1]` | lane 是否有限速 |

`lanes` 的 12 维通常是：

```text
x, y,
dx, dy,
left_dx, left_dy,
right_dx, right_dy,
traffic_light_0, traffic_light_1, traffic_light_2, traffic_light_3
```

#### 第五步：读取 route lane 字段

源码：

```python
route_lanes = data['route_lanes']
route_lanes_speed_limit = data['route_lanes_speed_limit']
route_lanes_has_speed_limit = data['route_lanes_has_speed_limit']
```

字段结构：

| 字段 | shape | 含义 |
|---|---|---|
| `route_lanes` | `[route_num, route_len, 12]` | 导航 route 上的 lane 特征 |
| `route_lanes_speed_limit` | `[route_num, 1]` | route lane 限速 |
| `route_lanes_has_speed_limit` | `[route_num, 1]` | route lane 是否有限速 |

#### 第六步：读取静态目标

源码：

```python
static_objects = data['static_objects']
```

shape：

```text
[static_objects_num, 10]
```

10 维含义：

```text
x, y, cos_h, sin_h, width, length,
czone_sign, barrier, traffic_cone, generic_object
```

#### 第七步：重新组织成字典

源码：

```python
data = {
    "ego_current_state": ego_current_state,
    "ego_future_gt": ego_agent_future,
    "neighbor_agents_past": neighbor_agents_past,
    "neighbors_future_gt": neighbor_agents_future,
    "lanes": lanes,
    "lanes_speed_limit": lanes_speed_limit,
    "lanes_has_speed_limit": lanes_has_speed_limit,
    "route_lanes": route_lanes,
    "route_lanes_speed_limit": route_lanes_speed_limit,
    "route_lanes_has_speed_limit": route_lanes_has_speed_limit,
    "static_objects": static_objects,
}
```

注意这里改变了两个字段名：

| `.npz` 原字段 | dataset 输出字段 |
|---|---|
| `ego_agent_future` | `ego_future_gt` |
| `neighbor_agents_future` | `neighbors_future_gt` |

#### 第八步：返回 tuple

源码：

```python
return tuple(data.values())
```

Python 3.7+ 中字典保持插入顺序，所以返回 tuple 的顺序就是上面字典的插入顺序。

训练代码强依赖这个顺序：

```python
batch[0]  # ego_current_state
batch[1]  # ego_future_gt
batch[2]  # neighbor_agents_past
...
```

如果调整 `data` 字典字段顺序，必须同步修改 `train_epoch.py` 中的 `batch[i]` 索引。

## 和 DataLoader 的关系

`train_predictor.py` 中：

```python
train_loader = DataLoader(
    train_set,
    sampler=train_sampler,
    batch_size=batch_size // ddp.get_world_size(),
    num_workers=args.num_workers,
    pin_memory=args.pin_mem,
    drop_last=True,
)
```

`DataLoader` 会自动把多个 `__getitem__()` 返回的 tuple 合成 batch。

例如单个样本：

```text
ego_current_state: [10]
```

batch size 为 `B` 后：

```text
batch[0]: [B, 10]
```

如果 `lanes` 单样本是：

```text
[70, 20, 12]
```

batch 后：

```text
[B, 70, 20, 12]
```

## 和 train_epoch.py 的字段映射

`DiffusionPlannerData.__getitem__()` 返回顺序和 `train_epoch.py` 的使用关系如下：

| dataset tuple index | dataset 字段 | train_epoch 用法 |
|---|---|---|
| `0` | `ego_current_state` | `inputs['ego_current_state'] = batch[0]` |
| `1` | `ego_future_gt` | `ego_future = batch[1]` |

## 注意事项

1. `__getitem__()` 返回的是 tuple，不是 dict；训练代码通过固定 index 读取。
2. `future_len` 在当前源码里只保存到 `self._future_len`，没有在 `__getitem__()` 中裁剪未来轨迹。
3. `neighbor_agents_past` 使用 `past_neighbor_num` 截断，通常等于 `args.agent_num`。
4. `neighbor_agents_future` 使用 `predicted_neighbor_num` 截断，通常小于或等于 `agent_num`。
5. 如果 `.npz` 缺少任一 key，比如 `route_lanes_speed_limit`，`__getitem__()` 会直接 KeyError。
6. 如果调整返回 tuple 的字段顺序，必须同步调整 `train_epoch.py` 中所有 `batch[i]`。
7. `opendata()` 返回的 `NpzFile` 没有显式 close；当前写法依赖对象生命周期释放资源。
