# diffusion_planner/utils/tb_log.py 详解

本文档详细解释 `diffusion_planner/utils/tb_log.py` 中的类、函数、变量、调用关系，以及每个方法的输入输出数据结构。

这个文件定义了一个日志封装类：

```python
class TensorBoardLogger()
```

它的作用是统一管理训练日志：

1. 用 `SummaryWriter` 写 TensorBoard 日志。
2. 用 `wandb.init()` 初始化 Weights & Biases 实验。
3. 通过 `sync_tensorboard=True` 让 wandb 同步 TensorBoard 指标。
4. 在 DDP 分布式训练中只让 `rank == 0` 的主进程写日志，避免多进程重复记录。

## 文件位置

```text
diffusion_planner/utils/tb_log.py
```

## 上下游调用关系

`tb_log.py` 主要被训练入口 `train_predictor.py` 使用。

导入位置：

```python
from diffusion_planner.utils.tb_log import TensorBoardLogger as Logger
```

初始化位置：

```python
wandb_logger = Logger(
    args.name,
    args.notes,
    args,
    wandb_resume_id=wandb_id,
    save_path=save_path,
    rank=global_rank,
)
```

记录指标位置：

```python
wandb_logger.log_metrics(
    {f"train_loss/{k}": v for k, v in train_loss.items()},
    step=epoch + 1,
)
```

```python
wandb_logger.log_metrics(
    {f"lr/{k}": v for k, v in lr_dict.items()},
    step=epoch + 1,
)
```

整体训练调用链：

```text
train_predictor.py
    -> model_training(args)
        -> Logger(...)
            -> TensorBoardLogger.__init__()
                -> wandb.init()
                -> wandb.config.update(args)
                -> SummaryWriter(log_dir=f"{save_path}/tb")
        -> train_epoch(...)
        -> wandb_logger.log_metrics(train_loss, step=epoch+1)
        -> wandb_logger.log_metrics(lr_dict, step=epoch+1)
        -> save_model(..., wandb_logger.id, ...)
```

注意：源码中定义了 `finish()`，但当前 `train_predictor.py` 没有显式调用它。

## 导入项

```python
import os
from torch.utils.tensorboard import SummaryWriter
import wandb
```

| 导入项 | 作用 |
|---|---|
| `os` | 设置环境变量 `WANDB_MODE` |
| `SummaryWriter` | TensorBoard 日志写入器 |
| `wandb` | Weights & Biases 实验管理和日志记录 |

## TensorBoardLogger 类

类定义：

```python
class TensorBoardLogger():
```

这个类封装了两个日志系统：

| 日志系统 | 对应对象 | 作用 |
|---|---|---|
| TensorBoard | `self.writer` | 本地写入 scalar 指标，例如 loss、learning rate |
| wandb | `wandb_writer` / `self.id` | 记录实验配置、同步 TensorBoard 日志、保存 run id |

类的主要成员变量：

| 成员变量 | 数据结构 | 含义 |
|---|---|---|
| `self.args` | `argparse.Namespace` 或配置对象 | 训练参数配置 |
| `self.writer` | `SummaryWriter` 或 `None` | TensorBoard writer；非主进程中为 `None` |
| `self.id` | `str` 或 `None` | wandb run id；用于 checkpoint 里保存并恢复同一个 wandb run |

## __init__()

函数定义：

```python
def __init__(self, run_name, notes, args, wandb_resume_id, save_path, rank=0):
```

### 作用

初始化日志记录器。只有 `rank == 0` 时才会真正初始化 wandb 和 TensorBoard。

这样设计是为了适配 DDP 分布式训练：

```text
rank 0: 写日志
rank 1/2/3/...: 不写日志
```

避免多个进程同时写同一份日志。

### 输入数据结构

| 参数 | 数据结构 | 含义 |
|---|---|---|
| `run_name` | `str` | 当前实验名称，对应 `args.name` |
| `notes` | `str` | 当前实验备注，对应 `args.notes` |
| `args` | `argparse.Namespace` 或类似配置对象 | 训练参数配置，至少需要有 `use_wandb` 字段 |
| `wandb_resume_id` | `str` 或 `None` | wandb run id；断点续训时用于恢复已有 run |
| `save_path` | `str` 或 `None` | 日志保存目录；主进程中应为有效路径 |
| `rank` | `int` | 当前进程 rank；只有 `rank == 0` 才写日志 |

### 输出数据结构

| 返回值 | 含义 |
|---|---|
| 无显式返回 | 初始化 `self.args`、`self.writer`、`self.id` |

初始化后的状态：

| 条件 | `self.writer` | `self.id` |
|---|---|---|
| `rank == 0` | `SummaryWriter(log_dir=f"{save_path}/tb")` | `wandb_writer.id` |
| `rank != 0` | `None` | `None` |

### 分步骤解释

#### 第一步：保存 args

源码：

```python
self.args = args
```

`args` 是训练参数对象，会被后面写入 wandb config。

#### 第二步：初始化成员变量

源码：

```python
self.writer = None
self.id = None
```

默认不创建 writer。只有主进程 `rank == 0` 才继续初始化。

#### 第三步：判断是否为主进程

源码：

```python
if rank == 0:
```

如果当前不是 rank 0：

```text
self.writer 保持 None
self.id 保持 None
log_metrics() 后续不会写任何内容
```

#### 第四步：设置 WANDB_MODE

源码：

```python
os.environ["WANDB_MODE"] = "online" if args.use_wandb else "offline"
```

含义：

| `args.use_wandb` | `WANDB_MODE` | 含义 |
|---|---|---|
| `True` | `"online"` | 同步到 wandb 云端 |
| `False` | `"offline"` | 只在本地保存 wandb 日志，不上传 |

这个环境变量会影响后续 `wandb.init()` 的行为。

#### 第五步：初始化 wandb

源码：

```python
wandb_writer = wandb.init(
    project='Diffusion-Planner',
    name=run_name,
    notes=notes,
    resume="allow",
    id=wandb_resume_id,
    sync_tensorboard=True,
    dir=f'{save_path}',
)
```

参数含义：

| 参数 | 数据结构 | 含义 |
|---|---|---|
| `project` | `str` | wandb 项目名称，固定为 `Diffusion-Planner` |
| `name` | `str` | 当前 run 名称 |
| `notes` | `str` | 实验备注 |
| `resume` | `str` | `"allow"` 表示允许按 id 恢复；如果 id 不存在则创建新 run |
| `id` | `str` 或 `None` | 要恢复的 wandb run id |
| `sync_tensorboard` | `bool` | 是否自动同步 TensorBoard scalar 到 wandb |
| `dir` | `str` | wandb 本地文件保存目录 |

`sync_tensorboard=True` 是关键点：本项目实际调用 `SummaryWriter.add_scalar()` 写 TensorBoard，wandb 会同步这些 TensorBoard 指标。

#### 第六步：写入 wandb config

源码：

```python
wandb.config.update(args)
```

作用是把训练参数记录到 wandb 页面。

这里的 `args` 通常来自 `train_predictor.py` 的 `get_args()`，包含：

```text
batch_size
learning_rate
train_epochs
agent_num
lane_num
route_num
hidden_dim
diffusion_model_type
...
```

#### 第七步：保存 wandb run id

源码：

```python
self.id = wandb_writer.id
```

这个 id 后面会传给 `save_model()`：

```python
save_model(..., wandb_logger.id, ...)
```

然后 checkpoint 会保存：

```python
'wandb_id': wandb_id
```

断点续训时 `resume_model()` 会恢复 `wandb_id`，再传回 `Logger(..., wandb_resume_id=wandb_id, ...)`。

#### 第八步：创建 TensorBoard writer

源码：

```python
self.writer = SummaryWriter(log_dir=f'{save_path}/tb')
```

日志目录：

```text
{save_path}/tb
```

训练时写入的 scalar 都会进入这个目录。

## log_metrics()

函数定义：

```python
def log_metrics(self, metrics: dict, step: int):
```

### 作用

把一个指标字典写入 TensorBoard。

如果当前进程不是 rank 0，`self.writer is None`，这个函数什么也不会写。

### 输入数据结构

| 参数 | 数据结构 | 含义 |
|---|---|---|
| `metrics` | `Dict[str, int/float/np.number]` | 指标名称到数值的映射 |
| `step` | `int` | 当前训练步数或 epoch，用作 TensorBoard 横轴 |

输入例子：

```python
{
    "train_loss/loss": 1.234,
    "train_loss/ego_planning_loss": 0.456,
    "train_loss/neighbor_prediction_loss": 0.778,
}
```

或者：

```python
{
    "lr/lr": 0.0005,
}
```

### 输出数据结构

| 返回值 | 含义 |
|---|---|
| 无显式返回 | 通过 `self.writer.add_scalar()` 写入 TensorBoard 事件文件 |

### 分步骤解释

#### 第一步：检查 writer 是否存在

源码：

```python
if self.writer is not None:
```

只有 rank 0 才会有 writer。

非 rank 0 进程：

```text
self.writer = None
log_metrics() 不写日志
```

#### 第二步：遍历 metrics 字典

源码：

```python
for key, value in metrics.items():
```

其中：

| 变量 | 数据结构 | 含义 |
|---|---|---|
| `key` | `str` | 指标名称，例如 `train_loss/loss` |
| `value` | number | 指标值 |

#### 第三步：写入 TensorBoard scalar

源码：

```python
self.writer.add_scalar(key, value, step)
```

对应 TensorBoard 概念：

| 参数 | TensorBoard 含义 |
|---|---|
| `key` | tag，指标名 |
| `value` | scalar value |
| `step` | global step |

由于 `wandb.init(sync_tensorboard=True)`，这些 TensorBoard scalar 也会被 wandb 同步。

### 实际调用位置

文件：

```text
train_predictor.py
```

训练 loss：

```python
wandb_logger.log_metrics(
    {f"train_loss/{k}": v for k, v in train_loss.items()},
    step=epoch + 1,
)
```

这里 `train_loss` 来自：

```python
train_loss, train_total_loss = train_epoch(...)
```

其数据结构一般是：

```python
{
    "neighbor_prediction_loss": ...,
    "ego_planning_loss": ...,
    "loss": ...,
}
```

所以写入 TensorBoard 后的 tag 是：

```text
train_loss/neighbor_prediction_loss
train_loss/ego_planning_loss
train_loss/loss
```

学习率：

```python
lr_dict = {'lr': optimizer.param_groups[0]['lr']}
wandb_logger.log_metrics(
    {f"lr/{k}": v for k, v in lr_dict.items()},
    step=epoch + 1,
)
```

写入 tag：

```text
lr/lr
```

## finish()

函数定义：

```python
def finish(self):
```

### 作用

关闭 TensorBoard writer，刷新未写入磁盘的缓存。

### 输入数据结构

| 参数 | 数据结构 | 含义 |
|---|---|---|
| 无 | - | 只使用 `self.writer` |

### 输出数据结构

| 返回值 | 含义 |
|---|---|
| 无显式返回 | 如果 writer 存在，则关闭 writer |

### 分步骤解释

源码：

```python
if self.writer is not None:
    self.writer.close()
```

如果当前是 rank 0：

```text
self.writer 是 SummaryWriter
调用 close() 刷新并关闭 TensorBoard 文件
```

如果当前不是 rank 0：

```text
self.writer 是 None
不执行任何操作
```

### 当前调用情况

当前源码中没有搜索到 `wandb_logger.finish()` 或 `logger.finish()` 的调用。

这意味着训练脚本结束时主要依赖 Python 进程退出自动释放资源。更稳妥的写法通常是在训练结束后显式调用：

```python
wandb_logger.finish()
```

如果还希望关闭 wandb run，也可以额外调用：

```python
wandb.finish()
```

不过当前 `finish()` 源码只关闭 TensorBoard writer，没有调用 `wandb.finish()`。

## 注意事项

1. 只有 `rank == 0` 会创建 wandb run 和 TensorBoard writer，其他 rank 不写日志。
2. `args.use_wandb=False` 时，`WANDB_MODE` 被设为 `offline`，仍然会初始化 wandb，但不会在线同步。
3. `wandb.config.update(args)` 要求 `args` 中的对象能被 wandb 正常序列化；本项目在 `train_predictor.py` 中保存 `args.json` 时单独处理了 normalizer，但这里直接传给 wandb。
4. `finish()` 只关闭 TensorBoard writer，不调用 `wandb.finish()`。
5. 当前训练脚本没有显式调用 `finish()`。
6. 如果 `rank == 0` 但 `save_path=None`，`wandb.init(dir=f'{save_path}')` 和 `SummaryWriter(log_dir=f'{save_path}/tb')` 会使用字符串 `"None"` 拼路径，通常不是期望行为；当前 `train_predictor.py` 只在非主进程把 `save_path` 设为 `None`，而非主进程不会初始化 writer。
7. `sync_tensorboard=True` 表示本项目的指标主要通过 TensorBoard 写入，再由 wandb 同步。
