# diffusion_planner/utils/data_augmentation.py 详解

本文档解释 `diffusion_planner/utils/data_augmentation.py` 的代码结构、函数输入输出、变量含义和调用关系。这个文件主要实现训练阶段的数据增强：随机扰动自车当前状态，然后把 ego、邻车、地图、静态障碍物、未来轨迹统一变换到新的 ego/anchor 坐标系下。

## 1. 文件作用

`data_augmentation.py` 的核心类是 `StatePerturbation`。

它做三件事：

1. 对 batch 中一部分样本的 `ego_current_state` 加随机扰动。
2. 根据扰动后的当前自车状态，重新插值 ego 前 2 秒的未来轨迹，使轨迹从新的扰动状态平滑接回原始未来轨迹。
3. 以扰动后的 ego 当前位姿作为新的坐标系原点，把所有输入特征和未来标签都重新转换到该坐标系下。

训练时的调用关系大致是：

```text
train_predictor.py
    └── 创建 StatePerturbation(...)

train_epoch.py
    └── aug(inputs, ego_future, neighbors_future)
            ├── StatePerturbation.augment(...)
            ├── StatePerturbation.interpolation_future_trajectory(...)
            └── StatePerturbation.centric_transform(...)
                    ├── vector_transform(...)
                    ├── heading_transform(...)
                    └── StatePerturbation.get_transform_matrix_batch(...)
```

## 2. 全局常量

```python
NUM_REFINE = 20
REFINE_HORIZON = 2.0
TIME_INTERVAL = 0.1
```

含义：

- `NUM_REFINE = 20`：对未来轨迹前 20 个点做平滑修正。
- `REFINE_HORIZON = 2.0`：修正的时间长度是 2 秒。
- `TIME_INTERVAL = 0.1`：轨迹采样间隔是 0.1 秒。

因此前 20 个未来点对应：

```text
0.1s, 0.2s, ..., 2.0s
```

在 `StatePerturbation.__init__()` 中还会构造：

```python
T = REFINE_HORIZON + TIME_INTERVAL
```

也就是 `2.1`。它用于五次多项式边界约束矩阵 `self.coeff_matrix`。

## 3. vector_transform

```python
def vector_transform(vector, transform_mat, bias=None):
```

### 3.1 函数作用

`vector_transform()` 用于批量旋转二维向量或二维坐标点。

如果传入 `bias`，它表示先把点平移到以 `bias` 为原点的坐标系，再乘旋转矩阵。

如果不传 `bias`，它只做旋转，不做平移。

所以这个函数同时适用于：

- 坐标点：例如 `x, y`，需要先减去坐标系原点，再旋转。
- 方向向量：例如速度、加速度、车道方向向量，只需要旋转，不需要平移。

### 3.2 输入数据结构

```python
vector: torch.Tensor
```

形状通常是：

```text
[B, ..., 2]
```

最后一维必须是二维向量 `[x, y]` 或 `[vx, vy]`。

常见例子：

```text
ego_future[:, :, :2]              -> [B, 80, 2]
neighbor_agents_past[:, :, :, :2] -> [B, A, 21, 2]
lanes[:, :, :, :2]                -> [B, L, P, 2]
static_objects[:, :, :2]          -> [B, S, 2]
```

```python
transform_mat: torch.Tensor
```

形状是：

```text
[B, 2, 2]
```

每个 batch 样本都有一个自己的二维旋转矩阵。

```python
bias: Optional[torch.Tensor]
```

通常是当前自车位置：

```text
[B, 2]
```

也就是 `center_xy = cur_state[:, :2]`。

### 3.3 输出数据结构

输出仍然是 `torch.Tensor`，形状和 `vector` 完全一致：

```text
[B, ..., 2]
```

### 3.4 代码分步骤解释

```python
shape = vector.shape
B = vector.shape[0]
nexpand = vector.ndim - 2
```

- `shape` 保存原始形状，最后要恢复回去。
- `B` 是 batch size。
- `nexpand` 表示中间有多少个非 batch、非二维坐标的维度。

例如：

```text
vector.shape = [B, A, 21, 2]
vector.ndim = 4
nexpand = 2
```

说明中间有 `A` 和 `21` 两个维度。

```python
if bias is not None:
    vector = vector - bias.reshape(B, *([1] * nexpand), -1)
```

如果 `bias = [B, 2]`，这里会 reshape 成可广播形状：

```text
[B, 1, 1, 2]
```

这样可以从 `[B, A, 21, 2]` 的每个点中减去当前 ego 的坐标。

```python
vector = vector.reshape(B, -1, 2).permute(0, 2, 1)
```

把任意多维点集统一整理成：

```text
[B, 2, N]
```

其中 `N` 是该样本中的所有二维点数量。

```python
vector = torch.bmm(transform_mat, vector).permute(0, 2, 1).reshape(*shape)
```

`torch.bmm()` 是 batch 矩阵乘法：

```text
[B, 2, 2] @ [B, 2, N] -> [B, 2, N]
```

最后再恢复成原始形状。

## 4. heading_transform

```python
def heading_transform(heading, transform_mat):
```

### 4.1 函数作用

`heading_transform()` 用于把航向角 `heading` 旋转到新的坐标系下。

它不是直接对角度做加减，而是先把角度转换成单位方向向量：

```text
[cos(heading), sin(heading)]
```

然后用旋转矩阵变换方向向量，最后用 `atan2()` 还原成新的角度。

这样做比直接处理角度更稳定，也能避免角度跨越 `pi` 和 `-pi` 时的跳变问题。

### 4.2 输入数据结构

```python
heading: torch.Tensor
```

形状通常是：

```text
[B, ...]
```

常见例子：

```text
ego_future[:, :, 2]        -> [B, 80]
neighbors_future[:, :, :, 2] -> [B, N, 80]
```

```python
transform_mat: torch.Tensor
```

形状：

```text
[B, 2, 2]
```

### 4.3 输出数据结构

输出是变换后的 heading，形状和输入 `heading` 相同：

```text
[B, ...]
```

### 4.4 代码分步骤解释

```python
B = heading.shape[0]
shape = heading.shape
nexpand = heading.ndim - 1
heading = heading.reshape(B, -1)
transform_mat = transform_mat.reshape(B, 1, 2, 2)
```

- 保存原始 heading 形状。
- 把 heading 展平成 `[B, N]`。
- 把旋转矩阵 reshape 成 `[B, 1, 2, 2]`，方便对每个 heading 广播。

```python
return torch.atan2(
    torch.cos(heading) * transform_mat[..., 1, 0] + torch.sin(heading) * transform_mat[..., 1, 1],
    torch.cos(heading) * transform_mat[..., 0, 0] + torch.sin(heading) * transform_mat[..., 0, 1]
).reshape(*shape)
```

这里做的是：

```text
old_direction = [cos(h), sin(h)]
new_direction = transform_mat @ old_direction
new_heading = atan2(new_direction_y, new_direction_x)
```

返回值再 reshape 回原始形状。

注意：代码里的 `nexpand` 被计算出来了，但没有继续使用。

## 5. StatePerturbation 类

```python
class StatePerturbation:
```

### 5.1 类作用

`StatePerturbation` 是训练时的数据增强器。

它的输入是模型训练 batch 中的：

- `inputs`
- `ego_future`
- `neighbors_future`

它的输出仍然是：

- `inputs`
- `ego_future`
- `neighbors_future`

但其中一部分样本会被扰动，并且所有相关特征会被同步变换到扰动后的 ego 坐标系。

## 6. StatePerturbation.__init__

```python
def __init__(
    self,
    low: List[float] = [-0., -0.75, -0.35, -1, -0.5, -0.2, -0.1, 0., -0.],
    high: List[float] = [0., 0.75, 0.35, 1, 0.5, 0.2, 0.1, 0., 0.],
    augment_prob=0.5,
    normalize=True,
    device="cpu"
):
```

### 6.1 函数作用

初始化增强器，保存扰动范围、增强概率、设备信息，并预先构造五次多项式轨迹插值需要的矩阵。

### 6.2 输入参数

```python
low: List[float]
high: List[float]
```

二者长度都是 9，对应随机噪声上下界：

```text
[x, y, heading, vx, vy, ax, ay, steering_angle, yaw_rate]
```

默认情况下：

- `x` 不扰动。
- `y` 在 `[-0.75, 0.75]` 米范围内扰动。
- `heading` 在 `[-0.35, 0.35]` rad 范围内扰动。
- `vx, vy, ax, ay` 也会轻微扰动。
- `steering_angle` 和 `yaw_rate` 默认不直接加噪声。

```python
augment_prob: float
```

增强概率相关参数。需要注意源代码中实际判断是：

```python
torch.rand(B) >= self._augment_prob
```

因此当 `augment_prob = 0.5` 时，增强概率大约是 50%。

但如果设置成 `0.8`，由于使用的是 `>= 0.8`，实际增强概率大约是 20%。这一点和变量名直觉不完全一致，需要按代码行为理解。

```python
normalize: bool
```

保存到 `self._normalize`，但在当前文件中没有实际使用。

```python
device: str | torch.device
```

指定生成张量所在设备，例如：

```text
"cpu"
"cuda"
"cuda:0"
```

### 6.3 成员变量

```python
self._augment_prob = augment_prob
self._normalize = normalize
self._device = device
self._low = low
self._high = high
self._wheel_base = get_pacifica_parameters().wheel_base
```

`self._wheel_base` 是 Chrysler Pacifica 的轴距，用于通过自行车模型在速度和 yaw rate 之间计算转角。

```python
self.refine_horizon = REFINE_HORIZON
self.num_refine = NUM_REFINE
self.time_interval = TIME_INTERVAL
```

保存轨迹修正参数。

```python
self.coeff_matrix = torch.linalg.inv(...)
```

`self.coeff_matrix` 是五次多项式边界约束矩阵的逆矩阵。

它用于求解：

```text
p(t) = a0 + a1 t + a2 t^2 + a3 t^3 + a4 t^4 + a5 t^5
```

的 6 个系数。

六个约束是：

```text
p(0), p'(0), p''(0), p(T), p'(T), p''(T)
```

分别对应起点位置、速度、加速度，以及终点位置、速度、加速度。

```python
self.t_matrix = torch.column_stack([...])
```

`self.t_matrix` 的形状是：

```text
[20, 6]
```

每一行是一个时间点的多项式基：

```text
[1, t, t^2, t^3, t^4, t^5]
```

时间点是：

```text
0.1, 0.2, ..., 2.0
```

### 6.4 输出

构造函数没有显式返回值，只初始化 `StatePerturbation` 实例。

## 7. StatePerturbation.__call__

```python
def __call__(self, inputs, ego_future, neighbors_future):
```

### 7.1 函数作用

让 `StatePerturbation` 实例可以像函数一样被调用。

训练代码中会直接写：

```python
inputs, ego_future, neighbors_future = aug(inputs, ego_future, neighbors_future)
```

### 7.2 输入数据结构

```python
inputs: dict
```

常见键和形状：

```text
inputs["ego_current_state"]   -> [B, 10]
inputs["neighbor_agents_past"] -> [B, A, 21, 11]
inputs["lanes"]               -> [B, L, P, 12]
inputs["route_lanes"]         -> [B, R, P, 12]
inputs["static_objects"]      -> [B, S, 10]
```

其中：

- `B`：batch size。
- `A`：历史邻车数量。
- `L`：lane polyline 数量。
- `R`：route lane polyline 数量。
- `P`：每条 polyline 的点数。
- `S`：静态障碍物数量。

```python
ego_future: torch.Tensor
```

形状：

```text
[B, 80, 3]
```

每个点通常是：

```text
[x, y, heading]
```

```python
neighbors_future: torch.Tensor
```

形状：

```text
[B, N, 80, 3]
```

其中 `N` 是预测的邻车数量。

### 7.3 输出数据结构

返回：

```python
return inputs, ego_future, neighbors_future
```

三者形状和输入相同，但坐标系已经被重新归一到扰动后的当前 ego 位姿。

### 7.4 代码分步骤解释

```python
aug_flag, aug_ego_current_state = self.augment(inputs)
```

先生成扰动后的自车当前状态。

```python
interpolated_ego_future = self.interpolation_future_trajectory(aug_ego_current_state, ego_future)
```

根据扰动后的当前状态，重新生成 ego 前 2 秒的未来轨迹。

```python
inputs['ego_current_state'][aug_flag] = aug_ego_current_state[aug_flag]
ego_future[aug_flag] = interpolated_ego_future[aug_flag]
```

只对 `aug_flag=True` 的样本替换当前 ego 状态和 ego 未来轨迹。

```python
return self.centric_transform(inputs, ego_future, neighbors_future)
```

最后把所有输入和标签统一转换到新的 ego-centric 坐标系下。

## 8. StatePerturbation.augment

```python
def augment(self, inputs):
```

### 8.1 函数作用

对 batch 中一部分样本的 `ego_current_state` 加随机扰动。

它只负责生成扰动后的当前自车状态，不会修改地图、邻车或未来轨迹。

### 8.2 输入数据结构

```python
inputs: dict
```

函数使用：

```python
inputs['ego_current_state']
```

形状：

```text
[B, 10]
```

字段含义按代码使用方式可理解为：

```text
0: x
1: y
2: cos(heading)
3: sin(heading)
4: vx
5: vy
6: ax
7: ay
8: steering_angle
9: yaw_rate
```

### 8.3 输出数据结构

```python
aug_flag: torch.Tensor
```

形状：

```text
[B]
```

类型是 bool。`True` 表示该样本会使用扰动后的状态。

```python
ego_current_state: torch.Tensor
```

形状：

```text
[B, 10]
```

表示扰动后的 ego 当前状态。

### 8.4 代码分步骤解释

#### 第一步：复制当前状态

```python
ego_current_state = inputs['ego_current_state'].clone()
B = ego_current_state.shape[0]
```

这里使用 `clone()`，避免直接在原始输入上立刻改值。

#### 第二步：决定哪些样本增强

```python
aug_flag = (torch.rand(B).to(self._device) >= self._augment_prob).bool().to(self._device) \
           & ~(torch.abs(ego_current_state[:, 4]) < 2.0)
```

这个条件由两部分组成：

1. `torch.rand(B) >= self._augment_prob`
2. `abs(vx) >= 2.0`

也就是说：

- 随机命中的样本才可能增强。
- 自车纵向速度太低的样本不会增强。

低速样本不增强的原因通常是：低速时 heading、yaw rate、轨迹方向更不稳定，强行扰动可能制造不合理轨迹。

#### 第三步：生成随机噪声

```python
random_noise = torch.rand((B, 9), device=self._device)
random_noise = random_noise * (torch.tensor(self._high, device=self._device) - torch.tensor(self._low, device=self._device)) \
               + torch.tensor(self._low, device=self._device)
```

`random_noise` 形状是：

```text
[B, 9]
```

每一行对应一个样本，每一列对应：

```text
[x, y, heading, vx, vy, ax, ay, steering_angle, yaw_rate]
```

#### 第四步：构造 new_state

```python
new_state = torch.zeros((B, 9), device=self._device)
new_state[:, 3:] = ego_current_state[:, 4:10]
```

`new_state` 的结构是：

```text
0: x
1: y
2: heading
3: vx
4: vy
5: ax
6: ay
7: steering_angle
8: yaw_rate
```

这里先把原始 `ego_current_state` 的运动状态复制进去：

```text
ego_current_state[:, 4:10] -> [vx, vy, ax, ay, steering_angle, yaw_rate]
```

#### 第五步：加扰动并裁剪速度、yaw_rate

```python
new_state += random_noise
new_state[:, 3] = torch.clamp(new_state[:, 3], min=0)
new_state[:, 8] = torch.clamp(new_state[:, 8], min=-0.85, max=0.85)
```

- `new_state[:, 3]` 是 `vx`，被限制为非负。
- `new_state[:, 8]` 是 `yaw_rate`，被限制到 `[-0.85, 0.85]`。

#### 第六步：写回 ego_current_state

```python
ego_current_state[:, 0:2] = new_state[:, 0:2]
ego_current_state[:, 2] = torch.cos(new_state[:, 2])
ego_current_state[:, 3] = torch.sin(new_state[:, 2])
ego_current_state[:, 4:10] = new_state[:, 3:]
```

原始状态里 heading 不直接存角度，而是存：

```text
cos(heading), sin(heading)
```

所以这里把 `new_state[:, 2]` 转成 cos/sin 后写回。

#### 第七步：用自行车模型修正 steering_angle

```python
cur_velocity = ego_current_state[i, 4]
cur_yaw_rate = ego_current_state[i, 9]
```

对每个样本，如果速度很低：

```python
if abs(cur_velocity) < 0.2:
    steering_angle = 0.0
    yaw_rate = 0.0
```

如果速度不低：

```python
steering_angle = torch.atan(cur_yaw_rate * self._wheel_base / torch.abs(cur_velocity))
```

这个来自简化自行车模型：

```text
yaw_rate = v / wheel_base * tan(steering_angle)
```

反解可得：

```text
steering_angle = atan(yaw_rate * wheel_base / v)
```

最后再限制转角范围：

```python
steering_angle = torch.clamp(steering_angle, min=-2/3*torch.pi, max=2/3*torch.pi)
```

### 8.5 小例子

假设某个样本当前状态是：

```text
[x=0, y=0, cos=1, sin=0, vx=8, vy=0, ax=0, ay=0, steering=0, yaw_rate=0]
```

随机扰动生成：

```text
y + 0.5
heading + 0.1
vx - 0.3
```

扰动后可能变成：

```text
[0, 0.5, cos(0.1), sin(0.1), 7.7, 0, 0, 0, steering_new, yaw_rate_new]
```

后续 `centric_transform()` 会以这个新状态作为新的 ego 坐标系原点和朝向。

## 9. StatePerturbation.normalize_angle

```python
def normalize_angle(self, angle):
```

### 9.1 函数作用

把角度归一化到：

```text
[-pi, pi)
```

### 9.2 输入数据结构

```python
angle: np.ndarray | torch.Tensor | scalar-like
```

可以是标量，也可以是任意形状数组或 tensor。

### 9.3 输出数据结构

返回与输入同形状的角度结果。

### 9.4 计算公式

```python
return (angle + np.pi) % (2 * np.pi) - np.pi
```

例如：

```text
angle = 3.5 rad
```

因为 `3.5 > pi`，归一化后会变成一个负角度：

```text
3.5 - 2*pi ≈ -2.783
```

## 10. StatePerturbation.get_transform_matrix_batch

```python
def get_transform_matrix_batch(self, cur_state):
```

### 10.1 函数作用

根据当前 ego 状态中的朝向，构造批量旋转矩阵。

这个旋转矩阵用于把全局或旧 ego 坐标系下的数据，转换到新的 ego 坐标系下。

### 10.2 输入数据结构

```python
cur_state: torch.Tensor
```

形状：

```text
[B, 10]
```

函数使用其中：

```text
cur_state[:, 2] -> cos(heading)
cur_state[:, 3] -> sin(heading)
```

### 10.3 输出数据结构

```python
transform_matrix: torch.Tensor
```

形状：

```text
[B, 2, 2]
```

每个样本的矩阵是：

```text
[[ cos,  sin],
 [-sin,  cos]]
```

这是把点从原坐标系旋转到 ego 局部坐标系的矩阵。

### 10.4 代码分步骤解释

```python
processed_input = torch.column_stack((cur_state[:, 2], cur_state[:, 3]))
```

得到：

```text
[B, 2]
```

每行是：

```text
[cos(heading), sin(heading)]
```

```python
reshaping_tensor = torch.tensor(
    [
        [1, 0, 0, 1],
        [0, 1, -1, 0],
    ],
    device=self._device
)
```

这个矩阵用于把 `[cos, sin]` 变成 4 个矩阵元素：

```text
[cos, sin, -sin, cos]
```

计算：

```python
processed_input @ reshaping_tensor
```

得到形状：

```text
[B, 4]
```

每行是：

```text
[cos, sin, -sin, cos]
```

最后：

```python
.reshape(-1, 2, 2)
```

变成：

```text
[[cos, sin],
 [-sin, cos]]
```

## 11. StatePerturbation.centric_transform

```python
def centric_transform(self, inputs, ego_future, neighbors_future):
```

### 11.1 函数作用

以当前 `inputs['ego_current_state']` 为新的 anchor，把输入特征和未来标签全部转换到新的 ego-centric 坐标系。

这个函数会原地修改：

- `inputs['ego_current_state']`
- `inputs['neighbor_agents_past']`
- `inputs['lanes']`
- `inputs['route_lanes']`
- `inputs['static_objects']`
- `ego_future`
- `neighbors_future`

### 11.2 输入数据结构

```python
inputs: dict
```

主要键：

```text
inputs["ego_current_state"]    -> [B, 10]
inputs["neighbor_agents_past"] -> [B, A, 21, 11]
inputs["lanes"]                -> [B, L, P, 12]
inputs["route_lanes"]          -> [B, R, P, 12]
inputs["static_objects"]       -> [B, S, 10]
```

```python
ego_future: torch.Tensor
```

形状：

```text
[B, 80, 3]
```

```python
neighbors_future: torch.Tensor
```

形状：

```text
[B, N, 80, 3]
```

### 11.3 输出数据结构

返回：

```python
inputs, ego_future, neighbors_future
```

形状不变，但坐标和角度已经转换。

### 11.4 代码分步骤解释

#### 第一步：取当前 ego 状态和坐标系中心

```python
cur_state = inputs['ego_current_state'].clone()
center_xy = cur_state[:, :2]
transform_matrix = self.get_transform_matrix_batch(cur_state)
```

- `center_xy` 是新的坐标系原点。
- `transform_matrix` 是新的坐标系旋转矩阵。

#### 第二步：转换 ego_current_state

```python
inputs['ego_current_state'][:, :2] = vector_transform(..., bias=center_xy)
```

当前位置减去自己，所以转换后通常接近：

```text
[0, 0]
```

```python
inputs['ego_current_state'][:, 2:4] = vector_transform(..., bias=None)
```

转换 heading 的 cos/sin 向量。

```python
inputs['ego_current_state'][:, 4:6] = vector_transform(..., bias=None)
inputs['ego_current_state'][:, 6:8] = vector_transform(..., bias=None)
```

转换速度和加速度。

#### 第三步：转换 ego_future

```python
ego_future[:, :, :2] = vector_transform(ego_future[:, :, :2], transform_matrix, center_xy)
ego_future[:, :, 2] = heading_transform(ego_future[:, :, 2], transform_matrix)
```

- 未来位置 `[x, y]` 需要减去 `center_xy` 后旋转。
- 未来 heading 只需要旋转方向。

#### 第四步：转换 neighbor_agents_past

```python
neighbor_agents_past = inputs['neighbor_agents_past']
mask = torch.sum(torch.ne(neighbor_agents_past[:, :, :, :6], 0), dim=-1) == 0
```

`mask` 的形状是：

```text
[B, A, 21]
```

它表示哪些邻车历史点是 padding。

判断逻辑是：

```text
如果前 6 个特征全是 0，就认为该点无效
```

然后转换：

```python
neighbor_agents_past[:, :, :, :2] = vector_transform(..., center_xy)
neighbor_agents_past[:, :, :, 2:4] = vector_transform(..., None)
neighbor_agents_past[:, :, :, 4:6] = vector_transform(..., None)
```

分别处理：

- 位置 `[x, y]`
- heading 方向 `[cos, sin]`
- 速度 `[vx, vy]`

最后：

```python
neighbor_agents_past[mask] = 0.
```

把 padding 点重新置零，避免坐标变换把 padding 的全零值变成非零。

#### 第五步：转换 neighbors_future

```python
mask = torch.sum(torch.ne(neighbors_future[:, :, :, :2], 0), dim=-1) == 0
```

`mask` 形状：

```text
[B, N, 80]
```

如果未来位置 `[x, y]` 全为 0，则认为是无效 future 点。

然后：

```python
neighbors_future[:, :, :, :2] = vector_transform(..., center_xy)
neighbors_future[:, :, :, 2] = heading_transform(...)
neighbors_future[mask] = 0.
```

#### 第六步：转换 lanes

```python
lanes = inputs['lanes']
mask = torch.sum(torch.ne(lanes[:, :, :, :8], 0), dim=-1) == 0
```

`lanes` 形状：

```text
[B, L, P, 12]
```

代码转换四组二维数据：

```python
lanes[:, :, :, :2] = vector_transform(lanes[:, :, :, :2], transform_matrix, center_xy)
lanes[:, :, :, 2:4] = vector_transform(lanes[:, :, :, 2:4], transform_matrix)
lanes[:, :, :, 4:6] = vector_transform(lanes[:, :, :, 4:6], transform_matrix)
lanes[:, :, :, 6:8] = vector_transform(lanes[:, :, :, 6:8], transform_matrix)
```

可以理解为：

- `:2`：lane 点坐标，需要平移加旋转。
- `2:4`：lane 方向向量，只旋转。
- `4:6`：左边界或相关向量，只旋转。
- `6:8`：右边界或相关向量，只旋转。

最后：

```python
lanes[mask] = 0.
```

保持 padding 点为 0。

#### 第七步：转换 route_lanes

`route_lanes` 的处理方式和 `lanes` 完全类似：

```python
route_lanes[:, :, :, :2]
route_lanes[:, :, :, 2:4]
route_lanes[:, :, :, 4:6]
route_lanes[:, :, :, 6:8]
```

转换后同样使用 mask 把 padding 位置置零。

#### 第八步：转换 static_objects

```python
static_objects = inputs['static_objects']
mask = torch.sum(torch.ne(static_objects[:, :, :10], 0), dim=-1) == 0
```

`static_objects` 形状：

```text
[B, S, 10]
```

转换：

```python
static_objects[:, :, :2] = vector_transform(static_objects[:, :, :2], transform_matrix, center_xy)
static_objects[:, :, 2:4] = vector_transform(static_objects[:, :, 2:4], transform_matrix)
```

- `:2` 是静态物体位置。
- `2:4` 是静态物体朝向的 cos/sin。

最后：

```python
static_objects[mask] = 0.
```

### 11.5 为什么 padding 要置零

很多输入数组会被 padding 到固定大小。

例如某个样本只有 3 个静态障碍物，但模型输入固定要求 `S=20`，剩余 17 个会填 0。

如果直接做：

```text
padding点 [0,0] - center_xy
```

它会变成非零坐标，模型就可能误以为那里真的有一个物体。

所以代码在坐标变换后会再次：

```python
xxx[mask] = 0.
```

保证 padding 仍然是 padding。

## 12. StatePerturbation.interpolation_future_trajectory

```python
def interpolation_future_trajectory(self, aug_current_state, ego_future):
```

### 12.1 函数作用

根据扰动后的当前自车状态，重新生成 ego 未来轨迹的前 2 秒。

如果只扰动当前状态而不改未来轨迹，会出现一种不一致：

```text
当前 ego 被挪到了新位置/新朝向，但 future 还是从旧位置开始
```

这会让训练标签不连续。

所以该函数用五次多项式生成一段平滑轨迹，让它从扰动后的当前状态出发，并在 2 秒附近接回原始未来轨迹。

### 12.2 输入数据结构

```python
aug_current_state: torch.Tensor
```

形状：

```text
[B, 10]
```

字段：

```text
0: x
1: y
2: cos(heading)
3: sin(heading)
4: vx
5: vy
6: ax
7: ay
8: steering_angle
9: yaw_rate
```

```python
ego_future: torch.Tensor
```

形状：

```text
[B, 80, 3]
```

字段：

```text
0: x
1: y
2: heading
```

### 12.3 输出数据结构

```python
ego_future: torch.Tensor
```

形状仍然是：

```text
[B, 80, 3]
```

但前 20 个点被替换成插值轨迹，后 60 个点保持原始轨迹：

```text
new_future = refined_first_20_points + original_points_from_index_20
```

### 12.4 代码分步骤解释

#### 第一步：准备矩阵

```python
P = self.num_refine
dt = self.time_interval

M_t = self.t_matrix[None, :, :].expand(B, -1, -1)
A = self.coeff_matrix[None, :, :].expand(B, -1, -1)
```

- `P = 20`
- `dt = 0.1`
- `M_t` 形状是 `[B, 20, 6]`
- `A` 形状是 `[B, 6, 6]`

`M_t` 用于把多项式系数转换成轨迹点。

`A` 用于根据边界条件解多项式系数。

#### 第二步：读取起点状态

```python
x0 = aug_current_state[:, 0]
y0 = aug_current_state[:, 1]
```

起点位置来自扰动后的当前 ego 状态。

```python
theta0 = torch.atan2(
    ego_future[:, P//2, 1] - y0,
    ego_future[:, P//2, 0] - x0
)
```

起点方向 `theta0` 不是直接用 `aug_current_state` 的 heading，而是用当前点指向原始未来第 `P//2` 个点的方向。

这里：

```text
P//2 = 10
```

即用大约 1 秒后的原始未来位置来估计新的起始方向。

```python
v0 = torch.norm(aug_current_state[:, 4:6], dim=-1)
a0 = torch.norm(aug_current_state[:, 6:8], dim=-1)
omega0 = aug_current_state[:, 9]
```

- `v0` 是当前速度大小。
- `a0` 是当前加速度大小。
- `omega0` 是当前 yaw rate。

#### 第三步：读取终点状态

```python
xT = ego_future[:, P, 0]
yT = ego_future[:, P, 1]
thetaT = ego_future[:, P, 2]
```

终点取原始未来轨迹第 20 个点：

```text
ego_future[:, 20]
```

也就是 2 秒附近的轨迹点。

```python
vT = torch.norm(ego_future[:, P, :2] - ego_future[:, P-1, :2], dim=-1) / dt
```

用位置差估计终点速度大小。

```python
aT = torch.norm(
    ego_future[:, P, :2] - 2 * ego_future[:, P-1, :2] + ego_future[:, P-2, :2],
    dim=-1
) / dt**2
```

用二阶差分估计终点加速度大小。

```python
omegaT = self.normalize_angle(ego_future[:, P, 2] - ego_future[:, P-1, 2]) / dt
```

用 heading 差估计终点 yaw rate。

#### 第四步：构造 x 方向边界条件

```python
sx = torch.stack([
    x0,
    v0 * torch.cos(theta0),
    a0 * torch.cos(theta0) - v0 * torch.sin(theta0) * omega0,
    xT,
    vT * torch.cos(thetaT),
    aT * torch.cos(thetaT) - vT * torch.sin(thetaT) * omegaT
], dim=-1)
```

`sx` 形状：

```text
[B, 6]
```

六个量分别是：

```text
x(0)
x'(0)
x''(0)
x(T)
x'(T)
x''(T)
```

其中：

```text
x'(t) = v * cos(theta)
x''(t) = a * cos(theta) - v * sin(theta) * omega
```

#### 第五步：构造 y 方向边界条件

```python
sy = torch.stack([
    y0,
    v0 * torch.sin(theta0),
    a0 * torch.sin(theta0) + v0 * torch.cos(theta0) * omega0,
    yT,
    vT * torch.sin(thetaT),
    aT * torch.sin(thetaT) + vT * torch.cos(thetaT) * omegaT
], dim=-1)
```

`sy` 形状：

```text
[B, 6]
```

六个量分别是：

```text
y(0)
y'(0)
y''(0)
y(T)
y'(T)
y''(T)
```

其中：

```text
y'(t) = v * sin(theta)
y''(t) = a * sin(theta) + v * cos(theta) * omega
```

#### 第六步：求五次多项式系数

```python
ax = torch.bmm(A, sx[:, :, None])
ay = torch.bmm(A, sy[:, :, None])
```

`sx[:, :, None]` 形状是：

```text
[B, 6, 1]
```

所以：

```text
[B, 6, 6] @ [B, 6, 1] -> [B, 6, 1]
```

`ax` 和 `ay` 分别是 x、y 两个方向的五次多项式系数。

#### 第七步：计算轨迹点坐标

```python
traj_x = torch.bmm(M_t, ax)
traj_y = torch.bmm(M_t, ay)
```

形状：

```text
[B, 20, 1]
```

表示前 20 个未来点的 x、y 坐标。

#### 第八步：计算轨迹 heading

```python
traj_heading = torch.atan2(
    torch.diff(traj_y, dim=1),
    torch.diff(traj_x, dim=1)
)
```

根据相邻点的方向计算 heading。

`torch.diff()` 会让长度从 20 变成 19，所以后面补一个最后的 heading：

```python
traj_heading = torch.cat([traj_heading, traj_heading[:, -1:, :]], dim=1)
```

最终 `traj_heading` 形状恢复为：

```text
[B, 20, 1]
```

#### 第九步：拼回完整未来轨迹

```python
return torch.cat([
    torch.cat([traj_x, traj_y, traj_heading], dim=-1),
    ego_future[:, P:, :]
], dim=1)
```

前半段：

```text
torch.cat([traj_x, traj_y, traj_heading], dim=-1) -> [B, 20, 3]
```

后半段：

```text
ego_future[:, P:, :] -> [B, 60, 3]
```

最终：

```text
[B, 80, 3]
```

## 14. 一个完整流程例子

假设 batch 中某个样本：

```text
ego_current_state = [0, 0, 1, 0, 8, 0, 0, 0, 0, 0]
```

表示：

- ego 在原点。
- 朝向 x 正方向。
- 速度 8 m/s。

增强时随机扰动为：

```text
y = +0.5
heading = +0.1 rad
vx = -0.3
```

扰动后的 ego 当前状态可能变成：

```text
[0, 0.5, cos(0.1), sin(0.1), 7.7, 0, 0, 0, steering, yaw_rate]
```

随后：

1. `interpolation_future_trajectory()` 重新生成未来前 20 个点，让轨迹从这个扰动状态平滑出发。
2. `centric_transform()` 以 `[0, 0.5]` 和 `heading=0.1` 为新的坐标系。
3. ego future、neighbor future、lane、route lane、static object 全部被减去 `[0, 0.5]` 并旋转 `-0.1` rad。

最终模型看到的是一个自洽的新样本：

```text
当前 ego 在新坐标系原点附近
未来轨迹从扰动后的状态出发
邻车和地图都处于同一个新 ego 坐标系
```

## 15. 关键注意点

1. `StatePerturbation` 是训练增强逻辑，不是推理时必须执行的逻辑。
2. `augment_prob` 的实际语义要看代码中的 `torch.rand(B) >= augment_prob`，它并不是严格意义上的“增强概率”等于 `augment_prob`。
3. 低速样本会被排除增强，条件是 `abs(vx) < 2.0`。
4. `centric_transform()` 会原地修改 `inputs`、`ego_future`、`neighbors_future`。
5. padding 数据在变换后会被重新置零，否则 padding 点会因为平移而变成非零假目标。
6. `interpolation_future_trajectory()` 使用五次多项式连接扰动后的当前状态和原始未来轨迹，保证训练标签连续。
