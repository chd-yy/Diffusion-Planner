# diffusion_planner/loss.py 详解

本文档解释 `diffusion_planner/loss.py` 的代码结构、函数输入输出、变量含义和调用关系。这个文件当前只有一个核心函数：`diffusion_loss_func()`，用于训练 Diffusion Planner 的扩散模型损失。

## 1. 文件作用

`loss.py` 负责把训练 batch 中的未来轨迹真值组织成扩散模型训练目标。

它主要完成：

1. 从 `futures` 中取出 ego future、neighbor future 和 neighbor future mask。
2. 把 ego 和 neighbor 拼成统一的 agent 维度。
3. 对 future 轨迹做状态归一化。
4. 采样扩散时间 `t` 和高斯噪声 `z`。
5. 通过 SDE 的 `marginal_prob()` 构造加噪轨迹 `xT`。
6. 把加噪轨迹和扩散时间放进 `merged_inputs`，送入模型。
7. 根据 `model_type` 计算扩散训练损失。
8. 分别统计：
   - `neighbor_prediction_loss`
   - `ego_planning_loss`

训练调用链是：

```text
train_predictor.py
    └── train_epoch(...)
            └── diffusion_loss_func(...)
                    ├── args.state_normalizer(...)
                    ├── ddp.get_model(model, args.ddp).sde.marginal_prob(...)
                    └── model(merged_inputs)
                            └── Diffusion_Planner.forward(...)
                                    ├── Encoder.forward(...)
                                    └── Decoder.forward(...)
                                            └── DiT.forward(...)
```

## 3. diffusion_loss_func

```python
def diffusion_loss_func(
    model: nn.Module,
    inputs: Dict[str, torch.Tensor],
    marginal_prob: Callable[[torch.Tensor], torch.Tensor],
    futures: Tuple[torch.Tensor, torch.Tensor],
    norm: StateNormalizer,
    loss: Dict[str, Any],
    model_type: str,
    eps: float = 1e-3,
):
```

## 4. 函数作用

`diffusion_loss_func()` 是训练阶段的扩散损失函数。

它不是直接让模型预测未来轨迹，然后和真值做 MSE。它先把真实未来轨迹 `gt_future` 通过扩散前向过程加噪，得到 `xT`，再让模型根据输入场景、加噪轨迹和扩散时间 `t` 学习去噪目标。

根据 `model_type` 不同，模型目标有两种：

```text
model_type == "score"
    模型预测 score，loss 约束 score * std 接近 -z

model_type == "x_start"
    模型直接预测干净 future，loss 约束输出接近归一化后的 gt_future
```

## 5. 输入参数

### 5.1 `model`

```python
model: nn.Module
```

训练中的 Diffusion Planner 模型。

在 `train_epoch.py` 中调用：

```python
loss, _ = diffusion_loss_func(
    model,
    inputs,
    ddp.get_model(model, args.ddp).sde.marginal_prob,
    (ego_future, neighbors_future, mask),
    args.state_normalizer,
    loss,
    args.diffusion_model_type
)
```

函数内部会调用：

```python
_, decoder_output = model(merged_inputs)
```

训练态模型返回：

```text
encoder_outputs, decoder_output
```

其中 `decoder_output` 至少包含：

```python
decoder_output["score"]
```

形状通常是：

```text
[B, P, 1 + T, 4]
```

### 5.2 `inputs`

```python
inputs: Dict[str, torch.Tensor]
```

模型输入字典。

在进入 `diffusion_loss_func()` 前，`train_epoch.py` 已经做过：

```python
inputs = args.observation_normalizer(inputs)
```

也就是说，观测输入已经经过 `ObservationNormalizer` 归一化。

本函数中直接读取的 key 有：

```text
inputs["ego_current_state"]     -> [B, 10]
inputs["neighbor_agents_past"]  -> [B, past_neighbor_num, 21, 11]
```

后面还会通过：

```python
merged_inputs = {
    **inputs,
    "sampled_trajectories": xT,
    "diffusion_time": t,
}
```

额外给模型增加两个训练专用字段。

### 5.3 `marginal_prob`

```python
marginal_prob: Callable
```

扩散 SDE 的边缘概率函数。

实际来自：

```python
ddp.get_model(model, args.ddp).sde.marginal_prob
```

在当前项目中，默认 SDE 是 `VPSDE_linear`，定义在：

```text
diffusion_planner/model/diffusion_utils/sde.py
```

`VPSDE_linear.marginal_prob(x, t)` 返回：

```text
mean, std
```

用于描述扩散前向过程：

```text
x_t = mean(x_0, t) + std(t) * z
```

### 5.4 `futures`

```python
futures: Tuple[torch.Tensor, torch.Tensor]
```

虽然类型注解里写了两个 tensor，但实际传入和解包是三个对象：

```python
ego_future, neighbors_future, neighbor_future_mask = futures
```

来自 `train_epoch.py`：

```python
(ego_future, neighbors_future, mask)
```

#### `ego_future`

形状：

```text
[B, T, 4]
```

字段：

```text
[x, y, cos_heading, sin_heading]
```

注意：原始数据里的 ego future 是 `[x, y, heading]`，但在 `train_epoch.py` 进入 loss 前已经转成了 cos/sin：

```python
ego_future = torch.cat(
    [
        ego_future[..., :2],
        torch.stack(
            [ego_future[..., 2].cos(), ego_future[..., 2].sin()],
            dim=-1
        ),
    ],
    dim=-1,
)
```

所以传到 loss 时已经是 4 维。

#### `neighbors_future`

形状：

```text
[B, Pn, T, 4]
```

字段：

```text
[x, y, cos_heading, sin_heading]
```

其中：

- `Pn`：需要预测的 neighbor 数量。
- `T`：未来轨迹步数，通常是 80。

同样，原始 neighbor future 是 `[x, y, heading]`，进入 loss 前也被转成了 `[x, y, cos, sin]`。

#### `neighbor_future_mask`

形状：

```text
[B, Pn, T]
```

类型：

```text
bool tensor
```

含义：

```text
True  -> 该 neighbor future 时间点无效或是 padding
False -> 该 neighbor future 时间点有效
```

它在 `train_epoch.py` 中构造：

```python
mask = torch.sum(torch.ne(neighbors_future[..., :3], 0), dim=-1) == 0
```

意思是：如果 neighbor future 的 `[x, y, heading]` 全是 0，就认为该点无效。

### 5.5 `norm`

```python
norm: StateNormalizer
```

用于归一化 future 状态。

调用方式：

```python
norm(gt_future)
```

输入形状：

```text
[B, 1 + Pn, T, 4]
```

输出形状不变。

`StateNormalizer` 中的 `mean/std` 通常形状可以广播到：

```text
[B, 1 + Pn, T, 4]
```

其中第 0 个 agent 用 ego 的 mean/std，后面的 neighbor 使用 neighbor 的 mean/std。

### 5.6 `loss`

```python
loss: Dict[str, Any]
```

输入时通常是空字典：

```python
loss = {}
```

函数内部会写入：

```python
loss["neighbor_prediction_loss"]
loss["ego_planning_loss"]
```

函数返回后，`train_epoch.py` 继续写入总 loss：

```python
loss['loss'] = loss['neighbor_prediction_loss'] + args.alpha_planning_loss * loss['ego_planning_loss']
```

### 5.7 `model_type`

```python
model_type: str
```

支持：

```text
"score"
"x_start"
```

它决定 `decoder_output["score"]` 的训练目标。

虽然 key 名叫 `"score"`，但在 `model_type == "x_start"` 时，它实际代表模型预测的干净起始轨迹 `x_start`。

这个逻辑和 `diffusion_planner/model/module/decoder.py` 中的 `DiT.forward()` 对应：

```python
if self._model_type == "score":
    return x / (self.marginal_prob_std(t)[:, None, None] + 1e-6)
elif self._model_type == "x_start":
    return x
```

### 5.8 `eps`

```python
eps: float = 1e-3
```

用于采样扩散时间 `t` 时避开 0：

```python
t = torch.rand(B, device=gt_future.device) * (1 - eps) + eps
```

因此：

```text
t ∈ [eps, 1]
```

避免 `t = 0` 时出现数值不稳定或 `std = 0` 的问题。

## 6. 输出

函数返回：

```python
return loss, decoder_output
```

### 6.1 `loss`

类型：

```text
Dict[str, torch.Tensor]
```

函数内部写入：

```text
neighbor_prediction_loss -> scalar tensor
ego_planning_loss        -> scalar tensor
```

返回到 `train_epoch.py` 后，会继续增加：

```text
loss -> scalar tensor
```

总 loss 计算方式：

```python
loss['loss'] = loss['neighbor_prediction_loss'] + args.alpha_planning_loss * loss['ego_planning_loss']
```

### 6.2 `decoder_output`

类型：

```text
Dict[str, torch.Tensor]
```

训练阶段至少包含：

```text
decoder_output["score"] -> [B, P, 1 + T, 4]
```

其中：

- `B`：batch size。
- `P = 1 + Pn`：第 0 个是 ego，后面是 neighbor。
- `1 + T`：第 0 个时间步是 current state，后面 T 个是 future。
- `4`：状态维度 `[x, y, cos_heading, sin_heading]`。

## 7. 函数内部流程详解

### 7.1 解包 futures

```python
ego_future, neighbors_future, neighbor_future_mask = futures
```

得到：

```text
ego_future           -> [B, T, 4]
neighbors_future     -> [B, Pn, T, 4]
neighbor_future_mask -> [B, Pn, T]
```

这里的 `neighbor_future_mask=True` 表示无效。

### 7.2 构造 neighbors_future_valid

```python
neighbors_future_valid = ~neighbor_future_mask
```

取反后：

```text
neighbors_future_valid=True 表示该 neighbor future 点有效
```

形状仍然是：

```text
[B, Pn, T]
```

后面计算 neighbor loss 时，只会保留有效位置。

### 7.3 读取 batch 维度

```python
B, Pn, T, _ = neighbors_future.shape
```

含义：

```text
B  -> batch size
Pn -> neighbor 数量
T  -> future 时间步数量
_  -> 状态维度，通常是 4
```

### 7.4 取当前 ego 和 neighbor 状态

```python
ego_current, neighbors_current = (
    inputs["ego_current_state"][:, :4],
    inputs["neighbor_agents_past"][:, :Pn, -1, :4]
)
```

`ego_current` 形状：

```text
[B, 4]
```

字段：

```text
[x, y, cos_heading, sin_heading]
```

`neighbors_current` 形状：

```text
[B, Pn, 4]
```

它来自 neighbor 历史轨迹的最后一帧：

```python
inputs["neighbor_agents_past"][:, :Pn, -1, :4]
```

其中 `-1` 表示取历史序列最后一帧，也就是当前时刻。

### 7.5 构造 neighbor_current_mask

```python
neighbor_current_mask = torch.sum(torch.ne(neighbors_current[..., :4], 0), dim=-1) == 0
```

形状：

```text
[B, Pn]
```

含义：

```text
True  -> 该 neighbor 当前状态是 padding，无效
False -> 该 neighbor 当前状态有效
```

逻辑是：

```text
如果 [x, y, cos_h, sin_h] 四个值全是 0，就认为该 neighbor 不存在
```

### 7.6 拼接 neighbor_mask

```python
neighbor_mask = torch.concat(
    (neighbor_current_mask.unsqueeze(-1), neighbor_future_mask),
    dim=-1
)
```

`neighbor_current_mask.unsqueeze(-1)`：

```text
[B, Pn] -> [B, Pn, 1]
```

`neighbor_future_mask`：

```text
[B, Pn, T]
```

拼接后：

```text
neighbor_mask -> [B, Pn, 1 + T]
```

含义：

```text
第 0 个时间步：neighbor 当前状态是否无效
后面 T 个时间步：neighbor future 是否无效
```

这个 mask 后面会用于把 `all_gt` 中 neighbor 的无效位置置零。

### 7.7 拼接 ego 和 neighbor future

```python
gt_future = torch.cat(
    [ego_future[:, None, :, :], neighbors_future[..., :]],
    dim=1
)
```

`ego_future[:, None, :, :]` 的形状：

```text
[B, 1, T, 4]
```

`neighbors_future` 的形状：

```text
[B, Pn, T, 4]
```

拼接后：

```text
gt_future -> [B, 1 + Pn, T, 4]
```

第 1 维的含义是：

```text
agent 0      -> ego
agent 1..Pn  -> neighbors
```

代码注释里写的是：

```python
# [B, P = 1 + 1 + neighbor, T, 4]
```

这里更准确应理解为：

```text
P = 1 + Pn
```

### 7.8 拼接 current_states

```python
current_states = torch.cat(
    [ego_current[:, None], neighbors_current],
    dim=1
)
```

`ego_current[:, None]`：

```text
[B, 4] -> [B, 1, 4]
```

`neighbors_current`：

```text
[B, Pn, 4]
```

拼接后：

```text
current_states -> [B, 1 + Pn, 4]
```

和 `gt_future` 的 agent 维度保持一致：

```text
agent 0      -> ego current
agent 1..Pn  -> neighbor current
```

### 7.9 统计 agent 数 P

```python
P = gt_future.shape[1]
```

得到：

```text
P = 1 + Pn
```

### 7.10 采样扩散时间 t

```python
t = torch.rand(B, device=gt_future.device) * (1 - eps) + eps
```

形状：

```text
[B]
```

每个 batch 样本一个扩散时间。

范围：

```text
[eps, 1]
```

举例：

```text
t = [0.12, 0.87, 0.43, ...]
```

### 7.11 采样高斯噪声 z

```python
z = torch.randn_like(gt_future, device=gt_future.device)
```

形状和 `gt_future` 相同：

```text
[B, P, T, 4]
```

每个 future 状态维度都会采样一个标准高斯噪声。

### 7.12 构造 all_gt

```python
all_gt = torch.cat(
    [current_states[:, :, None, :], norm(gt_future)],
    dim=2
)
```

`current_states[:, :, None, :]`：

```text
[B, P, 4] -> [B, P, 1, 4]
```

`norm(gt_future)`：

```text
[B, P, T, 4]
```

拼接后：

```text
all_gt -> [B, P, 1 + T, 4]
```

其中：

```text
all_gt[:, :, 0, :]   -> 当前状态
all_gt[:, :, 1:, :]  -> 归一化后的未来轨迹
```

注意：当前状态没有经过 `StateNormalizer`。只有 future 部分调用了：

```python
norm(gt_future)
```

### 7.13 把 neighbor 无效位置置零

```python
all_gt[:, 1:][neighbor_mask] = 0.0
```

`all_gt[:, 1:]` 表示只处理 neighbor，不处理 ego：

```text
all_gt[:, 1:] -> [B, Pn, 1 + T, 4]
```

`neighbor_mask`：

```text
[B, Pn, 1 + T]
```

这句会把无效 neighbor 的 current/future 状态置 0。

为什么需要这一步：

- padding neighbor 不应该参与扩散训练。
- 归一化后的 padding 可能不再是 0。
- 所以需要重新把无效位置置零。

### 7.14 计算扩散边缘分布 mean/std

```python
mean, std = marginal_prob(all_gt[..., 1:, :], t)
```

输入：

```text
all_gt[..., 1:, :] -> [B, P, T, 4]
t                  -> [B]
```

输出：

```text
mean -> [B, P, T, 4]
std  -> 通常可广播到 [B, P, T, 4]
```

在 `VPSDE_linear.marginal_prob()` 里，逻辑是：

```text
mean = exp(mean_log_coeff) * x
std = sqrt(1 - exp(2 * mean_log_coeff))
```

这里的 `x` 是干净的归一化 future。

### 7.15 reshape std 方便广播

```python
std = std.view(-1, *([1] * (len(all_gt[..., 1:, :].shape)-1)))
```

`all_gt[..., 1:, :]` 的形状是：

```text
[B, P, T, 4]
```

维度数是 4。

所以：

```python
len(all_gt[..., 1:, :].shape) - 1 = 3
```

`std` 会 reshape 成：

```text
[B, 1, 1, 1]
```

这样它可以和：

```text
[B, P, T, 4]
```

广播相乘。

### 7.16 构造加噪 future xT

```python
xT = mean + std * z
```

形状：

```text
[B, P, T, 4]
```

含义：

```text
xT 是扩散前向过程在时间 t 的加噪 future
```

公式：

```text
x_t = mean(x_0, t) + std(t) * z
```

其中：

- `x_0` 是归一化后的真实 future。
- `z` 是标准高斯噪声。
- `t` 是扩散时间。

### 7.17 把 current state 拼回 xT

```python
xT = torch.cat([all_gt[:, :, :1, :], xT], dim=2)
```

`all_gt[:, :, :1, :]`：

```text
[B, P, 1, 4]
```

`xT`：

```text
[B, P, T, 4]
```

拼接后：

```text
xT -> [B, P, 1 + T, 4]
```

含义：

```text
第 0 个时间步是 current state，不加噪
后面 T 个时间步是加噪 future
```

这样模型可以在同一个 `sampled_trajectories` 里看到 current + noisy future。

### 7.18 构造 merged_inputs

```python
merged_inputs = {
    **inputs,
    "sampled_trajectories": xT,
    "diffusion_time": t,
}
```

这是 Python 字典解包语法。

`**inputs` 表示把原来的输入字典展开复制进新字典。

然后额外增加：

```text
sampled_trajectories -> [B, P, 1 + T, 4]
diffusion_time       -> [B]
```

这两个 key 是训练扩散 decoder 必需的。

在 `Decoder.forward()` 中会读取：

```python
sampled_trajectories = inputs['sampled_trajectories'].reshape(B, P, -1)
diffusion_time = inputs['diffusion_time']
```

然后送入：

```python
self.dit(sampled_trajectories, diffusion_time, ...)
```

### 7.19 调用模型

```python
_, decoder_output = model(merged_inputs)
```

训练阶段模型返回：

```text
encoder_outputs, decoder_output
```

这里只需要 decoder 输出，所以第一个返回值用 `_` 忽略。

`decoder_output` 中关键字段是：

```python
decoder_output["score"]
```

形状：

```text
[B, P, 1 + T, 4]
```

### 7.20 去掉 current 时间步

```python
score = decoder_output["score"][:, :, 1:, :]
```

因为 loss 只监督 future，不监督 current state。

所以从：

```text
[B, P, 1 + T, 4]
```

变成：

```text
[B, P, T, 4]
```

变量名叫 `score`，但它在不同 `model_type` 下含义不同：

```text
model_type == "score"   -> score 是得分函数预测
model_type == "x_start" -> score 实际是 x_start 预测
```

## 8. 两种 loss 分支

### 8.1 `model_type == "score"`

```python
if model_type == "score":
    dpm_loss = torch.sum((score * std + z)**2, dim=-1)
```

训练目标：

```text
score * std ≈ -z
```

所以 loss 是：

```text
(score * std + z)^2
```

`score` 形状：

```text
[B, P, T, 4]
```

`z` 形状：

```text
[B, P, T, 4]
```

`std` reshape 后可广播到：

```text
[B, P, T, 4]
```

`torch.sum(..., dim=-1)` 会把最后一维 4 个状态维度求和。

因此 `dpm_loss` 形状：

```text
[B, P, T]
```

### 8.2 `model_type == "x_start"`

```python
elif model_type == "x_start":
    dpm_loss = torch.sum((score - all_gt[:, :, 1:, :])**2, dim=-1)
```

训练目标：

```text
模型输出 ≈ 干净的归一化 future
```

其中：

```python
all_gt[:, :, 1:, :]
```

是归一化后的真实 future：

```text
[B, P, T, 4]
```

所以这相当于对每个 agent、每个 future 时间点做状态维度上的 MSE 求和。

输出 `dpm_loss` 形状同样是：

```text
[B, P, T]
```

## 9. neighbor_prediction_loss

```python
masked_prediction_loss = dpm_loss[:, 1:, :][neighbors_future_valid]
```

### 9.1 取 neighbor 部分

```python
dpm_loss[:, 1:, :]
```

去掉第 0 个 agent，也就是 ego，只保留 neighbor：

```text
[B, Pn, T]
```

### 9.2 用 valid mask 过滤

```python
neighbors_future_valid
```

形状：

```text
[B, Pn, T]
```

`True` 表示有效。

所以：

```python
dpm_loss[:, 1:, :][neighbors_future_valid]
```

会得到一维 tensor：

```text
[num_valid_neighbor_future_points]
```

里面只包含有效 neighbor future 点的 loss。

### 9.3 求平均

```python
if masked_prediction_loss.numel() > 0:
    loss["neighbor_prediction_loss"] = masked_prediction_loss.mean()
else:
    loss["neighbor_prediction_loss"] = torch.tensor(0.0, device=masked_prediction_loss.device)
```

如果有有效 neighbor future 点，则求平均。

如果没有，则设为 0，避免空 tensor 上调用 `mean()` 得到 NaN。

输出：

```text
loss["neighbor_prediction_loss"] -> scalar tensor
```

## 10. ego_planning_loss

```python
loss["ego_planning_loss"] = dpm_loss[:, 0, :].mean()
```

`dpm_loss[:, 0, :]` 表示第 0 个 agent，也就是 ego：

```text
[B, T]
```

直接对 batch 和时间维度求平均。

输出：

```text
loss["ego_planning_loss"] -> scalar tensor
```

注意：ego future 没有类似 neighbor 的 padding mask，因此所有 ego future 时间点都会参与 loss。

## 11. NaN 检查

```python
assert not torch.isnan(dpm_loss).sum(), f"loss cannot be nan, z={z}"
```

作用：

```text
如果 dpm_loss 中存在 NaN，直接中断训练
```

`torch.isnan(dpm_loss)` 得到 bool tensor。

`sum()` 会统计 NaN 数量。

如果 NaN 数量不为 0：

```python
not torch.isnan(dpm_loss).sum()
```

会触发断言失败。

## 12. 输出返回

```python
return loss, decoder_output
```

返回后，`train_epoch.py` 会继续计算总 loss：

```python
loss['loss'] = loss['neighbor_prediction_loss'] + args.alpha_planning_loss * loss['ego_planning_loss']
```

然后：

```python
loss['loss'].backward()
```

也就是说：

```text
diffusion_loss_func 负责计算分项 loss
train_epoch.py 负责组合总 loss 并反向传播
```

## 13. 关键张量形状总览

假设：

```text
B  = batch size
Pn = predicted_neighbor_num
P  = 1 + Pn
T  = future_len，通常是 80
```

| 变量名 | 形状 | 含义 |
|---|---:|---|
| `ego_future` | `[B, T, 4]` | ego future 真值，字段 `[x, y, cos_h, sin_h]` |
| `neighbors_future` | `[B, Pn, T, 4]` | neighbor future 真值 |
| `neighbor_future_mask` | `[B, Pn, T]` | `True` 表示无效或 padding |
| `neighbors_future_valid` | `[B, Pn, T]` | `True` 表示有效 |
| `ego_current` | `[B, 4]` | ego 当前 `[x, y, cos_h, sin_h]` |
| `neighbors_current` | `[B, Pn, 4]` | neighbor 当前 `[x, y, cos_h, sin_h]` |
| `neighbor_current_mask` | `[B, Pn]` | neighbor 当前状态是否无效 |
| `neighbor_mask` | `[B, Pn, 1 + T]` | neighbor 当前 + 未来无效 mask |
| `gt_future` | `[B, P, T, 4]` | ego + neighbor future 真值 |
| `current_states` | `[B, P, 4]` | ego + neighbor 当前状态 |
| `t` | `[B]` | 扩散时间 |
| `z` | `[B, P, T, 4]` | 标准高斯噪声 |
| `all_gt` | `[B, P, 1 + T, 4]` | current + 归一化 future |
| `mean` | `[B, P, T, 4]` | SDE 边缘分布均值 |
| `std` | `[B, 1, 1, 1]` | SDE 边缘分布标准差，广播用 |
| `xT` | `[B, P, 1 + T, 4]` | current + 加噪 future |
| `decoder_output["score"]` | `[B, P, 1 + T, 4]` | decoder 输出 |
| `score` | `[B, P, T, 4]` | 去掉 current 后的 decoder 输出 |
| `dpm_loss` | `[B, P, T]` | 每个 agent、每个未来时间点的扩散 loss |
| `masked_prediction_loss` | `[num_valid]` | 有效 neighbor future 点的 loss |

## 14. 简单例子

假设：

```text
B = 2
Pn = 3
T = 80
```

那么：

```text
ego_future       -> [2, 80, 4]
neighbors_future -> [2, 3, 80, 4]
```

拼接后：

```text
gt_future -> [2, 4, 80, 4]
```

这里第 1 维的 4 个 agent 是：

```text
0: ego
1: neighbor_0
2: neighbor_1
3: neighbor_2
```

加上 current state 后：

```text
all_gt -> [2, 4, 81, 4]
```

其中：

```text
all_gt[:, :, 0, :]   -> 当前状态
all_gt[:, :, 1:, :]  -> 未来 80 帧
```

扩散只对 future 加噪：

```text
all_gt[:, :, 1:, :] -> [2, 4, 80, 4]
```

构造 `xT` 后再拼回 current：

```text
xT -> [2, 4, 81, 4]
```

模型输出：

```text
decoder_output["score"] -> [2, 4, 81, 4]
```

去掉 current：

```text
score -> [2, 4, 80, 4]
```

最后得到：

```text
dpm_loss -> [2, 4, 80]
```

其中：

```text
dpm_loss[:, 0, :]   -> ego planning loss 来源
dpm_loss[:, 1:, :]  -> neighbor prediction loss 来源
```

## 15. 需要特别注意的点

1. `futures` 的类型注解写成了两个 tensor，但实际使用是三个对象：`ego_future`、`neighbors_future`、`neighbor_future_mask`。
2. `neighbor_future_mask=True` 表示无效，而 `neighbors_future_valid=True` 表示有效。
3. 当前状态 `current_states` 不参与扩散加噪，只有 future 部分会通过 `marginal_prob()` 加噪。
4. `all_gt[:, 1:][neighbor_mask] = 0.0` 只清理 neighbor 的无效位置，不清理 ego。
5. `decoder_output["score"]` 这个 key 名在 `model_type == "x_start"` 时容易误导，它实际表示模型预测的干净 future。
6. `dpm_loss` 的最后一维状态维度已经被 `torch.sum(..., dim=-1)` 求和，后续只剩 `[B, P, T]`。
7. 总 loss 不在 `loss.py` 中计算，而是在 `train_epoch.py` 中组合。
